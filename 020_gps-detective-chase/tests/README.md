# 関連箇所の検証

本番Firebaseへ接続するテストは含みません。`firebase-mock.js` はブラウザテスト時にだけルート差し替えで読み込まれます。アプリのHTMLから参照しません。

## 実行

```powershell
node --experimental-vm-modules tests/logic.cjs
$env:PLAYWRIGHT_PATH = 'インストール済みplaywright-coreの絶対パス'
node tests/browser.cjs
$env:TEST_BROWSER = 'webkit'
node tests/browser.cjs
```

`browser.cjs` のブラウザ実行パスはこの作業環境に合わせています。他環境では `CHROMIUM_EXECUTABLE` / `WEBKIT_EXECUTABLE` で指定できます。LeafletとOSMは既存の外部URLを利用するため、地図確認にはネットワークが必要です。Playwrightやブラウザを本プロジェクトへ追加インストールしていません。

## 2026-10-17の結果

- Nodeロジックテスト：成功。座標・取得時刻の無効値、未来時刻、10秒の鮮度境界、精度50mの境界、25m／5秒の既定捕獲、GPS監視の重複開始、拒否／失敗／タイムアウト、更新停止、停止後の遅延コールバック、再開、目撃の原子的生成、勝利の重複確定防止。目撃の既定半径・有効期限・移動方向、実Roomのキャッシュなし参加、閉じたセッションの更新拒否、確定応答待ち設定も確認。
- Chromium（タッチ対応モバイル画面設定＋通信／GPSモック）：成功。320×568、375×667、390×844、430×932の各7画面の横方向はみ出し、作成・準備・開始の連打、準備の通信失敗後の操作復旧、コピー拒否時の代替、GPSエラー・精度不足、位置送信、通信切断、pagehide/pageshow、結果画面復帰時のGPS停止、終了後の送信停止、再戦、既存部屋への再参加、退出時の購読解除、通信遅延中の目撃の重複防止、ローカル捕獲、デバッグ終了後の分離。
- デスクトップWebKit：検証を試みたが、インストール済みWebKitとドライバ間のプロトコルエラー（`Unknown setting: PushAPIEnabled`）で中止。合格とはしていません。
- 入力欄の文字選択設定、操作ボタンのtouch-action、Leafletのマウスドラッグ：Chromiumで成功。
- 実際のゲーム画面のスクリーンショットで地図・HUD・安全確認・退出ボタンの配置を確認。
- 全 `js/*.js` の構文確認、`git diff --check`：成功。

ブラウザテストの画面サイズ検証はDOM寸法と一部のスクリーンショットに基づきます。iPhone Safariそのものの合格判定ではありません。
