# 鉄棒ゲーム — 足を振ってこぐ大車輪チャレンジ

ビルド・外部ライブラリ・通信不要の1人用Canvasゲームです。静的Webサーバーで配信するか、index.htmlを開いて遊べます。iPhoneは横画面推奨です。

## 操作

- **こぐ**：Space / Z、または左ボタンを押している間、股関節から足を前へ振り出します。離すと足を下へ戻します。
- **離す！**：X / Enter、または右ボタンで離手します。
- **もう一度**：着地後のボタン、または R。

下へ向かう途中でこぎ、振り上がったら足を戻す、を繰り返します。押しっぱなしや速い連打では勢いが育ちません。右へ上がる瞬間に離手し、空中でも足の姿勢を変えて回転を調整できます。着地前には足を下へ戻してください。

## 玩具の動き

腕は肩から手まで固定長の1パーツです。描画にも物理にも同じ手・肩の座標を使い、画像倍率は一定です。姿勢に応じて肩角度だけが少し変わります。

足も長さ一定で、通常の0度から前方65度へ股関節を中心に回転します。腰と上半身は少し前へ動きます。ばね・減衰による姿勢補間で、押す・離すと足が滑らかに動きます。左右別の腕や足はありません。

腕・胴体・足の質量位置から重心と慣性モーメント、姿勢変化に伴う角運動量を計算します。重力トルクと運動量の交換によって振り子の勢いが増減します。玩具らしく数回で大車輪へ進めるよう、足の姿勢による慣性変化を強調しています。ボタンによる一定の角速度加算や自動離手はありません。

離手時は重心速度、姿勢、角速度をそのまま引き継ぎます。空中では重心を弾道運動させ、足の姿勢による慣性変化と内部の動きから回転を計算します。

## 表示と調整

白い手足を見分けやすい濃い青系の背景です。通常時はiPhone横画面で旧版の約1.8倍の選手サイズになるよう画角を寄せ、大きな振り・大車輪では一周が収まるよう滑らかに画角を広げます。

physics.js冒頭のCONFIGに調整値を集約しています。

- armLength：固定の腕長
- legForwardAngle / legReturnAngle：足の前方・通常角度（ラジアン）
- pumpStrength：足の質量効果と姿勢による慣性変化の強調度
- pumpResponseSpeed：足を動かす姿勢応答
- shoulderForwardAngle / hipForwardAngle：肩・腰の補助姿勢
- viewMinHeight / viewHeight / viewMargin：画角・余白
- gravity / swingDamping：重力・振り子減衰

DEBUGでは足の現在・目標角度、振り子角度、角速度、現在の振れ幅（エネルギーからの推定）、こぐON/OFF、重心座標とマーカー、腕長、接触判定などを表示します。
