# 鉄棒ゲーム — 大車輪チャレンジ

ビルド・外部ライブラリ・通信不要の1人用Canvasゲームです。`index.html` を開くか、リポジトリを静的Webサーバーで配信してください。iPhoneは横画面推奨です。

## 操作

- **縮む**：Space / Z、または左ボタンを押している間だけ。離すと伸びます。
- **離す！**：X / Enter、または右ボタン。鉄棒から飛び出します。
- **もう一度**：着地後のボタン、または R。

下を通る直前に縮み、振り上がったところで伸びると振幅が育ちます。押しっぱなしでは育ちません。右へ上がるタイミングで離手し、空中で縮んで回転、着地前に伸びて足を下へ向けます。

## 構成と調整

- `physics.js`：描画から独立した固定刻みの可変長振り子、自由飛行、着地・採点。冒頭 `CONFIG` に調整定数を集約。
- `game.js`：Canvas描画、3パーツのPNG、入力、カメラ、結果表示。
- `style.css`：画面サイズ・セーフエリア対応。
- `assets/`：オリジナル玩具画像。肩・腰を基準に回転・補間します。

Matter.jsは使用せず、重力トルクと慣性変化による角運動量保存を計算します。縮む操作自体による一定の加速や自動離手はありません。姿勢補間は約133ms。角速度の上限のみ玩具らしい速度に制限しています。離手時は重心の接線速度・半径方向速度と角速度を引き継ぎ、空中は慣性変化で回転速度が変わります。

足・頭・胴体の円を前フレームから掃引し、マットと床に最初に当たる部位を判定します。評価は足からの接触、胴体傾き、速度、回転速度、マット中央からの距離で決まります。DEBUGで当たり判定、肩・腰・手、運動量の数値を確認できます。

検証：`node 026_tetsubou-game/tests/physics.test.cjs` と `node 026_tetsubou-game/tests/input.test.cjs`。`tests/browser.test.cjs` はPlaywrightが導入された開発環境用です（必要に応じて `PLAYWRIGHT_MODULE` にモジュールのパスを指定）。WebKitで844×390・667×375・390×844、Chromiumで1280×800の表示・入力・着地・再開を確認済みです。iPhone実機での表示・操作の最終確認は別途必要です。
