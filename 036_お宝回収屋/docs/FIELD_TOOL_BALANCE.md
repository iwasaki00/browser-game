## 課題と制約

初期資金からの購入時間、継続採取・移動を含む長期FN、精密道具の実プレイヤー操作時間、実機Safari・電池/メモリは未計測。川底手動操作回数は0.6秒の引き動作換算、設備は1登録。河原の回収操作秒は手0.3/ピンセット0.18/スポイト0.22/セット0.18のモデル値で、実機測定ではない。小型道具の用途と大型の速度/回収率のトレードオフを維持し、0.9.0で資金制約付きルートを検証する。

再実行：npm.cmd run balance:field-feel。
