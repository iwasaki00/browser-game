# Version 0.9.0 — GAME EXPERIENCE REFINEMENT

1. **Version**：0.9.0 — GAME EXPERIENCE REFINEMENT。ローカル実装・検証のみ。commit/push/Pages公開なし。

2. **主要ファイル**：src/experience.ts、ux-guidance.ts、experience.css、main.ts、shop.ts、collection.ts、reveal.ts、surface.ts、engine.ts、tool-value.ts、automation.ts、automation-ui.ts、save.ts、dev-ux.ts/model/worker、tests/experience.test.ts、scripts/ux-*、package/lock、dist、READMEとdocs。

3. **初心者案内**：短い次操作ボタン→必要時だけ説明/移動。任意に非表示/設定で復帰。未洗浄・露出・砂・装備・分野解放を実状態で判断。

4. **30分モデル**：100シード×A/B/C/Dの400回。初回購入平均 A 7.41モデル分 (100/100)、B 5.30モデル分 (100/100)、C 9.80モデル分 (100/100)、D 18.61モデル分 (97/100)。設備は全方針未到達。人間の実プレイ時間ではありません。

5. **砂浜**：平行な左右と斜め見下ろし/10層を維持。実除去量に応じた砂粒、露出の光、材質/速度/体力の既存処理を保持。

6. **川底**：保持/投擲/引上げ・張り・進捗・能力不足を維持。観測した理由で再挑戦を案内。作業後に解放済み分野を表示。

7. **河原**：採取→粒径→比重→精密回収を維持。在庫/粒に応じて選別台へ案内し、処理ゲージは実作業に対応。

8. **購入メリット**：短い用途と展開詳細。同じエリア/対象/材料の実処理APIで比較し、条件がない時は算出しない。

9. **装備**：4枠/ワンタップを維持。短縮名、正式名、選択状態、所持一覧折りたたみ。

10. **ショップ**：用途/分野に加え名前・ID・説明検索。根拠ある候補最大3件。日本語変換中は入力欄を保持、確定時に検索。

11. **設備**：投入3手順、原則一枚の詳細。購入不能な設備を直近目標にしない。ライン詳細は既存画面。

12. **発見/洗浄**：未露出・未洗浄の正体を隠し、完了後にR/SR/Jを区別。標準/軽量/なし、短縮/スキップ、固定サイズを保持。

13. **図鑑**：300種/12件ページを維持。最近12種類の初登録を表示。再発見では追加せず、素材なし/読込失敗はSVG。

14. **3分野導線**：FN/荷物/道具共有、解放条件は既存実績。任意移動と現在区画破棄を維持。

15. **経済**：価格/報酬/出現率/道具性能の変更なし。モデルはJ0、二重報酬0 FN。慎重方針の未購入や待ちをそのまま報告。

16. **保存互換**：任意のexperienceと演出設定を追加。旧保存は案内無効で移行、再移行同一。既存台帳・在庫・6ラインを保持、オフライン加算なし。

17. **DEBUG LAB**：UX-01〜20追加、全179件/8タブ。初回ログ、根拠、30分比較、Worker中止、JSON/CSV。通常/テスト保存分離。

18. **自動テスト**：617件成功（581＋36）、失敗0。案内/保存互換/候補/比較/初登録/20シナリオ/4方針/計測終了境界を追加。

19. **既存ブラウザ回帰**：7/7成功。追加で新UI、川底/河原、設備、6ライン、保存・複数タブも成功。

20. **長時間・負荷**：6ライン24ゲーム時間、1002個大量処理、連続供給4332個。キュー最大64、履歴200。保存 177719 → 183599 bytes。

21. **画面幅**：Chrome 320/390/1280、Edge390成功。横はみ出し/固定モーダル/スクロール/タッチ経路を自動確認。

22. **本番除外**：Chrome/Edgeで開発API/強制操作/隠し入口が無効。成果物にUX・比較Worker・LABのデバッグ文字列なし。

23. **ビルド**：TypeScript検査＋Vite成功。JS約389.89kB。

24. **Windows起動**：対象フォルダで npm.cmd run dev -- --port 5176 --strictPort → http://localhost:5176/ 。依存未導入なら npm.cmd ci。公開版確認は npm.cmd run preview。

25. **PC実プレイ**：12項目の5段階評価は未評価。初回購入までの迷い、道具の差、深掘り/引上げ/選別、設備の達成感をユーザー確認待ち。

26. **iPhone Safari**：実機未確認。タッチ・投擲・内部スクロール・ソフトキーボード/IME・Safe Area・復帰・熱/電池を評価表で確認。WebKitも未実施。

27. **既知の問題**：設備購入は30分モデルで未到達。慎重Dの3シードで初回購入未到達。探索モデル/固定操作時間の限界があり、人間の成績や楽しさを保証しません。

28. **0.9.1への引き継ぎ**：ユーザー評価後に、初回購入前の探索/設備までの距離/実機の描画・タッチを優先付け。推測で経済を変更しない。
