# Version 0.4.0 — DEPTH EXPANSION

|層|内部深度|対応例|描画|
|---|---|---|---|
|1|0〜80|素手、熊手、軽量大型熊手|明るい砂|
|2|80〜180|小型・大型スコップ|濃い砂|
|3|180〜280|大型砂用スコップ、移植ごて、ブラシ|茶色|
|4|280〜420|大型採砂スクープB203|湿った濃色|
|5|420〜600|電動砂吸引装置B302の手動操作|締まった暗い砂礫|

通常画面は数値深度を表示せず、穴の底色・壁・影と到達層の説明で伝えます。左右水平、前後だけ遠近感のCanvas 2D表示を維持します。硬い層ほど作業が重くなり、B203/B302は硬い砂への適性を持ちます。範囲・1作業の進み方・体力・損耗が異なります。自分の上限まで達した地点では、それ以上掘らず体力も消費しません。上位道具は同じ穴を続けて掘れます。

## 新区画とお宝

新しい通常砂浜はbeachDepthVersion:1、maskの正規化基準600です。従来の浅いお宝配置・抽選をそのまま保持し、追加で第4層にB007（310〜400）、第5層にB005（470〜580、3%でB009）を各1個配置します。新マスターを増やさず、追加深層からB012を生成しません。従来抽選のB012報酬18000FNは維持します。

B201は従来深度まで、B202/B204/B206は第4層まで、B205は第5層までを探知します。探知機だけで回収・掘削はできません。深い品は地点の掘削が到達し、周囲の露出率も満たした後に見えます。

## 旧セーブの移行

共通保存形式v2を維持し、区画単位のbeachDepthVersionで正規化基準を判別します。マーカーのない旧区画はmask×280のままです。穴の配列を600基準へ再スケールしたり、既存の品を追加生成したりしません。旧区画では新道具も280で止まります。探索場所に「新しい清掃区画から第4・第5層に対応」と案内し、新しく作る区画から600を使います。初回チュートリアルも従来仕様です。

移動時は未採取地形を破棄し、砂袋・砂利袋・洗浄待ち品・図鑑・FN・道具・身体能力・履歴を保持します。川底の回収途中と河原の選別途中は、それぞれ通常の保存経路で保持します。移行だけでお宝・FN・ジャックポットを追加しません。同じ移行を繰り返しても結果が変わらないことを試験します。

未知の区画バージョン、非有限値、範囲外の深度やmaskは拒否します。セーブのキーと本番／開発通常／LABの分離は継続します。

## 確認

自動テストで80/180/280/420/600の上限、同じ穴で持替え、深度550の回収と二重報酬防止、深層保存、旧区画保持、未知形式拒否、色・壁・影を確認。ブラウザでは320/390/1280pxで実タッチにより420→600へ進み、保存・再読込と回収・洗浄を確認します。結果は [TEST_RESULTS](TEST_RESULTS.md)、画像は [第4層](v040-depth-four-390.png)／[第5層](v040-depth-five-390.png)。Safari実機は未確認です。
