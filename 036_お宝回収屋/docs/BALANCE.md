# BALANCE — 0.1.0

## 経済

マスター指定の価格・報酬・出現重みを維持。初回固定6品を保証し、最初の4品で160 FNを確保する。追加区画は無料、未選別砂は手でも処理でき、素手・熊手の上限より深い品を残して次の区画に移動できる。

工程能力の比較用目標は、探知機のみ「探索18・回収6・選別6・運搬10」→6個/分、熊手＋大型スコップ＋ふるい「14・14・12・10」→10個/分。道具は切り替えて使用し、実際の面積・深さ・選別作業を変える。能力値からFNを自動加算しない。実収益は過去60秒の確定報酬のみ。

## モデルの限界

操作モデルは5px相当の作業1回に0.11秒を割り当てる。走査点は道具幅に応じて間引く。即時回収・即時洗浄・すぐに購入する理想操作で、UIを探す時間・演出・持ち替えを計上しない。毎ステップの回復呼出しは短い休止を近似しており、実際の指を置いたままの連続作業より体力面で有利。保有した熊手は購入判定・能力比較に含むが、このボットの掘削は素手／小型／大型スコップ主体。道具セットの10個/分は予測モデルの検証であり人間の実測ではない。

したがってこの結果は進行経路と経済の到達可能性の検証で、実機プレイヤーの所要時間の保証ではない。小型スコップが約2分の目標より早く、通常収益も高め。人間によるプレイを次の調整で優先する。

## 調整履歴

1. 最初の試験は0.65秒/サンプルの低速全面走査で初発見119.6秒、40分以内に探知機未購入97/100。初回区画のランダム追加品にJが混入していたため、無J試験として不十分だった。
2. 時間モデルを0.11秒/サンプルに修正し、全区画のJを除外。初発見24.1秒、未購入0/100。価格・出現重み・報酬の変更なし。
3. 初回の最初のB004だけ深さ25→20。初発見16.2秒へ改善。身体能力の微小効果を反映した最終結果が上表。

将来は休止・洗浄・購入・道具持ち替えの時間を明示的に計上したボットと、実プレイヤー記録を併用する。
