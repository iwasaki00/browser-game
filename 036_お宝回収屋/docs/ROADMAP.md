# 0.3.0から0.4.0への引継ぎ

- iPhone Safari実機で皿の円運動・ドラッグ、Safe Area、LAB内入力、バックグラウンド保存を確認。
- 人間の操作で採取・前処理・選別・精密回収の時間を測り、モデルとの差と道具の購入価値を調整。
- 大量の砂利袋・残渣・工程履歴の長時間保存容量と、まとめて選ぶUIを改善。
- G-C/G-D、将来お宝G009〜G012、電動化・自動供給は未実装。既存の固定個体・二重報酬防止を維持して拡張。
- DEV限定モジュール・専用セーブ・工程計測・シナリオを新機能の検証基盤として継続。

# ROADMAP

## 0.2.0からの引継ぎ

- iPhone Safari実機で投擲・ゆっくりしたドラッグ・Safe Area・LAB入力とスクロールを検証。
- 人間の探索で小型磁石／フックの役割と重量操作感、100シードのモデル時間との差を計測。
- DEBUG LABは今後も共通基盤として利用。長時間の収益・回収履歴を圧縮し、ログ出力と新エリアシナリオを追加。
- R-C/R-D、河原の追加エリア、砂浜追加道具、正式素材は別バージョンで実装。



## 0.1.3からの引継ぎ

- Safari実機で洗浄アニメーション、内部スクロール、Safe Areaと連打操作を検証。
- 事前探知・深さ・反応特性を利用する人間の探索パターンを計測。
- ID別サイズプロファイルと固定損耗量の初期ルールを、将来の材質・重量マスターへ統合。
- 長時間での探知跡・残渣・実測履歴の描画と保存容量を計測。


## 0.1.2からの引継ぎ

- Safari実機で水平投影・道具追従・手応えとアイコンの非重複を確認。
- 長時間プレイでセルごとの深い穴の描画速度と色の判別性を計測。
- 手応えの確率・抑制間隔は実プレイで調整し、探知機の役割を残す。
- 深度判定と描画の基準を共通化し、将来の道具追加でも同じ穴を掘り足すテストを継続。

## 0.1.1からの引継ぎ

- Safari実機でSVGカーソル・タッチ中表示・上部通知・背景復帰を確認。
- 平面になった砂浜の探索密度と実プレイヤーの進行時間を計測。
- 旧断面データから変換した平面の掘削痕について追加の実セーブを検証。
- 長時間運用時の穴の輪郭描画・未処理砂の蓄積を計測。

## Phase Aの継続調整

- iPhone Safari実機でドラッグ・Safe Area・バックグラウンド保存・復元を検証。
- 人間による10～25分のプレイ計測で初期スコップ購入時間と通常収益を再調整。
- 工程別の実測処理速度と予測能力の比較を拡充。
- 長時間セーブの区画アーカイブと履歴圧縮、保存容量の実機検証。
