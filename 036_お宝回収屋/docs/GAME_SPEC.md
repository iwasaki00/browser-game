# GAME_SPEC — 0.1.0

## 実装範囲

タイトル、B-A断面探索、セル掘削、露出回収、砂バッチ採取・手選別・ふるい、洗浄・正体判明・依頼返却、FN、5道具、4装備枠、体力・身体能力、ジャックポット、36種図鑑、収益・購入前後レポート、無料区画追加・再訪、保存復元、開発用テスト。

論理サイズ360×280、36×28セル。空気に接する上方向のセルが80%以上除去されたセルだけ掘削可能。同一操作で多層を飛び越えない。露出率55%以上で回収可能。入力は5論理px間隔に再標本化し、描画フレームから作業量を分離。タップでは掘れない。描画には軽量な飛散粒子だけを使う。

解放は仕様のOR条件を実装（B201は回収20個の経路を採用）。前提道具の購入は不要。道具効果は実際の掘削幅・深さ、選別個数、探知という操作差。連携による固定収益倍率はない。

C01は表層探索→砂選別、C16は熊手→深層大量採取→砂選別で機能。C02も定義・汎用判定済みだがB108がcatalogOnlyのため通常プレイでは未成立。他13連携は将来定義。

## 個体・区画・収益

区画はシード付きで10～14個を配置。初回6個は指定IDと固定収入。最初のボルトは深さ20、残る固定品は25/45に置き、発見目標を調整。位置は再読込で再抽選しない。

個体状態はburied→batchまたはstored→paid。掘削・ふるいは同じUIDを参照。スコップは小物B001～B004を砂バッチに移し、他の品は直接回収。バッチは個体のリストで、砂を再選別して生成・再抽選しない。保管容量24。容量不足時の砂バッチの残りは保持。

通常B-AにはB001～B005/B007。特別依頼としてB009/B011/B012。候補のあるレア度を65/25/8/1.8/0.2で正規化して区画生成時に抽選。初回の追加4～8個にも低確率の依頼品があり、序盤の大当たりを可能にしている。

評価額と収入は別。品質は図鑑最高評価に使用、報酬はマスター固定。B012は評価70000、依頼返却で18000 FN。洗浄ボタンで砂落とし→正体判明→返却・報酬を1回確定。通常品の長い強制演出はなく、設定で短縮可能。

## 身体能力

初期体力100、3能力Lv1。非作業時毎秒5回復。0でも半分の掘削量で続行。経験値120をレベル単位として、筋力は掘削量に最大15%の微増、観察は探知範囲に最大15pxの微増、器用さはふるい選別上限に最大2個の微増。作業経験で最大体力も増加。主役の道具差を上回らない。

## 保存

IndexedDBの1トランザクションで全状態を置換。購入・報酬・移動直後、5秒ごと、非アクティブ化時に保存。localStorageの即時バックアップとpagehide保存を併用し、新しい更新日時を優先して復元。キューで古い書込が新しい書込を追い越さない。失敗時に画面へ通知。形式移行関数、破損・未知の将来バージョンの検出を実装。読込失敗時は自動上書きせず開始を止める。

開発キーfinders-dev-v1、本番キーfinders-v1。オフライン進行なし。通常セーブにはマスター名称・価格をコピーしない。

## 合理的補完・制限

- 素手でも砂バッチを1個ずつ手選別可能として、ふるい未購入時の詰みを回避。
- 清掃・回収報酬は洗浄確認の時点で確定。依頼も同画面で返却し、別の所有物売買は設けない。
- 探知機の特別実績による解放は将来枠。通常は回収20個で確実に解放。
- 工程能力は装備に基づく比較用の予測。実際の収益はプレイヤーの操作と個体報酬から集計し、予測値でFNを生成しない。直接回収では選別工程を省略。
- 保管容量と未処理砂が運搬・選別の負担。将来バケツ等で運搬を拡張する。
- 完成画像、川底・河原操作、設備・自動化、ランキング等は今回の対象外。
