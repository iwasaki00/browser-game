## 素手から始めるお宝探し

「お宝回収屋 — THE FINDERS」は、掘る・引き上げる・洗うを繰り返して道具を揃える探索ゲームです。3つの分野、12エリア、300種類のお宝を楽しめます。通貨FNはゲーム内だけの架空通貨です。

- **砂浜**：砂をなぞって掘り、深い地層へ。道具を替えると得意な硬さや掘れる範囲が変わります。採取した砂は選別し、お宝を洗って正体を確かめましょう。
- **川底**：岸辺でつかむ操作から、磁石やフックを使った回収へ。磁石につかない物や、重くて引き上げられない物には、別の道具と組み合わせを試してください。
- **河原**：砂利を集め、ふるい・皿・水流で粒を分けます。最後の小さな粒は自分の手で確かめて回収できます。

## 道具と設備で作業を育てる

回収報酬で46種類の使用可能道具を揃え、4枠へ装備。手作業に慣れたら電動ふるい・電動ウインチ・電動砂利搬送機へ作業を任せられます。最大6ライン、設備Lv1〜Lv3。材料不足や処理待ちを見ながら工程を改善しましょう。探索や洗浄、最後の精密回収には自分で操作する役割が残ります。

## 図鑑とセーブ

初めて洗ったお宝は図鑑へ。検索や分野の絞り込みで発見を振り返れます。進行はブラウザへ保存され、JSONファイルとして退避・復元できます。復元は内容を確認してから承認します。ブラウザや端末を替えるときはJSONを使って移行してください。

## 動作環境・制約

WindowsのChrome/Edgeで確認。iPhone Safariは0.9.2についてユーザーから実機受入OKとの申告を記録しました。機種・iOS・測定ログは未提供で、Codex自身による実機操作は行っていません。

ブラウザを閉じている間やタブが非表示の間の設備収益はありません。再読込後の設備は停止から再開します。同じ保存領域を複数タブで開く場合、進行するタブは1つです。サイトデータを消すと保存を失うため、JSONを退避してください。現在のお宝表示はSVG仮画像です。

今回、新しい道具やお宝の追加、価格や出現率の調整はしていません。正式公開は素材の配布許諾と最終確認の完了後に判断します。
