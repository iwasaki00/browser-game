# Version 0.6.0 — LINE BALANCE

## 条件

シード6000〜6099、3分野×A手作業/B個別設備/C接続ライン/D道具と運搬・整理を改善したライン＝1,200試行。各900秒（15モデル分）、初期100,000 FN、同じ初期能力・区画。必要道具と設備は実価格で購入する。Dの追加道具費も含む。初期回収実績20件相当を設定してエリア・購入条件を満たす。

採取・探索移動を継続し、精密回収と洗浄も通常処理で実施。固定個体・品質・報酬を使用し、隠れた価値を探索方針に使わない。砂浜は規則的な走査、川底は影を指定して公開失敗理由から一度フックを試す、河原は輪を採取する。未処理在庫が大きくなった場合は未予約材料を手動処理する。Aは新設備なし。河原の既存G203スルースの水流進行はAでも維持するため、全工程を指で逐次実行する比較ではない。

これは固定操作時間を用いたモデルであり、人間のプレイ時間ではない。操作時間・個別試行・トレース・道具構成は[機械可読結果](line-results-v060.json)。

## 操作とボトルネック

砂浜C/Dでは、空いた時間に採取を増やす方針のため総操作数はAより増える。同じ100材料単位あたりの操作はA約70.7、C約57.5、D約52.4へ減る。固定出力の作業量削減と、固定時間内の総操作数は別の指標。Dでは搬送・選別の改善で末尾の未処理砂も減る。

川底Cは総操作を約31.0%減らすが、整理工程と能力制限によりFN/分は手動より低い。Dでは強力磁石・滑車・フック・整理補助によって重量物と整理工程を改善し、FN/分が手動を上回る。

河原C/Dは総操作を約24.7%/25.7%削減。搬送だけを速くしても粒径・比重・手動精密回収が滞留する。段階別の稼働率・在庫・判定理由をJSONに保持。表示の推奨は通常画面の実測窓に基づき、最遅公称能力だけでは断定しない。

## 購入可能性と限界

1,200試行すべてで対象構成の道具・設備購入に成功、ジャックポット0、進行停止判定0（このモデルでは獲得FNが0かつ95%以上が待機の試行を停止と定義）。初期資金100,000 FNの比較なので、ここからゼロ資金での初回設備購入時間は導けない。既存価格・報酬を維持したv0.5.0の別購入ルート100シードでは、ゼロ資金からB/R/G各100件すべて購入、Jなし、平均96.9/115.2/182.1モデル分だった（[旧購入試験](automation-results-v050.json)）。これは本版でゼロ資金購入ルートを再計測した値ではない。

実際の人間の操作、Safari実機、長い期間の収益定常性は未計測。通常ゲームの価格は今回変更していない。

## 長時間と今後

3分野同時の24ゲーム時間、毎時保存復元24回、履歴200件上限、最大保存約144kBで整合性を維持。[負荷結果](line-stress-v060.json)。キュー64件、出力満杯、途中停止、二重報酬、非表示停止は別の自動試験でも確認。

次版では人間の操作時間で方針を検証し、川底の整理速度・手動の一括処理・入力過多時の案内を調整する。収益だけでなく操作あたり処理量と在庫残を比較する。
