# Version 0.9.0 — GAME EXPERIENCE REFINEMENT

## 調査と今回の範囲
既存は開始→砂浜で掘削→光る◇をタップ→洗浄でFN→回収2個でB101解放（150 FN）→砂採取/手選別・B104→新しい区画/エリア→設備→ライン。川底や河原の開放は既存の回収実績で判定します。解放と購入できる所持FNは別条件です。3分野のFN・道具・荷物は共有し、区画の地形だけを破棄します。

従来の課題は、常設の次操作がない、ショップの長い説明から用途を探す、クイックの長い名前が切れる、設備詳細が同時に開く、図鑑の初登録を見落とす点でした。砂浜/川底/河原の実作業API、洗浄固定モーダル、上部通知、Safe Area、保存台帳を再利用しています。

## 遊び方
次の行動ボタンは操作を強制しません。光る◇を拾い、洗浄してFNを確定します。未洗浄品は正体/評価/報酬が未判明のままです。購入後はクイックをタップして持ち替え、ショップの詳細で現在装備と同条件を比較できます。深層は新しい清掃区画から探索します。

川底では影を選択し、長押し/手前へのドラッグで回収。ロープ磁石はスワイプで投擲します。重量/磁性/障害物/距離の制約と再挑戦を維持し、観測した失敗理由から装備の見直しを案内します。河原は輪で採取→選別台→粒の精密回収→洗浄。砂利や回収可能な粒の在庫に応じて選別台へ案内します。FNは全分野で共有されます。

## 比較の根拠
砂浜は同じエリア・表面・厚み・現在の筋力/低体力補正で実掘削速度を比較。現在深度の詳細比較は装備画面で維持します。川底は保持/観測した同一対象、河原は同一袋で実処理APIの時間/量を表示。条件がない時は比較不可の説明だけを表示。荷重・未露出品の価値・レア度を見て購入候補を決めません。

## 演出と整合性
実際の除去砂量に応じた砂粒、穴の陰影、川底の進捗/張り、河原の処理ゲージを維持。露出した発見物の光と洗浄完了時にR/SR/Jの違いを表現。演出設定は報酬・品質・回収判定に影響しません。画像がない品はSVG、読込み失敗時もSVGへ置換します。画像300枚の生成や追加ダウンロードはありません。

## 保存と計測
experienceは最大11初回イベントと最近12種類。クリック、選択変更、キャンバスの接触開始を操作数とし、保持中のpointermoveを操作数として水増ししません。初回の層進入、道具購入、持ち替え、エリア解放、設備購入、実処理開始も記録。時刻は既存のゲーム時間で、外部送信はありません。旧保存は案内無効で移行し、設定から再表示可能。設定/情報追加のみで台帳/材料の形式変更はありません。

## 残る課題
初回購入時刻は探索方法に強く依存します。モデルで設備購入まで30分以内に到達しておらず、設備への成長導線は長時間の人間評価が必要です。実機Safari・操作の楽しさ・音/触覚の満足度は未確認。評価表へ記入後に0.9.1の調整を決めます。

川底・河原でも、保持中や未処理在庫を先に案内した後、未訪問の解放済み分野へ案内します。設備は前提・解放・資金がそろった場合だけ直近目標にします。ショップ検索は日本語変換中の要素を保持し、確定後に更新、途中のカーソル位置を戻します。
