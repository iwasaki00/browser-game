# SURFACE VIEW UPDATE — 0.1.1

## 変更の要点

1. 横からの断面表示を廃止し、台形に投影した砂浜表面へ変更。
2. 深さの数値を探索・道具説明から撤去。穴の壁・影・縁で表現。
3. 道具ごとに異なる6つのSVGカーソル。タッチ中は指の上に半透明表示。
4. 通知を砂浜の上部へ移動。4秒消去・タップ消去、固定操作ガイドとは分離。
5. 現区画のみ保持。古い地形は破棄し、回収品と採取済み砂は保持。
6. 旧セーブは資金・道具・図鑑を保持した形式v2に自動移行。

`surface.ts`が投影・逆変換・輪郭・アイコン、`main.ts`が入力と通知、`engine.ts`が平面掘削と区画運用、`save.ts`が形式移行を担当。

## 検証と制限

22件のロジック試験、Chromeの320×568・390×844・1280×900で実際のマウス・タッチイベントを使うUI試験。本番Chrome/Edgeも別途実行。画像はsurface-clean、surface-holes、touch-tool各PNG。Safari実機は未検証。

旧断面マスクの換算後の見た目は旧版と同一にはならない。既に露出した品の回収可否、資金、図鑑、道具、荷物の保持を優先する。大型連結穴の見た目・速度や、平面探索になった後の人間の進行時間は継続調整する。料金・オンライン処理は追加しない。
