## 起動とセーブの準備

1. 最初に既存セーブを「セーブ保護・バックアップ」でJSONへ退避。テストには別環境を推奨。開発/本番は保存キーが別。SafariはChromeの保存を自動共有しません。
2. PCとiPhoneを同じ信頼できるLANへ接続。WindowsのPowerShellで次を実行。

~~~powershell
Set-Location -LiteralPath "C:\_wk\github\browser-game\036_お宝回収屋"
npm.cmd run dev -- --host 0.0.0.0 --port 5176 --strictPort
~~~

3. 2026-11-12に確認したPCのWi-Fi IPv4は **192.168.3.17**。iPhone Safariで **http://192.168.3.17:5176/** を開く。DHCPで変わった場合はPCのipconfigで再確認。PCからiPhoneへの接続確認やFirewall設定変更は実施していません。
4. 接続できない場合は同じLAN/ゲストWi-Fi分離/PCのIP/サーバー稼働を確認。Firewallが必要ならPrivateネットワーク・TCP5176・自分のLAN/端末だけに限定し、Public許可やルーターのポート転送は行わない。試験で追加した許可は試験後に戻す。
5. 下表へOK/NG/未確認と再現条件を記入。既存データを置換する復元は退避JSONを確認してから承認。ファイルを選択しただけでは書き換わりません。
6. 試験後はPCのサーバー端末で **Ctrl+C**。今回の自動試験用サーバーも作業完了時に停止。
