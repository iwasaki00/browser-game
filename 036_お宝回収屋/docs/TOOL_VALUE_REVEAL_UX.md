# TOOL VALUE & REVEAL UX — Version 0.1.3

## 現行調査と修正

0.1.2の探知機は金属からの距離を数字で返すだけで、跡や回収方法の品質差はなかった。選別はボタンの意味が所有道具で自動的に切り替わり、括弧内は砂量ではなく未処理バッチ数だった。洗浄はひし形の発光と即時の画面置換で、汚れの除去アニメーションは存在しなかった。

今回、探知情報・品質・選別状態を `tool-value.ts`、洗浄画面を `reveal.ts` に分離した。価格・通常報酬・時計18000 FN・36お宝・126道具・C01/C16・1区画運用は維持。

## 探知機

- 実在する埋没個体の距離・サイズ初期プロファイル・金属判定・深さから反応を計算。
- 弱／中／強、浅そう／深そう、反応の特徴を表示。大きな安いボルトも強く反応し、品名・レア度・評価額は表示しない。
- 探知位置は40pxの粗い区画へ丸める。同じ個体の反応は最も強い粗い地点へまとめ、画面を跡で埋め尽くさない。
- 跡は持替え・再読込後も残り、回収または区画破棄で表示対象から外れる。再走査で個体を再抽選しない。
- 位置を十分近くで把握してから掘ると損耗が減る。初期品質は増加しない。

初期品質を基準に、大型の損耗は未探知8%・事前探知2%、小型は1%・0%、素手は1.5%・0.5%、熊手は3%・0.5%。初めて露出したときに一度だけ確定する。既存の傷は戻さず、掘った後からの探知や持替えでも再補正しない。損耗量を固定率で近似する初期ルールで、確率で価値を増やすものではない。既存の未洗浄品や砂内個体の旧品質も保持。

評価額にのみ品質を反映し、実際のFNは従来通り。丁寧回収ボーナスは今回は追加していない。

## 手選別と砂ふるい

手選別は最初から3単位／作業・所要体力6。B104購入後は15単位／作業・所要体力4のふるいを選択可能。両方を並べ、残量0なら無効表示。複数の小バッチも1回の上限までまとめて処理する。

砂バッチの個体UIDは採取時に確定。手選別では小物を残渣へ残し、次の手作業またはふるいで再処理できる。砂の未通過量と残渣量を別に保存し、区画移動後も保持する。再選別は同じ個体を参照し、再抽選・無限生成・二重報酬なし。手選別だけでも進行可能。

残渣を再び通す分は作業量に含まれる。比較で150単位の原砂に対して手作業153単位となるのは再処理3単位のためで、砂が増えたものではない。

## 洗浄

「砂まみれの小物」→洗浄中→正体判明→報酬・図鑑登録を同一画面で表す。「洗う」は約1.4秒、短縮設定なら350ms。「スキップ」はアニメーションだけを省き、同じ個体・品質・報酬へ進む。

キャップ・釣り針・ボルト・リング・メダル・時計等のSVGに汚れレイヤーを重ね、徐々に透明化し、砂粒が落ちる。洗浄前は本名・レア度・品質・評価・報酬を表示しない。

モーダル・タイトル・お宝表示・ボタンの領域は段階ごとに作り直さず、固定領域の中身を更新する。Safe Areaと画面高に応じた高さ上限を設け、情報部分だけスクロールできる。主要ボタンは下部に保持。閉じるとタイマーを破棄し、洗浄待ちを残す。完了時だけ既存のpaid状態とUIDで報酬を確定・保存する。

## 第3層

深掘り計算と水平投影は変更していない。同じ穴が素手80→小型180→大型280まで進み、床色が明確に暗くなることと、深度245の品を回収して洗浄できることを再確認。各段階で保存・再読込成功。数値は通常UIに表示しない。

## 比較と制限

100シードの道具比較では約6個回収に必要な有効掘削が未探知296.11回、探知43.82回。探知側は別途63回の走査を含む。品質保持率92%対97.33%。探索動作のモデルであり、実機プレイヤーの時間や因果効果を保証しない。

同じ150単位・6個体は手選別51回、ふるい10回。通常進行100シードは全件到達し、通常451.8 FN/分と探知機購入1720.1モデル秒は前版と同じ。自然抽選の別試験100区画では時計4個。進行試験は大当たりを除外している。

Safari実機、長時間の大量の探知跡・残渣・履歴、個別端末での色と演出の感触は継続確認事項。commit・push・公開は実施していない。
