# Version 0.8.1 — 道具の掘削性能

最大深度と速度は別管理。素手80、小型B101＝180、大型B105＝280、深掘りB203＝420、B302＝600を維持。B107精密ごては280。その他は既存beachProfilesの上限を使用する。

速度は内部深度/秒。層硬度・エリア硬度・石・深部環境・体力・筋力で補正する。装備画面は現在地点での実モデルの速度と同じ厚さの所要時間、到達層、適性、体力、精密特性を比較。4装備スロットは維持。

精密ごては狭い範囲・低い体力負荷・品質維持に向く。大型は広く速いが既存の品質損傷を維持。ブラシB106は露出直前の対象周辺12以内の薄層だけを8/秒で清掃し、280を超えない。探知機・ふるい・回収トング・運搬具に掘削能力を追加しない。
