# Version 0.9.1 — STABILITY & FINAL POLISH

## 形式と互換

既存saveVersion=2、IndexedDBのsaves/current、localStorageバックアップを継続。公開はfinders-v1、開発はfinders-dev-v1、LABはfinders-debug-v1。正規化mask・個体ID・台帳・材料・6ライン・設備ID/Lvを維持。新たな保存領域や経済方式は追加していません。旧断面/任意項目はmigrateで移行。必須のFN・能力・所持品・図鑑・区画が欠けたデータは初期値で補わず拒否します。

## 保存と障害時

開始時点のスナップショットを検証し、IDBトランザクション内でrevisionと進行権を比較。主保存を確定してから端末バックアップを更新します。新しい緊急バックアップを古いキュー処理が上書きしないよう連番を比較。競合や全データ復元失敗では書込/緊急保存を保護します。

片方だけ正常な場合は正常データを選び、復元元と異常を表示します。読取りだけでは保存を変更せず、再開はユーザー操作です。両方異常なら開始を止め、元データ退避と復元を案内。容量/保存禁止/構文エラーの対応を表示。主保存のみ成功した場合はバックアップ注意として表示し、主保存失敗と区別します。

## JSONバックアップ

設定とタイトルのセーブ保護から端末内JSON保存。復元は20MB以下のファイルを検証→FN/道具/図鑑/区画を表示→確認ダイアログ→主保存確定→状態切替。検証失敗・キャンセル・書込例外では既存データを変更しません。インポート中は作業を停止し、成功後も設備停止状態で手動再開します。読込み不能データの退避ファイルは主保存とバックアップ原文を含む調査用で、通常セーブJSONとは区別します。外部送信なし。
