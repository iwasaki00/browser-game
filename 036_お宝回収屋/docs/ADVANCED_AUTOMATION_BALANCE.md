# Version 0.8.0 — ADVANCED AUTOMATION BALANCE

## 比較条件

100シード（8000〜8099）×3分野×5構成×少量/大量＝3000試行。少量1袋15単位（川底1対象）、大量20袋300単位（川底20対象）。同一シード・個体・品質・抵抗/粗粒率・道具で比較し、Jなし。材料準備済み・設備付与による性能比較で、同一資金制約の比較ではない。時間は固定操作モデルで、人間の実プレイ時間ではない。

最大300モデル秒。洗浄1.4秒、通常の選別・巻取り・精密回収APIを使用。初期の対象登録と設備準備は操作数に計上し、初期設定の所要時間と採取時間は性能比較から除外する。材料は有限で、未処理量を保持する。

## 購入までの資金モデル

別途100シード×3分野で初期エリアの採取を含む120秒の基本道具モデルを計測し、その通常FN/分が反復して得られると仮定して価格÷FN/分を計算。初期設備資金ゼロ・基本道具準備済みで、解放待ち・購入順・区画変化は含めない。購入到達まで直接進めた実測ではなく線形試算。

|---|---:|---:|
|B|380.8|152.3|

ジャックポットを使わず通常収益で積み上げるモデル。低収益条件では長く、持込FNで時間は変わる。

## 待ち・稼働・負荷

JSONにライン/個体ID、レベル、道具、工程、在庫、稼働率、材料待ち秒、出力待ち秒、滞留根拠を収録。ライン別時間の合算は二台の場合に経過時間を超え得る。

1002対象を全件回収、確定後466091 bytes、約109.5秒。6ライン24ゲーム時間・毎時保存復元24回。毎分、試験側で完了参照を整理（通常の区画切替に相当）し、途中/未受取を残して材料/指定対象を供給し4332件処理。保存175651〜182209 bytes、履歴200、キュー最大64、非表示進行なし。試験全体約213.1秒で実行したモデルで、実機24時間放置ではない。

Node.js heapの毎時サンプルは約24.1〜108.8MiB。GCを含むプロセス計測で、ブラウザ/iPhoneのメモリ測定ではない。実機メモリは未測定。
