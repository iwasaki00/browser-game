# Version 0.2.0 — RIVER RECOVERY & DEBUG LAB

## 川底を遊ぶ

探索場所から「岸辺の浅瀬 R-A」「石だまり R-B」へ移動できます。解放条件は砂浜の累計回収報酬受取数で、それぞれ10個、20個です。旧セーブの図鑑に記録された発見回数も直ちに判定します。R-C/R-Dと河原は準備中です。

初めて川底へ入ると素手を選択します。FN、身体能力、所有道具、未洗浄品、未処理砂、図鑑、依頼履歴は共通です。区画移動で前の地形を破棄します。各川底区画に素手で回収できる軽量物を6個確保しており、新区画は無料です。

岸辺近くの輪郭をタップ・クリックしてつかみ、手前へドラッグします。指を離しても進捗は残ります。再び手前へ引くか、探索面内の「手前へ引く」を押して続行できます。磁石に付いた物の名称は引き上げ・洗浄後に判明します。

ロープ付き磁石は、岸から狙う水底へスワイプ・ドラッグし、離して投げます。終点が方向と距離を指定します。短すぎる操作では投げません。到達上限で距離を制限し、飛行・着水・吸着・巻取り・引き上げを簡易表示します。精密なロープ物理は使用しません。

水面、波紋、石、水草、水深による霞、水平な岸辺をCanvas 2Dで描画します。砂浜と同じ前後方向の遠近投影を使います。通常画面には深さや乱数シードを表示しません。

## 道具と判定

|道具|価格FN|できるようになる作業|
|---|---:|---|
|R101 回収トング|180|素手より遠くの小物をつかむ。選択範囲と重量上限も改善|
|R106 回収フック|470|岩の隙間や真鍮など、磁石が使えない場所・対象を引く|
|R103 小型磁石|520|近距離の鉄に吸着。2.7kgの鉄製チェーンはトング・フックから持ち替える効果を確認可能|
|R104 ロープ付き磁石|900|遠くへ磁石を投擲・巻取り|
|R110 ロープ巻取り器|1,800|対応する磁石・ロープを装備した作業の巻取り速度2.6倍|
|R201 強力ネオジム磁石|4,500|重い鉄に吸着。R104を装備すると遠距離でも使用可能|
|R206 滑車セット|7,200|強力磁石＋ロープを装備した重量物の引き上げ|

補助道具は装備画面で枠に入れておき、作業する磁石を選んで使用します。R110/R206を単独選択しても回収しません。所持だけではセット効果は発動しません。

距離、岩の障害、材質由来の磁性、吸着力、引き上げ能力を別々に判定します。鉄は磁性あり、真鍮・アルミ・金は磁性なしです。DEBUG LABの個体別磁性指定だけは検証用の上書きを許可します。

基準の引き上げ能力は素手0.75kg、トング2kg、フック2.2kg、通常磁石3kg、強力磁石8kg、適切な滑車構成22kg。筋力の補正は最大25%です。磁石の吸着上限は小型3kg、ロープ型4kg、強力18kg。距離は内部座標で素手55、トング130、フック210、近距離磁石105、ロープ265です。

C05はR104＋R110を実際に使う磁石の巻取りで適用します。吸着力は変えません。C06はR201＋R206にロープR104も備えた磁気回収で適用します。フック作業に磁石の効果を適用しません。重量物は回収対象が増える一方、引く量・操作回数が増えます。低体力では速度が半減します。

能力不足の個体を削除・再抽選しません。同じ区画で道具を替えて再挑戦できます。満杯時も個体と進捗を維持します。個体ID、材質、重量、磁性、難易度、初期品質、品質低下、損傷状態、評価額、獲得FN、回収状態を既存保存に統合しています。評価額は品質×マスター価値、実際のFNは固定清掃・契約報酬です。工具箱・真鍮バルブ等は依頼返却処理を使用します。

通常の川底出現対象はR001〜R007とR009。R008、R010〜R012はマスター・開発生成に残します。お宝36種、道具126種を維持し、動作可能な道具は砂浜5種＋川底7種です。

## DEBUG LABの開き方

1. `npm.cmd run dev` で開発サーバーを起動してゲームを開始します。
2. 設定・ヘルプを開き、下端の `VERSION 0.2.0` を素早く5回タップ・クリックします。
3. 通常状態を退避し、専用のテスト状態へ切り替わります。画面上部に `DEBUG TEST` と表示します。
4. パネルを閉じるとテスト状態の探索を操作できます。同じ操作で再び開けます。
5. 「通常プレイへ戻る」で退避した状態へ戻ります。リロード時も通常プレイを読み込みます。

|タブ|操作|
|---|---|
|状態|FN変更・追加、100/1,000/10,000/100,000のプリセット、体力・最大体力、筋力・観察力・器用さ、能力初期化|
|道具|個別付与・全実装道具付与、装備切替、条件無視、全126マスターと性能、所有・販売商品、組み合わせ候補と作業時能力|
|お宝|全36マスターから位置・深さ・重量・品質・レア度・磁性・状態を指定して生成|
|探索|区画・シード、お宝ID・重量・磁性・回収判定、砂浜深度、道具・探知・磁石・ロープ範囲、座標の個別表示|
|シナリオ|軽量品、トング、岩の隙間、鉄、真鍮、弱い磁石、短いロープ、重量不足、強力磁石、滑車の10例|
|収益|FN、累計、直近FN/分、エリア別・お宝別収益、成功率、使用回数、平均操作、失敗理由、ボトルネック、ジャックポット履歴。1秒ごとに更新|
|保存・ログ|セーブ確認、指定シード再生成、状態の記録・復元、テスト初期化、保存・読込、JSONコピー、直近100イベント|

タブは横スクロール、内容は縦スクロールに対応します。パネル内の入力・タッチは背後の探索へ伝えません。初期化、復元、地形破棄には確認を表示します。未実装道具は性能・マスター確認のみで、付与・装備しません。

強制生成でも固有IDと通常の品質・報酬処理を使用します。回収済み・支払済み指定も、通常の保管・報酬処理を経由するため二重払いを防ぎます。シナリオ操作は現在のテスト区画を入れ替えます。座標はパネル内に表示します。ロープが短い例は到達不能の位置に置くため、失敗後に新しい区画へ進むか別シナリオを選びます。

## 保存と本番版の分離

|用途|IndexedDB／localStorage識別子|
|---|---|
|公開・プレビュー通常プレイ|`finders-v1`（従来と同じ）|
|開発サーバー通常プレイ|`finders-dev-v1`（従来と同じ）|
|DEBUG LAB|`finders-debug-v1`|

保存キューの開始時にキーと状態のコピーを固定するため、切替中の非同期保存も別領域へ書き込みません。DEBUG LABは通常セーブを初期化する操作を提供しません。保存形式v2に任意フィールドを追加し、旧砂浜の深度・品質・荷物・残渣はそのまま維持します。川底で引き寄せ途中の進捗も保存します。

`import.meta.env.DEV` 内の動的importでのみ `dev.ts`、`dev-actions.ts`、`dev.css` を読み込みます。本番成果物にFN強制変更・生成操作・LABタブ・専用保存キーを含めないことを検証します。本番で専用セーブのAPIを要求しても拒否します。隠し操作だけに依存しません。

## 検証と制約

単体試験、実タッチイベントによるChromeの320×568／390×844／1280×900検証、Chrome／Edgeの本番検証、100シード進行・装備比較を実施します。結果は [TEST_RESULTS](TEST_RESULTS.md)、[BALANCE](BALANCE.md) と各v020 JSONへ保存します。

iPhone Safari実機は未確認です。縦画面での掴み・ゆっくりしたドラッグ・スワイプ投擲、アイコンと指の非重複、長押しメニュー、ダブルタップ、Safe Area、キーボード表示時のLAB入力、内部スクロール、バックグラウンド保存を確認してください。

物理は簡略化しています。影の選択精度、重さの操作感、100シードのモデル時間と人間のプレイ時間の差、長時間ログ・履歴の保存容量は次版でも調整します。R-C/R-D、河原、砂浜追加道具は未実装です。commit・push・公開は行いません。
