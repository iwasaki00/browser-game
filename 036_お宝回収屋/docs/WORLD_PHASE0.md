# Version 0.7.0 Phase 0 調査

実装前の基準は0.6.0。既存お宝36品（下表）、道具126マスター、使用可能46道具、B301電動ふるい25,000FN/R301電動ウインチ30,000FN/G304電動砂利搬送機48,000FN。利用可能エリアはB-A/R-A/R-B/G-A/G-Bの5つ。B-Bも未実装のため、12エリア達成には7エリアを追加開放する。既存12エリアの名前とIDを優先。

お宝の既存属性はdata.tsでmaster-source.jsonから組立。砂浜はC65/U25/R8/SR1.8/J0.2のレア度先行抽選だが、一部旧品は出現対象外。川底は軽量6個＋地域別8個。河原は8地点×3個、G-Bの特別地点は区画単位2.5%（noJackpotで抑止）。既存のFNはincome固定表、評価額とは別。B012だけ18000FNと台帳のJ判定を持つ。新データの評価をそのまま収入へ流用しない。

図鑑は種類ID→count/first/best/locations/tools。現在は36件全描画、名前は未発見時に隠す。保存済み個体はFind、砂はBatch.allocations/residueWork、砂利はGravelBatch.contents/goldAllocation/captureRankで固定。報酬台帳は履歴と分離され、v6単調増加個体UIDと未決済資格を保持。セーブはsaveVersion2、IDB単一書込タブとスナップショット/CASを維持する。

設備はAutoJobに元袋/個体を予約。64件上限、出力上限、再読込停止、非表示進行なし。0.6.0では袋全量が工程間容量に収まる前提があり、部分投入は未実装。今回ここを作業区間と供給済み上限で改善する。

DEBUG LABは8タブ、44通常＋15AUTO＋20LINE。DEV動的importと別セーブ領域、Worker中止を維持する。基準テスト351件。
