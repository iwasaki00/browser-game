# Version 0.9.0 — GAME EXPERIENCE REFINEMENT

## 条件と限界

初期資金0、Jなし、固定操作時間。人間の実プレイ時間ではない。シード9000〜9099を各4方針、400回×1800モデル秒。実ゲームの時間式掘削/回収/選別/洗浄後の報酬/購入/エリア判定を呼びます。資金・所持道具・能力の付与はありません。Aは次の行動のエリア案内、Bは砂浜に滞在、C/Dは分野を探索します。

見える範囲の固定格子を掘る。Aは案内・新分野、Bは砂浜効率、Cは購入を240秒待って探索、Dは価格の2倍まで貯める。洗浄1.4秒、クリック0.3–3秒、体力8未満で休憩。川底は影の座標のみで選択。未露出のお宝ID・深さ・価値は意思決定に使用しない。 掘削は小さな往復ドラッグを固定格子に沿って行います。これは最適探索ではなく、実プレイヤーの視線・判断・操作習熟・偶発的な大当たりを再現しません。最後の洗浄が時間内に終わらなければ未払いのままです。休憩は実際に進んだモデル秒だけを集計します。

## 調整と引き継ぎ

案内は洗浄・露出・未選別在庫を優先し、川底/河原でも作業後に解放済み分野を案内。買えない設備を直近目標として勧めず、初回スコップでは価格と不足FNを明示します。経済の即時調整は行っていません。設備までの距離、購入前の探索の迷い、休憩の負担は人間評価を待って検討します。
