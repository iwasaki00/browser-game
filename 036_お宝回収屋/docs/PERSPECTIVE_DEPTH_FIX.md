# PERSPECTIVE & DEPTH FIX — Version 0.1.2

## 原因の切り分け

変更前の実エンジンを、同じ探索地点で素手→小型→大型の順に呼び出して確認した。中心の深度は80→180→280となり、最大深度判定・地形の持越し自体は働いていた。

一方、0.1.1の描画はつながった穴全体の平均深度で底色を決め、全体最大深度で壁のずれを決めていた。広い道具で新しい浅いセルが増えると、中心の深掘りが平均に埋もれ、同じ深さに見えやすい。これは地点ごとの掘削状態と見た目の不一致だった。

追加の境界調査では、掘削80に対して埋没80.5の品を露出率の余裕だけで回収できた。こちらはエンジン側の不具合として修正した。記録は `depth-diagnosis-v012.json`。

## 修正

- 投影の画面yから左右x依存のせん断を除去。奥と手前の辺は水平、中心xは固定。逆変換も同じ式から直接計算する。
- 現在深度はmask×280。掘削は `next = min(toolMax, current + stroke)` とし、結果を同じセルへ戻す。道具切替で配列を初期化しない。
- 素手・熊手80、小型180、大型280。探知機・ふるい・未対応IDは掘削上限0。
- 地点の中心が個体の埋没深度へ到達したうえで周囲の露出率を判定。未到達の品は通常描画・回収・採砂へ出さない。
- 床色は各セルの実深度で連続補間。浅い砂→濃い砂→暗い茶色へ移り、壁の高さと影も各セルの深度で変える。お宝は地形の後に描き、手前の壁が不自然に覆わない。

## 素手の手応え

限界付近でさらに操作し、近くの下方に未到達の埋没品があると30%で反応。小さな「コツッ」と「何か手応えが…？」を約1.5秒だけ表示する。通常トーストを使わず、指の上の道具アイコンより下へ出す。

失敗後の同じ穴での再試行は12秒間隔、成功後はその穴で再通知しない。履歴は保存される。無音でも機能し、振動APIは使わない。既に露出した品、回収済み品、遠い品、お宝のない場所、既に素手の限界を超えている穴に特別な反応は出さない。

手応えは地形・配置・品質・体力・収益に影響せず、品名・レア度・正確な深さは明かさない。回収には引き続き適切な道具での掘削が必要。

## セーブ

0.1.1の保存形式v2と同じ深度表現を維持する。現在区画・資金・道具・装備・身体能力・図鑑・履歴・洗浄待ち品・未処理砂・ジャックポット履歴をリセットしない。現在地形の深度は再変換しない。位置・深度を検証し、不正なデータは読み込み失敗として自動上書きを止める。

手応え履歴handFeedbackだけを任意項目として追加。旧セーブは空履歴で読み込み、区画移動時には履歴も破棄。前区画を捨てる1区画運用は維持する。
