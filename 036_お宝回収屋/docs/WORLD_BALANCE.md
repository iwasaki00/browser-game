# Version 0.7.0 — WORLD BALANCE

## 試験条件

100シード（7000〜7099）×12エリア×3構成＝3600試行。別途、同じ3600条件で5個回収までの操作数を計測。各試行は最大120モデル秒、区画は有限で途中再生成しない。固定操作時間によるモデルであり、人間の実プレイ時間ではない。通常収益はジャックポットなし。

比較は基本道具／高性能道具／自動化ライン。全試行の初期FNは100000、同じ能力・シードを使い、必要道具と設備を準備済みにする。購入順序・資金形成までを再現する試験ではない。探索は固定の走査、川底は指定対象への磁石とフック、河原は実際の粒径・比重・精密回収を使用する。個体の中身は再抽選しない。砂浜の既存第5層、最初の浅い一般品、環境抵抗を含む。

## FNと投資

既存36品の評価・レア度・登録エリアと定義済み報酬を維持。以前income未設定のカタログ品は今回の通常回収対応に伴い固定契約報酬を設定した。評価額と支払いは別。新規品は分野とレア度に応じた固定報酬で、全評価額を無条件に支払わない。所有者があり得る品は回収契約として扱う。

設備価格B301=25000、R301=30000、G304=48000 FNは維持。通常収益が全条件で発生し、ジャックポットなしでも資金を積み上げる経路は残る。ただし今回の試験は資金準備済み比較のため、初回設備購入時間・人間の投資回収時間は未計測。前版の継続採取投資比較は[LINE_BALANCE](LINE_BALANCE.md)に履歴として保持し、新エリアの値として転用しない。今回120秒の区画比較から長期投資回収を断定しない。

## 大量データと長時間

強制配置1000個（通常確率の試験ではない）、5回再読込、1000個報酬確定、二重支払いなし。強制混合にはJが含まれるため518696 FNを通常の収益平均に使わない。保存サイズは503277→374193 bytes、詳細履歴200件、計測実行時間6.7秒。

3分野ラインを24ゲーム時間継続、毎時保存復元24回、最大キュー4件、保存サイズ142847〜155379 bytes。非表示24時間相当のtickでも状態不変、移行の二重実行も不変。実行環境の処理時間は41.4秒で、実機24時間放置した測定ではない。
