# Version 0.8.1 — 入力と手応え

押し続けると掘り、ドラッグで掘る場所を動かす。マウスとタッチは共通DigInputを使用。pointermoveは軌跡を記録するだけで、イベント回数では作業しない。20ms固定刻みで時刻付き軌跡を補間し、静止時も進行する。1回の計算で100msを超える経過を捨て、復帰時の大量進行を防ぐ。指を離すと残り20ms未満を確定する。

pointerup / cancel / lostpointercapture / マウスボタン解除 / ウィンドウblur / タブ非表示 / モーダル / 道具・区画変更で停止。複数指は主ポインタだけ処理。ページスクロール・長押しメニューは既存Canvas制御を維持。タッチ中だけ指の上に道具アイコンを表示。

短いタップは露出品の回収。掘削の長押し終了で勝手に回収しない。道具ごとの粒・色・量、300ms以上間隔の短い音、層進捗、限界案内で手応えを返す。粒子は最大70個、設備計算10Hzを維持し、DOMを毎フレーム増やさない。

掘削による採砂量はセルごとの実深度増分/80の合計。道具の上限深度に依存しない。素手・熊手の砂にも量を付けるが、直接露出した個体を勝手に砂袋へ移さない。小物採砂対応の既存道具だけが固定個体を袋へ移す。自動選別で再抽選しない。

旧シナリオ互換の固定作業dig APIは保持。通常のCanvasとDIG計測はdigForTimeを使用。既存砂袋の量は再解釈しない。

再実行：npm.cmd run test:digging-browser。Chrome 320/390/1280px、Edge 1280px、CDP実タッチイベントを使う。Safari実機は未確認。
