# Version 0.8.2 — 川底の道具体験

既存判定を調査：riverStartで対象選択/投擲/吸着、riverCheckで距離・予約・磁性・吸着重量・障害物・引上げ重量を判定し、riverPullで進捗/体力/品質/保管を確定していた。旧UIは移動距離とボタン回数で進行していた。

通常UIはriverWorkへ変更。入力軌跡だけをイベントで記録し、砂浜と共通の20ms作業刻みで長押し/ドラッグする。表示は実session.progressを使い、引上げ開始→水中から移動中→水面付近→保管。回収ボタンは通知が重ならない下の操作列へ配置。マウス/タッチ/blur/非表示/モーダルで停止し途中進捗を保持する。

単体の能力表。ロープR104との実装備で遠距離、R110で速度2.6倍、R201で吸着18kg、R206で引上げ22kgへ拡張。強力磁石単独の引上げは8kgで、吸着力とは別。小型磁石には軽量対象の取扱補正1.25、強力磁石は0.9。重量・難易度・水深抵抗・水流・体力を計算する。ロープ/巻取り/滑車の役割は購入だけでは発生しない。

R301電動ウインチは30,000FNを維持。対象を指定して設備へ登録した作業だけで有効。手動より巻上げ速度が1.8倍、設備Lvの倍率を別に適用。R110と併用でき体力負担は0。強力磁石やフックを持たずに吸着する機能はない。既存R-C/R-Dの重量物構成も維持。

磁性は固定個体/材質属性から判定。真鍮は磁石不可。隙間はフック、カメラで観察したアームなど既存条件を利用する。難易度は保持/移動の抵抗にも反映。精密アーム、カメラ、測定済みフックの既存品質保護は維持する。

能力不足は待っても回収できない。失敗対象は同じ区画に残り、道具を変更して再試行できる。対応道具の案内は判定結果を基に行う。持替えで進捗を削除せず、不適合な道具では停止し元の道具で再開できる。観察していない対象の詳細/価値を装備比較が勝手に推定しない。

既存モデル/回帰用riverPullの固定引き量APIは互換維持。通常操作と新規比較はriverWork、設備も同じ確定処理を使用する。実時間の大量遡及なし。
