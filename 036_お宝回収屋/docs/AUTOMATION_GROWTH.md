# Version 0.8.0 — AUTOMATION GROWTH

成長レポートは設備一覧の「同じ材料で成長を比較」。固定シード8080、砂100単位、25単位袋4個、抵抗1、内容物なしを使い、初期の素手と現在の購入設備・道具を全稼働させた処理能力を比べる。元セーブを変更しない。過去に記録した実プレイ値ではなく、採取・洗浄・FNの比較も含めない。

|1台Lv1|34|1|97.1%|20.4|30.6|

|2台Lv1|34|2|94.1%|20.4|18.0|
|2台Lv3|34|2|94.1%|20.4|15.8|

1台では処理時間が初期手作業より長くても、反復操作を大きく減らせる。2台は材料が複数袋に分かれると並列化できる。同じ大袋の進行区間は二重投入しないため、1袋だけの比較では強化が有利になる。通常画面には操作数と簡単なバー、累計回収・ライン数・購入設備・累計処理を表示し、各工程の能力・滞留はライン詳細で確認する。

お宝を含む性能比較は各分野100シード・5構成・少量/大量、計3000試行。[ADVANCED_AUTOMATION_BALANCE](ADVANCED_AUTOMATION_BALANCE.md)に処理量・FN・操作・投資条件を記録する。高い構成が常に最適とはしない。実際の人間の時間ではない。
