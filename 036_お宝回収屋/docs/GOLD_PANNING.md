# Version 0.3.0 — GOLD PANNING

## 河原へ出かける

「探索場所」からG-Aへ移動します。解放条件は砂浜累計回収20個、または川底累計回収5個です。初回は素手です。G-Bは河原の累計発見10個、またはパンニング完了5回で解放。G-C/G-Dは将来用で、通常プレイでは移動できません。

左右水平、前後だけ遠近感のあるCanvas 2D表示です。小石・砂利・浅い流れのある地点を、指やマウスでかき分けます。タップだけでは採取しません。1区画8地点、各地点18〜24単位の資源を持ち、使い切ると枯渇します。無料で新しい区画へ移動できます。前の地形と未採取品は破棄しますが、採取済みの砂利、未洗浄品、FN、道具、図鑑は持ち越します。

## 道具を買って工程を増やす

|ID|道具|価格FN|使い方・役割|
|---|---|---:|---|
|G101|小型スコップ|150|採取量が素手の1から6単位へ。後工程に大量の砂利を供給|
|G102|パンニング皿|280|実効容量4単位。左右スワイプ・円運動で砂を減らし、微細粒を残す|
|G103|ふるい|600|1回8単位。粗粒を取り除き、皿の投入量・作業量・微細粒の回収率を改善|
|G105|虫眼鏡|300|残った粒を観察し、黄鉄鉱と天然金の違いを推測|
|G110|スポイト型吸引瓶|950|選別済みの微細粒を1操作で回収。素手では細かさに応じて2〜3操作|
|G201|大型パンニング皿|1,900|実効容量14単位。大量処理向け。微細粒の回収率は通常皿より低い|
|G203|携帯型スルース|6,400|1回20単位まで供給し、時間経過で連続選別。最後の粒の回収は別操作|

砂浜・川底・河原はそれぞれ4枠のクイック道具を保持します。エリアを戻すと前回の割当と選択が戻ります。作業台では所有する工程用道具を直接選べます。

1. 最初は採取地点をかき分け、小石や鉱物を拾って「洗浄」します。
2. スコップで砂利をまとめて集め、「砂利袋」「作業台」で処理します。
3. 皿を選び、砂利を投入して、皿の上を左右・円状になぞります。砂が減り、粒が残ります。
4. 素手または吸引瓶に持ち替え、残った粒を拾い、洗浄してFNと図鑑記録を得ます。
5. ふるいを先に使うと、粗粒が減った状態で皿へ投入できます。
6. スルースは砂利を供給した分だけ連続処理します。供給がなければ何も生みません。

作業台を閉じても進捗は保持されます。途中作業を取り消す操作は確認を挟み、未完了の投入分を戻します。完了分を巻き戻したり、閉じるだけで作業を完了したりしません。加速度センサーや外部APIは不要です。

## C09と工程のボトルネック

C09はG101＋G103＋G102。所持だけの固定ボーナスはありません。採取量が増え、実際にふるった砂利は粗粒分の体積と皿の必要作業量が減り、微細粒を残しやすくなる組み合わせです。粗粒率75%なら、ふるい済みの砂利は通常皿の実効4単位に約7.8単位分の原砂利が入ります。

通常皿は微細粒、大型皿は投入容量、スルースは継続処理が得意です。スコップだけ買っても選別が遅ければ砂利がたまります。スルースだけ買っても素手採取が遅ければ供給が止まります。工程別の実測量をDEBUG LABで確認できます。

## 砂利袋・個体・回収

砂利袋には元区画・地点・数量・粗粒率・採取道具・ふるい済量・処理済量・手選別量・内容UID・分離粒・回収済UID・残渣・再処理進捗を保存します。同じ地点の未処理の採取分は集約します。個体の種類・粒径・比重・品質・取りこぼし判定用の値は区画生成時に固定します。

残渣は同じUIDを再処理します。再投入には作業と時間が必要で、再抽選で新しいお宝を作りません。選別前の微細粒を吸引瓶で直接回収することはできません。保管24個が満杯なら粒を残し、空きを作って再挑戦できます。最終品質・図鑑・報酬は共通処理を使い、同じUIDの二重報酬を防ぎます。評価額と実際のFNは別です。

黄鉄鉱は角ばり・強い光沢、天然金は丸み・柔らかな光沢を手掛かりにします。未確認の黄色い粒は正体を断定しません。虫眼鏡はヒントを増やし、種類・品質・FNを変えません。

G-Bには2.5%で金を含む特別地点があり、G007/G008計7個を配置します。発見履歴は一度だけ記録。G012等の将来品を通常生成せず、大当たりなしでも7道具を買えます。

## DEBUG LAB

開発サーバーで設定を開き、VERSION表示を素早く5回タップします。8タブのうち「河原」で地点資源量・砂利袋・個体・粒径・比重・選別進捗・回収率・残渣を確認できます。「収益」には共通の工程別操作回数・処理量・体力・作業時間を表示します。処理量の単位は工程ごとに異なり、採取・選別は砂利単位、観察・精密回収は粒数です。

「シナリオ」は従来10件に以下の12件を追加しました。テスト専用セーブで再現し、通常セーブを変更しません。

|ID|再現状態|
|---|---|
|G-TEST-01|素手で小石を探す|
|G-TEST-02|スコップ採取|
|G-TEST-03|ふるいへ投入済み|
|G-TEST-04|砂金を含む皿の操作|
|G-TEST-05|黄鉄鉱と金を虫眼鏡で観察|
|G-TEST-06|微細粒を吸引瓶で回収|
|G-TEST-07|大型皿14単位|
|G-TEST-08|スルースへの供給済み状態|
|G-TEST-09|実際に採取・ふるいを経たC09|

「状態」で時間を1/2/10倍にできます。ゲーム内時間・スルース処理が対象で、見た目・指の移動・洗浄アニメーションは実時間です。LABを終了すると1倍へ戻ります。お宝指定生成も通常個体・地点・砂利袋・回収報酬の経路を通します。破壊的な初期化・シナリオ切替は確認を挟みます。

DEV限定の動的importでLABと強制操作を分離し、本番成果物からJS・CSS・専用保存キーを除外します。隠し操作だけを安全対策にはしていません。

## 保存互換

共通のsaveVersionは2を維持し、河原の下位形式goldVersion:1を追加しました。旧セーブのFN・砂浜深度・川底・所持品・図鑑を維持し、不足する河原状態とカテゴリ別装備だけを補完します。未知の将来形式・不正な数量・重複個体・矛盾した途中作業は読み込みエラーにし、自動初期化しません。

保存先は本番finders-v1、開発通常finders-dev-v1、LABテストfinders-debug-v1です。採取・選別・精密回収・スルース途中から再開できます。オフライン進行はありません。
