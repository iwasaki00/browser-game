# Version 0.8.2 — RIVER & GOLD TOOL FEEL

1. **Version**：0.8.2。既存プロジェクトで実装・ローカル検証。commit・push・公開は行っていない。
2. **主要ファイル**：src/river.ts、river-view.ts、gold.ts、gold-ui.ts、main.ts、automation.ts、save.ts、field-feel-ui.ts、field-feel.css、dev-field-feel-model.ts、dev-field-feel.ts、dev-automation.ts、data.ts、tests/field-feel.test.ts、scripts/field-feel-balance.ts、field-feel-browser-test.mjs、既存回帰試験、package、dist、READMEとdocs。
3. **川底の性能**：到達距離・磁性・吸着力・引上げ能力・速度・精密性・体力を別に扱う。小型磁石は軽量対象の取扱が速く、強力磁石は吸着18kg/単体引上げ8kg。トング/棒/フック/観察済みアームは既存の距離と保持条件を利用。[全表](RIVER_TOOL_FEEL.md)。
4. **引上げ時間**：100シード平均。軽量約0.12kgは小型1.12秒、強力2.10秒。中量約2.6kgはロープ4.00秒、巻取り併用1.55秒。重量約12kgは強力単体不可、滑車で14.02秒、巻取り＋ウインチで3.00秒。モデル時間。
5. **判定**：距離/ロープ長、磁性、吸着重量、障害物、引上げ重量を順に確認。非磁性真鍮は磁石不可。フックは隙間・非磁性物へ。能力不足は待っても成功せず、対象は現在区画に残る。水深/重量/難易度/水流が抵抗に反映される。
6. **補助の違い**：R110は速度2.6倍、R206はロープ＋強力磁石の引上げ能力22kg、R301は指定済み作業の自動巻上げ・速度と体力負担軽減。設備Lv補正を維持。吸着道具なしでは回収しない。
7. **川底UI**：共通20ms長押し/ドラッグ。現在道具・抵抗・水中移動/水面付近・実進捗を描画。補助の速度差が実進行に反映。通知と重ならない下部操作列へ回収ボタンを移動。短い効果音は連続再生を抑制。
8. **河原の性能**：採取、粒径、比重、微細回収を分離。既存14道具/設備の用途・価格を維持。[全表](GOLD_TOOL_FEEL.md)。
9. **採取速度**：通常G101 10、G106 16.67単位/秒。隙間G-CではG101 6.67、G106 3.33。バケツは速度を増やさず、袋集約と準備を補助。イベント回数で資源を増やせず枯渇量を超えない。
10. **ふるい時間**：原料40単位でG103 4.80秒、G202 2.10秒（投入操作のモデル時間込み）。容量8→16、多段前処理の微細捕捉補助は実際に処理した範囲だけ。
11. **皿・スルース**：4単位は小型4.10秒、大型6.92秒、スルース4.62秒。40単位は小型41.00秒、大型27.52秒、スルース8.52秒。水路準備4秒/袋込み。大型皿は微細捕捉率とのトレードオフを維持。
12. **微細粒**：同一濃縮物・最大8操作で素手25%、G104 37.5%、G110 62.5%、G204 100%。G204は3操作で12粒を回収。残りは濃縮物に保持。生砂利から直接回収しない。精密工程のモデル秒を全工程の収益時間と区別する。
13. **河原UI**：採取/未処理/ふるい済み/濃縮粒/残渣の実数、時間で減る砂、多段表示、水流準備/連続処理、道具別アイコン。最終回収は粒の選択操作を維持。
14. **装備比較**：4枠維持、選択中の候補だけ詳細表示。川底は選択/観察済み対象、河原は同じ袋の次の投入を実モデルで比較。条件不明や能力不足は時間を捏造せず比較不可/理由を表示。候補で現在道具を持ち替えた構成として算出。
15. **ラインへの影響**：3設備、各分野2/合計6ライン、設備Lv1〜3、配分・予約・中間在庫を維持。新速度は作業に割り当てた道具だけに適用。固定個体/残渣/厳密台帳を共用。未知対象の自動探索・自動売却なし。
16. **保存互換**：FN、道具、4枠、12エリア、砂浜10層、川底対象、砂利、図鑑300、未洗浄品、ライン/設備/キュー/台帳/J履歴を維持。workSeconds/setup/sluicePreparedを任意追加。途中進捗を保持し非表示/終了中の収益を計算しない。
