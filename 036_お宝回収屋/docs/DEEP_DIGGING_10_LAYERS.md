# Version 0.8.1 — 10層掘削

物理深度の範囲は0〜600のまま、境界を40 / 80 / 130 / 180 / 230 / 280 / 350 / 420 / 510 / 600へ細分化。境界値は次の層に属し、600は第10層。到達能力は境界直前の層で表す（素手80＝第2層）。既存の80 / 180 / 280 / 420 / 600を変更しない。

第1層から順に柔らかい表面砂、湿った砂、締まった砂、砂利混じり、硬い砂、小石の混じった層、圧縮された砂礫、深い堆積層、硬質堆積層、最深部。表面の見下ろし視点、セルごとの実深度による穴の暗さ・壁厚・色、深い場所の小石模様で深さを表現。未露出品は描画しない。

通常画面には現在層・層内進捗・道具の到達層を表示し、数値深度は表示しない。層到達通知は区画単位、限界通知は区画と道具単位で抑制する。深い穴へ弱い道具を持ち替えても穴は浅くならない。

保存済みmaskと個体depthは移動・再抽選しない。旧280基準区画はその基準で保持するため第6層まで。無料の新しい清掃区画で600基準へ移行できる。旧600基準区画はそのまま第10層まで掘れる。未洗浄品・砂・砂利・個体ID・報酬台帳・ラインは維持。

詳細：[性能](TOOL_DIGGING_PERFORMANCE.md)、[入力](DIGGING_INPUT_AND_FEEL.md)、[計測](DIGGING_BALANCE.md)。
