## データと表示

- 正式な対応表：src/treasure-sprite-map.json。treasureId、sheet、col、row、size、field、category、rarity、availableを保持します。CSVはdocs/TREASURE_ASSET_MANIFEST.csv。
- src/treasure-sprite-map.tsが型・9シートの定義・セル境界を管理し、treasure-assets.tsがViteの画像URLを解決します。画像は使う画面で読み込み、同じURLを共有します。小さなPNGも本番で独立ファイルとして出力します。
- available=trueの114件をPNG表示し、予約のみの186件は既存SVGへ戻します。未割当・画像未配置・セル設定不正・読込エラー・シート寸法不正もSVGで表示します。失敗したシートはそのページ中は再試行せず、再読込で再試行します。
- 切り抜きは32×32のoverflow:hiddenとシート全体の位置オフセットで行います。図鑑一覧32px、詳細64px（2倍）、洗浄128px（4倍、短い画面は96px/3倍）。どのレア度も同じ表示倍率です。
- C/U/R/SR/Jは中立色/緑/青/紫/金の枠や控えめなグローで表現。洗浄前は枠の強調を隠し、既存の砂・泥オーバーレイを重ねます。洗浄後も同じスプライトを使います。
- 未発見の図鑑は共通のグレーシルエットで、個体の正体・レア度を画像から漏らしません。
- 洗浄・図鑑一覧・詳細を共通treasureShapeで表示します。収益レポートやログは現在テキスト中心のため、そのままです。探索Canvasの埋没物表現は変更しません。

## 制作由来と試作の限界

現在の9シートは専用ドット絵114件を含みます。第1弾12件・第2弾42件・第3弾60件は、内蔵image_genで各品を個別に新規制作し、32×32の透過・材質別パレットへ仕上げたものです。外部素材のダウンロードや元SVGの縮小は使用していません。第1弾の画風を基準として、原寸での形の違いを優先しました。

制作プロンプト・最終ドットデータはartwork/treasure-wave1/、artwork/treasure-wave2/、artwork/treasure-wave3/に保持しています。個別32px PNGは第2弾artwork/treasure-wave2/sprites/、第3弾artwork/treasure-wave3/sprites/。元の試作54件に残るSVG由来のPNG仮絵は0件です。PNG未作成186件は従来どおりSVGへフォールバックし、今回制作していません。

## 更新手順

1. JSONで対象IDの既存セルを確認します。公開後のcol/rowは移動せず、予約セルへ描き込みます。
2. PNGを256×160の透過画像のまま編集し、対象セルに32×32で配置します。隣のセルにはみ出さないようにします。
3. 完成した対象だけavailable=trueにします。未完成セルはfalseを維持します。
4. npm.cmd run data:treasuresでCSVを更新し、npm.cmd test、npm.cmd run build、npm.cmd run test:sprites-browserを実行します。
5. 本番プレビューで図鑑・洗浄・詳細と、読込失敗時のSVGを確認します。

scripts/create-sprite-plan.tsは初回計画を作った記録です。現在の対応を再採番しないため、将来の画像追加で安易に再実行しないでください。scripts/build-prototype-sheets.mjsは試作を再生成する開発用スクリプトで、完成絵を上書きするため通常ビルドからは実行しません。

## 保存と残作業

スプライトの座標・画像URL・ロード失敗状態は進行セーブに保存しません。既存のtreasureIdを表示時に参照するため、FN、品質、回収状態、図鑑、作業キューの互換性に影響しません。画像からFNや個体を生成する処理はありません。

今後は186件の空き予約セルへの制作、114件と整合する画風の維持、各品の判別性と実機Safariでの確認が必要です。制作元・プロンプトの記録を継続します。
