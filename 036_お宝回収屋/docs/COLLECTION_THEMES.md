# 図鑑のテーマ収集

現行 Version 1.0.0-rc.1 に追加。Version・ゲーム仕様上の採取条件・価格・報酬・装備性能・セーブ形式・300点の画像は変更しない。

## 使い方と進捗

通常メニュー「図鑑・記録」→「テーマ収集」を開く。3テーマの発見済み種類数を表示し、テーマを開くと対象品を確認できる。発見済みの「詳細」は図鑑の既存詳細表示を利用する。未発見品の名称・絵は伏せる。検索、絞り込み、ページ送り、探索目標9点は従来どおり。

唯一の進捗源は `discoveredTreasures`。テーマ専用の進捗や完成通知フラグは保存しない。未洗浄品・閲覧だけの品は数えず、重複回収は同じ1種類として扱う。旧セーブの登録済み品も直ちに反映する。

洗浄の報酬・図鑑登録処理の直前と直後で完成状態を比較し、未完成→完成になったテーマだけ既存の洗浄結果欄へ「テーマ完成 — テーマ名」を添える。閲覧、再読み込み、重複回収、すでに完成した旧セーブでは通知しない。追加報酬はない。

砂浜3品のマスター深度は0〜600だが、浅い個体も出現するため最上位装備は必須ではない。B-Aは初期解放、B-Bは砂浜回収5個。砂浜の素手深度制限は従来どおりで、深い個体には対応スコップが必要。

川底は砂浜累計回収10個でR-A、20個でR-Bへ進める。R101回収トング（180 FN、持上げ2kg）またはR103小型磁石などが初期の選択肢。距離が届かない個体は長い道具、障害物がある個体はフック等が必要で、テーマが条件を免除することはない。裸手の基礎能力だけではこれらの重量を満たさない場合がある。

河原G-Aは砂浜20個または川底5個、G-Bは河原の発見10種類またはパンニング5回。G-Cは河原累計回収20個＋G-B訪問実績＋所持500 FNまたは購入実績。微粒・薄片はG102パンニング皿で選別でき、最後は素手での反復回収も可能。G110吸引瓶は省力化であり必須ではない。最上位装備やJ/SR品はテーマに含めない。金の3形状を守るため、小粒の天然金1品はG-C以降の中盤対象としている。

根拠：`src/data.ts`、`src/treasure-expansion.json`、`src/world-generation.ts`、`src/world-rules.ts`、`src/engine.ts`、`src/river.ts`、`src/gold.ts`。追加テストでは全9品が通常の出現候補であり、ジャックポットを無効化した200シード以内の生成でも実際に出現することを確認する。

## DEBUG LAB：最短の完成確認

1. 静的デバッグ版 `dist-debug/index.html` → 開始 → DEBUG LAB →「お宝」タブ。
2. 「テーマ収集の確認」を開き、テーマを選んで「残り1点の状態を作る」。**現在のテスト用進行を新規状態に置き換えるため確認ダイアログあり。通常セーブには触れない。**
3. 閉じる →「図鑑・記録」→「テーマ収集」→選んだテーマ。`2 / 3` と未発見1品を確認。
4. DEBUG LAB →「お宝」。即回収欄に最後の品が自動選択される。「選んだ品を即回収」。最後の品は砂浜B005／川底R026／河原G009。
5. 閉じて図鑑を確認しても `2 / 3` のまま。洗浄 →「洗浄」を押すと「テーマ完成」。図鑑は `3 / 3 — 完成`。
6. 再読み込み → 開始 → 図鑑。完成は維持され、通知は出ない。同じ品をもう一度即回収・洗浄しても通知しない。

全300点の実名・画像・詳細の閲覧は発見フラグを変更しない。テーマ欄は静的デバッグ版でも未登録品を伏せる。すべて `finders-static-debug-v1` のみに保存。既存のローカルVite開発版のDEBUG LAB入口も維持する。

## Windowsでの起動

対象フォルダで `npm.cmd run build` と `npm.cmd run build:debug`。

PCで同一オリジンの通常／デバッグ成果物を確認する場合は `npm.cmd run preview:both`。コンソールに表示される `/dist/index.html` が通常版、`/dist-debug/index.html` が常時DEBUG版。通常版は `?debug=1` を付けてもDEBUGにならない。終了はCtrl+C。

iPhone確認用には、別々の端末画面で以下を実行できる。

```powershell
cd C:\_wk\github\browser-game\036_お宝回収屋
npm.cmd run preview -- --host 0.0.0.0 --port 4173 --strictPort
# 別のPowerShell：デバッグ版
npx.cmd vite preview --outDir dist-debug --host 0.0.0.0 --port 4174 --strictPort
```

同じWi-FiのiPhone Safariで `http://PCのIPv4アドレス:4173/`（通常）または `http://PCのIPv4アドレス:4174/`（DEBUG）を開く。通常は図鑑→テーマ収集、DEBUGは上の残り1点操作で3テーマを確認。未発見の伏せ字、折りたたみ、スクロール、詳細、洗浄後の完成表示、再読み込み後の完成維持を確認する。起動時からDEBUG／テスト用セーブ表記を確認する。終了は両方Ctrl+C。
