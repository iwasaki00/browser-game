# 効果音全部オレゲーム

自分の声や身の回りの音を録音し、その音をショット・爆発・ダメージなどの効果音として使うブラウザゲームです。第1版は共通サウンドスタジオ、サウンドパック、効果音チェック、縦スクロールシューティングを収録しています。

## 起動方法

静的ファイルだけで動作します。録音を使わず試す場合は `index.html` を開いて「すぐ遊ぶ」を選べます。録音機能を使う場合は、HTTPSで公開するか、開発時はlocalhostのHTTPサーバー経由で開いてください。

例：リポジトリ直下で `python -m http.server 8000` を実行し、`http://localhost:8000/023_koukaon-ore-game/` を開きます。

## マイク利用条件とiPhone Safari

- マイク取得にはHTTPSまたはlocalhostが必要です。通常のHTTPではブラウザがマイクAPIを許可しません。
- Safariでマイク許可を求められたら「許可」を選んでください。拒否した場合はSafariのサイト設定から変更します。
- AudioContextはボタン操作時に開始・再開します。バックグラウンドから復帰して音が止まった場合は画面上部の再開通知か、設定の「サウンドを再開」を押してください。
- 縦持ちを基本とし、Safe Areaとホームインジケータ領域を避けています。
- `navigator.vibrate` がない環境（iPhone Safariを含む場合があります）では振動設定は無効になります。

## 保存

録音Blob、サウンドパック、現在のパック、設定、最高スコアはIndexedDBへ保存します。音声はサーバーへ送信しません。Safariのサイトデータを削除すると録音も削除されます。プライベートブラウズでは保存が維持されない場合があります。

## ゲーム追加方法

`games/<ゲーム名>/` にゲームクラスを追加し、`GameManager`へ起動処理を登録します。ゲーム側から音を鳴らすときは録音や保存処理へ直接触れず、必ず `SoundManager.play("カテゴリ名")` を呼びます。

## 効果音カテゴリ追加方法

`js/config.js` の `soundDefinitions` に内部ID、表示名、短縮名、録音例、最大録音秒数を追加します。`SoundManager`の仮効果音も用意する場合は `profiles` に同じIDを追加します。

## 現時点の制限

- 自動トリミングは設定と将来の処理分離を用意した段階で、録音波形の切り詰めは未実装です。
- サウンドパックの端末外への書き出し・読み込みはありません。
- シューティングは1ステージ構成で、横持ち専用UIはありません。
- 実機ごとのMediaRecorder形式はSafariの実装に依存します。

## 次に追加するとよい機能

波形を使った無音トリミング、パックの共有、録音縛りモード、横スクロールアクションなどを同じ録音・再生基盤の上へ追加できます。
