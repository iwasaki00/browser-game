# スマートフォン操作の変更と確認

2026-10-14 実施。変更範囲に限定した確認であり、全件回帰テストではありません。

## 変更ファイル

- `index.html`：一覧リンク削除、拡大を制限しないviewport、日本語メニュー・初回操作説明。
- `style.css`：100dvh、Safe Area、操作領域とホットバーの分離、44px以上の主要ボタン、選択表示、内部スクロールと操作領域の文字選択防止。
- `script.js`：pointerIdごとの入力管理、複数指対応、capture喪失・キャンセル・長押し終了処理、非表示・blur・回転時の解除、必要時の自動ポーズ、初期化確認、日本語表示、Canvas実寸に基づく座標変換。
- `tests/mobile.cjs`：変更範囲のブラウザ自動テスト。フックはローカル検証サーバーの応答だけに挿入され、配布するゲームには含まれません。

## 検証結果

Chromiumの自動テスト31項目が成功。

- 320×568、375×667、390×844、430×932、844×390：主要UIの画面内配置、要素同士の非重複、44px以上の主要操作ボタン、クラフト・ポーズ操作。320×568と844×390のスクリーンショットを目視確認。
- 320×568（上20・下34px）と844×390（左右44・下21px）：CSSのSafe Areaを模擬して収まりを確認。
- CDPによる複数タッチ：移動＋採掘、同じ移動ボタンに複数指、一部の指だけ離す、全指終了、pointercancel、Canvasの操作指固定、長押し終了・タイマー解除、タッチジャンプ、回転時の解除。
- lostpointercapture：実際のタッチで取得したpointerIdを持つイベントの注入でハンドラーを検証。
- blurとvisibilitychangeによる入力解除、自動ポーズ・再開。visibilitychangeの非表示状態はテスト内で模擬。
- クラフト画面のネイティブ縦スワイプとホットバーの横スワイプ。
- PCのA/D・矢印キーと別名キーの同時押し解除、Spaceジャンプ、E配置、F攻撃。採掘・配置でのマップと所持数の変化、クラフト時の材料消費と作業台取得。
- セーブ・再読込による地形と所持品の復元、既存の保存キー・フィールド構造。初期化キャンセル時は保存文字列とワールドが不変、承認時は既存の新規ワールド生成へ移行。
- ブラウザ実行エラーなし、`node --check script.js`、対象ディレクトリの`git diff --check`が成功。
- HEADとの差分確認でワールド生成・洞窟生成、物理演算、敵AI、採掘耐久値・道具性能、クラフト材料・効果、ロード処理、保存キー・payload構造の維持を確認。

入力の内部状態を正確に検証するテストでは描画ループを停止し、必要なゲーム更新を明示実行しています。画面確認は通常の描画ループで実行しています。

## 再実行

Node.jsとPlaywright（Chromium）を用意して、プロジェクト直下で実行します。

```sh
node tests/mobile.cjs
```

Playwrightが通常のモジュール探索範囲外にある場合は`PLAYWRIGHT_MODULE_PATH`にモジュールパスを指定します。既存Chromeを使う場合は`CHROME_EXECUTABLE_PATH`に実行ファイルのパスを指定します。画像・結果JSONの出力先は既定でOSの一時ディレクトリ内の`frontier-below-mobile-results`です。`TEST_OUTPUT_DIR`で変更できます。
