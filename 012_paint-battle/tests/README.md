# スマートフォン入力・レイアウト修正の検証

実施日：2026-10-14。変更箇所と影響範囲に限定して確認。全件回帰テストは実施していません。

## 変更ファイル

- `index.html`：タイトルの「← ゲーム一覧」を削除。viewportの拡大制限を削除。盤面の利用可能領域を設け、SPパネルを操作デッキに移動。「タイトルに戻る」は維持。
- `style.css`：back-linkのCSSを削除。100dvhと上下左右のSafe Areaから画面高を確保し、HUD・情報表示・操作デッキ・退出ボタンを配置した残りの領域に正方形の盤面を表示。横画面は盤面の左右に操作を配置。小型画面は余白と情報を縮小し、ジョイスティック116px・攻撃86px・SP54pxを確保。各メニューは内部スクロール可能。操作領域のtouch-actionと文字選択防止を維持し、touch-calloutを抑制。入力欄は文字選択可能。
- `app.js`：攻撃のpointerIdとキーボード入力の所有を管理。開始した指以外の終了を無視。pointerup / keyupだけでチャージャーを発射し、pointercancel / lostpointercaptureでは破棄。capture解放前に所有を解除し二重処理を防止。既存の700msクールダウンを維持。ジョイスティックの別指による上書きを防止。blur・非表示・offline・pagehide・Firebase接続切断で入力解除。試合終了・退出・部屋削除で描画と演出タイマーを停止。
- `tests/mobile.cjs`：変更範囲の自動テスト。検証用フックはローカルHTTP応答にのみ追加され、配布用app.jsには含まれない。
- `tests/README.md`：この検証記録。

## 再実行

Node.jsとPlaywrightのChromiumが必要です。

```sh
node tests/mobile.cjs
```

通常の探索範囲外にあるPlaywrightは`PLAYWRIGHT_MODULE_PATH`で指定できます。既存Chromeを利用する場合は`CHROME_EXECUTABLE_PATH`を指定できます。画像と結果JSONはOS一時ディレクトリ内の`paint-battle-mobile-results`に出力します。`TEST_OUTPUT_DIR`で変更できます。実時間の確認を含むため実行に約65秒かかります。
