## 自動テスト

- 標準180×300・高精細270×450の不透明画像中央で、横方向の溝が連続する。高速の斜線でも跡の中心に穴埋まりや途切れがない。
- 指を動かさない入力では粒が移動しない。なぞり砂中は8方向重力の値を変えても通常物理を更新せず、指を離した溝を保持する。
- 交差する軌跡を繰り返しても粒のID・色・個数を保持する。「砂を戻す」完了時は位置・色・個数・固定状態が初期画像と一致する。即時リセットも確認。
- 縦の全高壁を挟んで繰り返しなぞっても、壁マスクが変わらず、粒が反対側へ移らない。通常の道具へ戻す際も同じ側に全粒を収め、一粒一セルの整合性を検証。その後は自由粒が重力で移動する。
- 速い払いは遅い払いより進行方向の変位が大きい。不正値の入力は無視する。
- 実アプリのハンドラーで、道具選択後のパネル閉鎖、「重力なし」表示、一斉崩壊の無効化（強制イベントも無視）、センサー入力後の配置保持を確認。
- 標準・高精細それぞれで、サイズプレビュー取消、砂時計との往復、復元・途中リセット、通常の道具への復帰でも画像変換が勝手に走らないことを確認。
- 既存の壁なし物理、壁の支持・消去・貫通防止、傾きの許可・監視・画面回転、砂時計の流下・反転、写真サイズ・品質変更も再実行。

## 実装

`PathEngine` のなぞり砂中だけ、入力区間のカプセル領域にある粒を両脇へ移す。短い入力間隔の速い払いには、小さな前方向変位を加える。通常の `SandEngine`、砂時計、傾き監視のアルゴリズムは変更しない。

移動は壁を確認する縦横の隣接セル経由で行う。固定砂で詰まった場所では縁への一時的な重なりを許し、指を離した後には更新しない。道具を戻すときは壁を除いたセルだけを探索し、空きセルから隣接粒を順に動かして重なりを解消する。ここで移動した固定粒も自由粒にする。復元は既存のID・原位置をそのまま使い、最後の既存リセットで正確に確定する。

メイン画面のボタン数とCSSは変更せず、「道具」パネルに1項目だけ追加。実ブラウザとiPhoneでの見え方・操作感は未確認。

## 再実行と手動確認

```sh
npm test
npm run reference:trace
npm start
```

`http://127.0.0.1:5173` を開き、標準・高精細で不透明写真中央をゆっくり／速くなぞる。停止・指離し・傾きで溝が保持されるか、繰り返し・壁付近・道具復帰・復元・リセット・砂時計往復を確認する。iPhoneのHTTPS接続方法はルートREADMEを参照。実ブラウザでの見え方や実機の結果を、上のNode計測と混同しない。
