# 次期バージョンの改善候補

以下は候補のみで、v0.2.0では実装していません。

1. 実機の測定結果に基づく性能・操作感の調整。活動粒子リストや描画の差分更新を検討する。
2. 大きな写真のデコード時のメモリ負荷、EXIF方向、Safariのファイル選択の互換性改善。
3. 傾きセンサーの実機感度調整。連続重力ベクトルへの拡張は別途仕様を決める（8方向の傾き入力はv0.2.0で実装済み）。
4. 摩擦・重力・斜面の崩れやすさの詳細調整。
5. 粉末・砂鉄・液体などの素材別ルールと、風・磁力などの外力。
6. 砂が元画像へ戻るアニメーション、別画像への変形。
7. 画像・動画としての保存。

優先度はまず実機検証と不具合修正です。新機能は仕様を決めてから追加します。
