## 表示・操作

- [ ] 縦画面で主要な操作ボタンが収まり、横スクロールがない。
- [ ] 画面が小さい端末でも操作でき、設定を開いた際は必要に応じてページをスクロールできる。
- [ ] 写真選択をキャンセルしても元の画像が維持される。
- [ ] 写真ライブラリ／ファイルからJPEG・PNG・WebPを選べる。
- [ ] 写真の縦横比とEXIFの向きが正しい。縦撮影・横撮影・上下逆の撮影で確認する。
- [ ] 透過PNGの透明な部分には砂がない。
- [ ] 破損画像・未対応形式では理由が表示され、現在の画像が残る。
- [ ] 同じ画像を連続して選び直せる。大きな写真の後に別画像を選んでも正しく切り替わる。
- [ ] タップした周辺だけが崩れる。
- [ ] 速いスワイプでもブラシ範囲が途切れない。
- [ ] 遅いスワイプと速いスワイプで押し出し方が変わる。
- [ ] 指を止めたときに押出力が追加されない。
- [ ] 指がCanvasの外へ出た後、操作終了・キャンセルが正しく扱われる。
- [ ] 砂の上でページスクロール・長押しメニュー・ダブルタップ拡大が起きない。
- [ ] 操作領域以外のページ操作・設定のスクロールができる。

## 物理・性能

- [ ] 一斉崩壊後、固定粒子が0になり、床に堆積する。
- [ ] 砂山の上部が斜めに流れる。
- [ ] 自由砂を横や上に押せる。強い操作でも壁を貫通しない。
- [ ] 8方向の重力が動作し、静止していた砂も再び動く。
- [ ] 操作前後で総粒子数が変化しない。
- [ ] リセットで色・位置・固定状態・粒子数が即時に戻る。
- [ ] 回転・アドレスバーの伸縮で粒子や操作状態が消えない。
- [ ] 品質切替では現在の画像を初期状態から再生成する。
- [ ] 診断パネルを開閉でき、固定／自由の合計が総粒子数と一致する。
- [ ] 標準のサンプルで崩壊中のFPSを記録し、30fps目標を評価する。
- [ ] 軽量でも同じ条件で計測する。
- [ ] アプリをバックグラウンドにして戻しても砂が急激に飛ばない。
- [ ] 10分以上操作し、粒子数・異常終了・自動再読み込み・発熱を確認する。
