# iPhone Safari 実機確認 — v0.2.1 TILT LAB

今回の実機検証はすべて未実施です。以下をチェックして結果を記録してください。

## v0.2.1の追加確認

- [ ] 標準と高精細で同じ画像を読み込み、Canvasと見た目のブラシ幅を比較する。
- [ ] 高精細270×450・実粒子数・崩壊中FPSを記録する。サンプルは39,440粒。
- [ ] 崩壊・スワイプで粒子数が増減せず、リセットで元の高精細画像に戻る。
- [ ] 品質の選択前に再生成の説明があり、操作中に自動で品質変更されない。
- [ ] 傾き開始後5秒以上待ってから動かし、最初の有効値で傾きへ移行できる。
- [ ] 初回待機中は直前の手動重力を維持し、矢印で待機を解除できる。
- [ ] 傾き有効化後、同じ姿勢で5秒以上待ってから逆に傾ける。イベントが静止中も届いていたか、途絶えたかを区別して記録する。
- [ ] Windows版 iPhone Web Emulator 1.1.1でも上記の初回待機・有効化後静止を別々に記録する（iPhone実機の結果と混ぜない）。

## 傾き・回転の必須確認

- [ ] HTTPSのURLと警告のない接続を確認する（[README](../README.md)の手順を参照）。
- [ ] 起動直後は手動で、傾き操作のボタンを押す前には許可を要求しない。
- [ ] センサーの許可を拒否した場合、理由が表示されて手動操作を継続できる。
- [ ] 許可後の最初の姿勢で下向きになり、「基準を合わせる」でも下向きに戻せる。
- [ ] **縦向きロックONでも、左右への傾きが砂に反映される。** 実際の表示は縦のままで停止しない。
- [ ] 軽い左右の傾きで斜め下、より大きな傾きで横に流れ、基準へ戻すと下へ流れる。
- [ ] 小さい手ブレや境界付近で方向が頻繁に切り替わらない。反応の角度と遅れを記録する。
- [ ] 固定写真は傾けただけでは崩れない。
- [ ] **傾けながら指で砂を触れ、部分崩壊・押し流しが同時に使える。**
- [ ] **縦向きロックOFFで実際に横表示にすると停止し、縦表示へ戻して安定させれば続きから遊べる。**
- [ ] 横表示中はタッチ・更新・リセット・画像変更等が停止し、総数と固定／自由の数が変わらない。
- [ ] 回転前後で粒子の位置・色・総数・固定／自由・基準が保持される。元画像へ戻ったり再生成されたりしない。
- [ ] 縦に戻した直後、指を離してから触れ直すと、タッチ位置がずれない。
- [ ] 横表示中に矢印を押すと即座に手動へ戻り、その方向が適用される。
- [ ] 手動モードでは横表示による一時停止が起きない。
- [ ] Safariのバックグラウンド復帰後、値未受信の案内・手動復帰・傾き再試行が扱える。

縦向きロックはOS側で設定します。アプリからのロック状態検出・設定変更は行いません。自動テストの成功でこれらを確認済みにはしません。

## 表示・操作

- [ ] 縦画面で主要な操作ボタンが収まり、横スクロールがない。
- [ ] 画面が小さい端末でも操作でき、設定を開いた際は必要に応じてページをスクロールできる。
- [ ] 写真選択をキャンセルしても元の画像が維持される。
- [ ] 写真ライブラリ／ファイルからJPEG・PNG・WebPを選べる。
- [ ] 写真の縦横比とEXIFの向きが正しい。縦撮影・横撮影・上下逆の撮影で確認する。
- [ ] 透過PNGの透明な部分には砂がない。
- [ ] 破損画像・未対応形式では理由が表示され、現在の画像が残る。
- [ ] 同じ画像を連続して選び直せる。大きな写真の後に別画像を選んでも正しく切り替わる。
- [ ] タップした周辺だけが崩れる。
- [ ] 速いスワイプでもブラシ範囲が途切れない。
- [ ] 遅いスワイプと速いスワイプで押し出し方が変わる。
- [ ] 指を止めたときに押出力が追加されない。
- [ ] 指がCanvasの外へ出た後、操作終了・キャンセルが正しく扱われる。
- [ ] 砂の上でページスクロール・長押しメニュー・ダブルタップ拡大が起きない。
- [ ] 操作領域以外のページ操作・設定のスクロールができる。

## 物理・性能

- [ ] 一斉崩壊後、固定粒子が0になり、床に堆積する。
- [ ] 砂山の上部が斜めに流れる。
- [ ] 自由砂を横や上に押せる。強い操作でも壁を貫通しない。
- [ ] 8方向の重力が動作し、静止していた砂も再び動く。
- [ ] 操作前後で総粒子数が変化しない。
- [ ] リセットで色・位置・固定状態・粒子数が即時に戻る。
- [ ] 回転・アドレスバーの伸縮で粒子や操作状態が消えない。
- [ ] 品質切替では現在の画像を初期状態から再生成する。
- [ ] 診断パネルを開閉でき、固定／自由の合計が総粒子数と一致する。
- [ ] 標準のサンプルで崩壊中のFPSを記録し、30fps目標を評価する。
- [ ] 軽量でも同じ条件で計測する。
- [ ] アプリをバックグラウンドにして戻しても砂が急激に飛ばない。
- [ ] 10分以上操作し、粒子数・異常終了・自動再読み込み・発熱を確認する。
