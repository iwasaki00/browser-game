# SAND MOTION v0.2.0 — TILT LAB

## 変更範囲

追加は重力の入力元とスマホ横表示時の停止・復帰です。`src/engine.js`、`src/image.js` の物理・砂の流れ方・画像変換には変更を加えていません。部分崩壊・押出し・一斉崩壊・リセットは既存の処理を使います。初期状態は手動です。

## 入力と許可

`src/tilt.js` の `TiltController` にブラウザAPIを注入します。「傾きで操作」のクリックから `start()` を呼び、セキュアコンテキストとAPIの存在を確認します。`requestPermission()` がある場合は、他の非同期処理を待つ前にボタン操作の中で呼びます。最初の有効値までは手動を維持します。API非対応、拒否、例外、4秒間有効値を受信できない場合は理由を表示して手動に戻ります。

矢印を押すとリスナーと監視タイマーを破棄して手動へ戻り、選んだ方向を適用します。許可要求の途中で手動へ戻った場合は、遅れて許可されても開始しません。非表示中の値欠落で即時タイムアウトしないよう、監視を猶予します。

## 持ち方から8方向へ

beta・gammaから画面内の重力の射影を算出します。画面座標の横成分を `cos(beta) * sin(gamma)`、下成分を `sin(beta)` として角度を得ます。地磁気のalphaは使いません。縦持ち付近でgammaだけが急変する場合にも対応できます。角度は最初の有効値を基準として相対化します。完全に水平に近い姿勢は射影が小さく方向が不安定になるため採用せず、縦に起こす案内を表示します。

基準姿勢は下向きで、相対角を平滑化し、感度倍率とデッドゾーンを適用して既存の8方向へ量子化します。方向切替にはヒステリシスを入れ、境界の往復を抑えます。「基準を合わせる」は直近の有効姿勢を新基準にして下向きにします。固定粒子の解除は行いません。

### 実機調整用の定数

すべて `src/tilt.js` の `TILT` にまとめています。

| 定数 | 初期値 | 意味 |
|---|---:|---|
| gain | 2.5 | 相対傾きの感度倍率 |
| deadZoneDegrees | 4° | 小さな手ブレを無視する範囲 |
| hysteresisDegrees | 3° | 方向の境界に加える余裕（入力角） |
| smoothingMs | 100ms | 指数平滑化の時定数 |
| minimumProjection | 0.12 | ほぼ水平の不安定な姿勢を除外する射影長 |
| sensorTimeoutMs | 4000ms | 有効値の未受信で手動に戻すまでの時間 |
| watchdogMs | 500ms | 受信監視の周期 |
| resumeStableMs | 350ms | 縦表示復帰後の安定期間 |
| resumeToleranceDegrees | 2.5° | 安定とみなす角度の幅 |
| resumeMinSamples | 3 | 安定期間内に必要な受信数 |
| maxSampleGapMs | 250ms | 安定期間を継続できるサンプル間隔 |

初期の下向きからは相対傾き約12°超で斜め下、約30°超で横へ切り替わります。戻る境界はそれぞれ約6°・24°です。平滑化のため瞬時には切り替わりません。初期値は自動テストのみで確認し、実機での感度調整は未実施です。

## 横表示の停止と復帰

端末のセンサー角度と表示の向きを分離します。表示は `screen.orientation.type`、その角度、iOSの旧 `window.orientation` の順で判断し、取得できない場合のみ表示領域の縦横比を使います。センサーを傾けただけでは停止しません。PCはモバイル判定の対象外です。

スマホかつ傾きモードで横表示になった場合、オーバーレイを表示し、物理ステップ・タッチ入力を止めます。リセット・一斉崩壊・画像変更・品質変更も停止中は無効にします。読み込み途中の画像が停止中に完了した場合は置換せず、選び直しを案内します。矢印からの手動復帰は利用できます。

縦表示に戻ってから有効な入力が継続して350ms安定すると自動復帰します。途中で揺れ・受信間隔の空き・再回転があれば安定の計測をやり直します。元の基準姿勢は保持します。フレーム経過時間をリセットし、停止中の時間を後からまとめて更新しません。粒子・グリッドは再生成しません。前のPointer Captureは解除し、次のタッチは最新のCanvas矩形から内部グリッド座標に換算します。

## 参照したAPI仕様

許可のユーザー操作要件と回転行列は [W3C Device Orientation and Motion](https://www.w3.org/TR/orientation-event/) を確認しました。センサー処理はこの仕様の座標から画面内の方向を算出するアプリ独自の入力変換です。OSの縦向きロックの制御・検出APIは使用していません。
