## 実装結果

空の作業フォルダーに、依存ライブラリのないHTML / CSS / JavaScript構成で新規実装しました。2Dグリッド、TypedArrayの粒子データ、色付き粒子、部分解除・連続ブラシ・押出力、一斉崩壊、瞬時リセット、8方向の重力、品質2段階、診断パネルを実装しています。Canvas 2Dを使用し、固定時間ステップと最大4ステップ／フレームを設定しています。

画像選択は標準のfile input、JPEG／PNG／WebPのデコードはブラウザ内で行います。サンプル画像もCanvasで生成します。透明セルの除外、アスペクト比保持、EXIFを扱う標準デコーダー、失敗時のエラー表示、最後に選択した画像を優先する処理を実装しました。

コミット・push・公開は実施していません。他プロジェクトの既存変更には触れていません。

## ブラウザ検証の状況

ローカルサーバー `http://127.0.0.1:5173` のHTTP 200とES ModuleのJavaScript MIMEを確認しました。初期の4173ポートはOSに接続を拒否されたため、既定を5173に変更し、環境変数PORTで変更できるようにしています。

ブラウザ連携ホストが利用できなかったため、Windows ChromeのUI経由で確認を試みましたが、ユーザーの物理EscキーによりComputer Useが停止しました。以後のブラウザ操作は実施していません。アプリのブラウザ表示・実際の操作、Chrome／Edgeの互換性は未検証です。

`test/browser.html` に、サンプル生成、3形式のデコード、透明画像、破損ファイル、アプリのボタン・合成PointerEvent・リサイズ・品質切替の検証ページを用意しました。この検証ページ自体のブラウザ実行も未検証です。
