# 一筆で変わる世界 / ONE STROKE WORLDS

**Version 0.6.0 — Playable Game**

一筆で地形を削る・盛る、水流パズルです。6つのチャレンジで町へ水を届け、水害を防ぎます。
既存の水流式・A〜Dの巡回・一筆判定・Stage 01〜03・同期比較・Living Map描画を維持し、ステージ解放、進捗保存、フリー実験、メニューとガイドを追加しました。

## 続けて遊ぶ

初回はStage 01から。クリアすると次の地図が解放され、クリア済みの地図には何度でも戻れます。「ステージ選択」で現在・クリア済み・未解放を確認できます。再起動時は最高解放ステージから新しい世界を始めます。

進捗と表示設定はlocalStorageの`one-stroke-worlds.save.v1`へ自動保存します。保存形式はスキーマバージョン1。保存データが壊れていても起動でき、保存不可なら警告してタブ内だけで遊べます。設定の「進捗・設定を初期化…」は確認後にこのゲームのデータだけを削除します。

「フリー実験」は正解のない観察用で、3サンプルから自由に削る・盛るを試せます。1試行1ストローク、RESETで初期化し、チャレンジ進捗に影響しません。「デバッグ」は開発用の数値検証として別モードを維持しています。今回フリー実験への世界比較は追加していません。

メニューを開くと計算を停止し、「ゲーム画面へ戻る」では停止したまま戻ります。モード切替は新しいWorldStateを生成します。Stage 01のガイドは場面に応じて短く表示し、設定で非表示にできます。「操作ガイド」では後から読み返せます。

## 生きている地図

草原から高地へ変わる緑と隣接高度差の陰影で地形を表し、水は深さに応じた青の濃淡で重ねます。「盤面の表示」で通常・高度と境界線・水量表示を切り替えられます。セルを選択すると高度と水量を数値で確認できます。

「流向を表示」は直近の論理ステップで実際に移動した水の矢印を表示します。傾斜から流れを推測しません。流量0・未記録の移動は表示せず、矢印は間引いています。停止中は直前の記録を静止表示し、RESETで記録も消えます。「動きを抑える」で流線と結果演出を静止し、OSのアニメーション軽減設定も反映します。これらの設定も保存します。

水源は水滴入りの丸、取水は菱形、排出口は下向き矢印入りの四角、町は家で区別します。町には給水・浸水状態を文字と警告模様でも表示します。一筆の実線・超過の破線・変更セルの半透明表示は既存処理と同じ対象セルを使います。残り長さは描画中に地図内にも表示します。

PCは地図を主領域とし、ステージ・目標・操作を右側に配置。スマホ幅は短いステージ情報、地図、編集・実行操作の順です。詳細情報は「地図のヒント・町の状況」から開けます。ページの縦スクロールとCanvas内のパン・ピンチを分けています。

## 世界A/Bの比較

チャレンジの一筆プレビューまたは実行結果から「世界A/Bを比較」を選びます。同じ初期条件から両世界を再生し、共通PLAY / PAUSE / STEP / RESET / SPEEDで操作できます。RESETは同じ一筆でStep 0へ戻し、「一筆を描き直す」は地形も初期化します。

広い画面は左右並列、900px未満はBEFORE（A）／AFTER（B）切替です。切替は再計算せず、両世界のパン・ズーム・表示範囲を共有します。差分は世界B−世界Aで表示し、取水量増加・最大浸水深減少を改善とします。任意ステップへのシークと全履歴保存はありません。

関連8ファイル・234テスト成功、0失敗。TypeScript型チェック・Viteビルド成功。Chromeで進捗復元、メニュー停止、390px幅のステージ選択・設定・フリー実験を確認済みです。スマートフォン実機は未確認です。詳細は[0.6.0実装報告](docs/IMPLEMENTATION-v0.6.0.md)を参照してください。

## チャレンジ

初期表示はチャレンジモードです。未クリアの後続ステージは、順番にクリアすると解放されます。

| ステージ | 操作・目標 | 計算期間 |
| --- | --- | --- |
| 01 はじめての一筆 | 尾根を削り、若葉の町の取水施設で4,096単位以上取水 | 120ステップ |
| 02 乾いた町 | 二つの尾根を一筆で削り、風待ちの町へ2,048単位以上給水 | 240ステップ |
| 03 水害から守れ | 水路を盛って堤防を作り、町の水深を常に128単位未満に保つ | 初期状態〜160ステップ |
| 04 川の分かれ道 | 削る・排出口への流れを分岐させ、木立の町へ2,048単位以上 | 240ステップ |
| 05 二つの願い | 削る・朝日と夕日の町へそれぞれ1,024単位以上 | 300ステップ |
| 06 最後の一筆 | 盛る・丘上へ2,048、川守へ128単位以上給水し、両町の浸水も防止 | 初期状態〜300ステップ |

白い家が町、黄色の◆が取水地点です。町の中心セルと取水セルは別の場所です。
取水量・水深は整数水量単位で表示します（256単位＝地形高度1）。
町は取水施設が取り除いた水の実績を参照し、町で二重に水を除去しません。
一度浸水した履歴は水が引いても残り、失敗確定後も終了ステップまで計算します。

「一筆なしで実行」で基準結果を確認できます。一筆後は「この一筆で実行 →」。
成功後は「次のステージへ」、再挑戦は「やり直す」またはRESETを使います。
デバッグモードへ切り替えると、従来の64×64サンプルと自由な削る・盛る操作を使えます。
途中の地形・水量・ストロークは保存せず、クリア進捗と設定だけを保存します。

## 操作

1. ステージまたはデバッグのサンプルを選び、**描画**モードを選択。
2. 盤面をドラッグして一筆。チャレンジの操作・長さ・半径・変更量はステージに従います。デバッグは長さ12セル、半径2セル、高度変更量12。
3. 半透明の変更予定セルと変更後高度を確認。実線が有効部分、赤い破線が超過部分です。
4. **この一筆で実行 →**で初期水量を保持し、編集地形でステップ0から計算。
5. **RESET**で元の地形・水量へ戻して再挑戦。描き直す場合は**一筆キャンセル / 再描画**。

**移動**モードのドラッグでパン、ホイールまたは2本指ピンチで1〜4倍ズーム。
描画中に2本目の指を置くと一筆を取り消してカメラ操作へ移ります。Escでも取消できます。
「全体」で表示位置を戻せます。Canvas外は通常のページスクロールが可能です。
施設・protectedセルは編集できません。保護区域の通過も長さを消費します。
プレビュー中は元の世界を変更しません。実行後はRESETまで追加編集できません。
点だけの入力は円形ブラシとして扱います。

従来のPLAY / PAUSE / STEP / SPEEDも利用できます。一筆なしのPLAY・STEPは元地形を計算します。
PREVIEW中は専用の実行ボタンを使います。デバッグは600、チャレンジは指定ステップで完了し、タブ非表示時は停止する設計です。
