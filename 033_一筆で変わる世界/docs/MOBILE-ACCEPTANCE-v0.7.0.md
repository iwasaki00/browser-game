# スマートフォン実機受入試験書 — 0.7.0

作成日: 2026-10-22。iPhone Safari / Android Chromeの**実機操作は未実施**です。PCの狭幅表示や自動テストを実機合格として転記しません。

## 準備と記入方法

0.7.2のPhase 6継続記録は[実機受入試験記録](PHASE6-DEVICE-RECORD-v0.7.2.md)を参照してください。2026-10-23にユーザーから「動作確認なし」と回答を受領したため、全30項目の未実施を維持しています。iPhoneのIP-01〜08用の報告ひな形とNG整理票を用意しました。

0.7.1でも既存の30項目をそのまま使用します。[実機アクセス手順](DEVICE-ACCESS-v0.7.1.md)に、既存静的配信とWindows上のLAN開発サーバーの開き方を追記しました。以下の未実施状態は変更していません。

試験専用のブラウザープロファイル、または進捗を消してよい試験端末を使います。通常プレイ用の進捗は消さないでください。配信されたゲームURLを開きます。PCのlocalhostはスマートフォン自身を指すため、そのまま入力しないでください。診断パネルは開発用だけで、通常配信にはありません。

各表の「実際の結果」に見たことを記入し、「判定」をOK / NG / 未実施のどれかに変更します。期待通りでなければNG、条件を用意できなければ未実施とし、備考に理由・画像番号を残します。再試験時も前回の結果を残してください。
