# 実機からゲームを開く手順 — 0.7.1

作成日: 2026-10-22。スマートフォンからの実アクセスは未確認です。この手順を作成したことは実機起動の成功を意味しません。

## 推奨: 既存の静的配信を使う

1. 普段利用しているbrowser-gameの配信URLをスマートフォンのSafari/Chromeで開き、一覧から「一筆で変わる世界」を選びます。
2. ゲームヘッダーの版が **v0.7.1** であることを確認します。古い場合は配信担当者が更新したか確認します。今回コードと`play/`を更新しましたが、リモートへのpush・公開は行っていません。
3. 使用した完全なURL、機種、OS・ブラウザー版、日時を[実機試験書](MOBILE-ACCEPTANCE-v0.7.0.md)へ記入します。

既存の配信先はこのプロジェクトのREADMEでは確定できないため、具体的な公開URLを推測していません。リンク一覧や他ゲームを変更する必要はありません。本番配信には開発用診断が含まれず、`?quality=1`を付けても表示しません。

## 必要な場合だけ: 同じLANの開発サーバー

1. Windows PCとスマートフォンを**同じ信頼できる家庭内・社内LAN**へ接続します。ゲストWi-Fiや端末分離のあるネットワークでは相互に接続できないことがあります。
2. PCのPowerShellで`ipconfig`を実行し、使っているWi-FiまたはEthernetアダプターの「IPv4 アドレス」を確認します。VPNや仮想アダプターの値を使わないでください。今回の作業では実機接続に使用できるPCのLAN IPを確認していません。
3. プロジェクトのフォルダーで次を実行します。ポートを変えたらURL側も同じ番号へ変更します。

```sh
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

4. スマートフォンのアドレス欄へ `http://<PCで確認したLAN IPv4>:5173/` を入力します。`<...>`は説明用の置き換え欄で、そのまま入力しません。スマートフォンに`localhost`や`127.0.0.1`を入力するとPCにはつながりません。
5. Windowsのファイアウォールで止まる場合は、まず信頼できるLANのネットワーク種別と、Node.jsの受信許可が**プライベートネットワークに限定**されているか確認します。管理対象PCは管理者へ相談してください。必要な場合だけ、使用する実行ファイル・TCPポート・同一LANに範囲を限定した一時的な許可を使用し、試験後に戻します。
6. ページが開いたことをスマートフォンで実際に確認してから、試験書の起動項目を記入します。PCからサーバーへ接続できただけでは実機起動OKにしません。
7. 終了したらPCのターミナルで`Ctrl+C`を押してサーバーを止めます。試験用の許可を追加した場合は削除・復元し、不要なポート開放を残しません。

ルーターのポート転送、パブリックネットワークへの広い許可、ファイアウォール全体の無効化は不要です。開発サーバーをインターネットへ直接公開しないでください。診断が必要なLAN試験だけURLへ`?quality=1`を追加し、通常操作・見た目の受入試験は診断を外して実施します。

## 接続できない時の記録

接続先URL（必要に応じて内部情報を伏せる）、PC/スマートフォンのネットワーク種別、サーバー起動の有無、画面に出たメッセージ、時刻を残します。IPを推測したり、安全設定を広く解除して接続を試したりせず、「未実施・接続不可」として原因を切り分けます。
