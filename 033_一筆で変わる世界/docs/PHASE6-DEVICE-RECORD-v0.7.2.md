## NGの整理と修正要否

実機NGの報告はありません。問題がないと確認できた意味ではありません。修正要否は未判定で、具体的な修正候補は結果受領・原因調査後に整理します。NGが届いたら次の票を問題ごとに追加します。

| 項目 | 記入内容 |
| --- | --- |
| 課題ID / 試験ID / 元の記録 | 対応する報告への参照 |
| 環境 / 実際の結果 | 機種・版・画面・観測した動作 |
| 再現手順 / 頻度 | 開始状態、指の本数、操作順、発生率。再現未確認と再現済みを区別 |
| 影響範囲 / 回避策 | 操作・ステージ・端末への影響は確認範囲のみ |
| 優先度 / 根拠 | P1: 起動不能・進行不能・データ消失、P2: 主要操作に支障、P3: 軽微な表示等。未調査なら未判定 |
| 原因 / 修正要否 / 修正候補 | 未特定を許容し、推測でゲームロジックを変更しない |
| 状態 / 再試験 | 未調査・調査中・修正済み・再試験待ち等。修正後は同じ環境・手順で確認 |
