# 4. Stage 04〜06の目標と地形設計

すべて24×24の保護された水路、初期総水量32,768、継続水源なし。施設と町の中心は別セルです。

**Stage 04「川の分かれ道」**：削る、長さ5、半径1、高度差8、240ステップ。南の排出口は1ステップ64単位を除去します。東の尾根を開くと流れが分かれ、木立の町の取水（上限256/ステップ）が必要2,048単位を達成します。排出との配分も実際に変化します。

**Stage 05「二つの願い」**：削る、長さ9、半径1、高度差8、300ステップ。北・南への水路には別々の尾根があります。一筆で両方を開き、朝日・夕日の町の独立した取水施設（各上限256/ステップ）でそれぞれ1,024単位を確保します。片方の尾根だけでは一町だけが達成し、全体は失敗します。

**Stage 06「最後の一筆」**：盛る、長さ5、半径1、高度差8、300ステップ。北への給水路を残し、東の低い町への流れだけを堤で止めます。上流にも編集可能な候補があり、そこを止めると浸水は防げても北への給水が途絶えます。単なる全流路の遮断では解けません。

既存COMBINEDは対象町すべての給水・浸水条件を評価する仕様です。そのまま使い、丘上の町は必要2,048・危険水深512、川守の町は必要128・危険水深128を設定しました。川守の取水施設は町の中心より上流にあり、中心を浸水させず給水できます。既存判定に町別の例外は加えていません。

# 7. 進捗保存の仕様

保存キーは`one-stroke-worlds.save.v1`、`schemaVersion:1`。保存するのは順序付きのクリア済みID、最高解放ステージID、流向ON/OFF、軽減設定、Stage 01ガイド表示、地図表示モードです。世界の水量・地形・ストローク・途中ステップは保存しません。起動時は最高解放ステージの新しい世界を生成します。

クリア済みIDはStage 01からの連続した既知ID列に限り、重複・未知ID・順序飛ばし・不整合な最高解放ID・不正な設定・未知スキーマを拒否します。壊れたデータでは初期状態と警告で起動し、読み込みだけで既存データを削除・上書きしません。クリア・設定変更時に保存します。

localStorageの取得・読み込み・書き込み・削除はそれぞれ例外を処理します。保存に失敗してもメモリー内の解放・設定を維持します。再読み込み後までの保持は保証せず、その制約を画面へ通知します。後の書き込みに成功すると保存失敗の警告を解除します。

クリアは通常試行の確定GoalResult、または比較の世界Bの最終成功結果からのみ登録します。途中の取水目標到達では解放しません。フリー実験・デバッグ・世界Aの結果では進捗を変更しません。

初期化は設定のボタンで確認ダイアログを開き、「初期化する」の明示操作時だけ実行します。キャンセル・Esc・ダイアログを開くだけでは削除しません。削除対象は自ゲームのキーだけです。削除拒否時には、その事実とタブ内の初期化を分けて通知します。

# 8. フリー実験モードの仕様

既存3サンプルを新しいTrialSessionで開始し、削る／盛る、一筆のプレビューと実行、PLAY・PAUSE・STEP・RESET、流向と水量の観察を利用できます。1試行1ストロークで、追加の編集を累積しません。チャレンジの町・GoalTracker・進捗は持ち込みません。

フリー実験は「水の観察」「水のようす」、デバッグは「開発用の実験条件」「検証モニター」として役割を示します。共通の既存コアと描画部品を使い、内部状態は試行ごとに独立です。今回フリー実験へのA/B比較、独自地形保存・入出力は追加していません。

# 9. メニュー・画面構成

チャレンジ、フリー実験、ステージ選択、設定、操作ガイド、ゲームへ戻る導線を追加しました。選択画面はPC3列・スマホ2列で、クリア済み・挑戦可能・未解放・現在を文字と記号で区別します。

メニューを開くと既存ランナーと比較を停止し、Pointer操作を解除します。戻っても自動再生しません。モード変更やステージ選択では前のランナーを停止して新規世界を採用します。単一のrequestAnimationFrameは維持し、別の計算タイマーは追加していません。メニュー中は通常計算・比較・結果差分集計を進めません。

通常結果にも取水・浸水のB−A差を表示するため、既存ComparisonControllerで差分を集計します。1フレーム最大4同期ステップに制限し、最終結果を再利用します。メニュー中の集計は止まり、リトライ・モード変更で破棄します。比較画面そのものの同期方式とカメラ、PC左右・スマホ切替は維持しています。

Stage 01では描画・プレビュー・実行・結果・比較の場面に応じて1文のガイドを表示します。設定で非表示にでき、操作ガイドから常に読み返せます。ガイドは計算条件に含みません。

# 15. 既知の問題と次バージョンへの引き継ぎ

- localStorageを無効化・消去した環境や別オリジンでは進捗を引き継げません。保存不可時の継続はタブ内のみです。
- 現行保存スキーマはv1のみ対応。将来ステージの順序変更や移行を行う場合は、明示的なマイグレーション設計が必要です。
- 世界・途中ストロークは保存せず、再起動は最高解放ステージのStep 0です。
- フリー実験の比較・地形保存・複数ストローク編集はありません。
- 既存の水流方向偏りは変更していません。対称性関連テストも実行しました。
- 次版ではスマートフォン実機、OS軽減設定、描画プロファイルの確認を優先できます。

オンライン、アカウント、クラウドセーブ、ランキング、音、3D、独自物理エンジン、地形入出力、Web Workerは追加していません。
