# 4. 地形・水・施設の描画方式

基本色は`MAP_THEME`で管理し、CanvasとCSS変数へ共通適用します。地形は草原#B9D7A2から高地#71966Fへの補間色を用い、左・上の隣接高度差で陰影を付けます。高度モードでは色の差と実際の高度境界線を強調します。通常・高度とも同じ地形配列と同じCellEditを参照します。地形の形状・座標を滑らかに移動させる補間はしません。

水量が正のセルだけ、水#54ADD7を水深に応じた透明度で重ねます。透明度は最大0.85とし、地形を完全には隠しません。水際は光#BCE7F5の線で示します。施設・町は水より後に描画します。高度モードでは水の塗りと矢印を省略し、数値情報では実際の水量を参照できます。

## 実流量の読み取り

`equalizePair`の計算式と更新処理はそのままです。`updateGroup`はその呼び出し前後の実水量と戻り値を観測し、正の移動だけを`{from, to, amount}`として記録します。既存の巡回順で計算し、ステップ成功後に凍結した記録を通知します。記録を取得しない計算とも結果が一致することをテストしています。

保存するのは直近1論理ステップだけです。比較ではA・B両候補の計算・目標観測に成功した場合だけ、両世界の流量も確定します。例外時に片方の候補流量だけが公開されることはありません。RESETは流量も初期化します。

矢印はこの実記録だけから生成し、水面勾配から方向を推測しません。表示密度を抑えるため、盤面サイズに応じた原点セルの間引きと、同じ原点の最大移動1本の選択を行います。流量0、記録なし、両端とも現在水量0の移動は描きません。矢印は全移動の網羅表示や流速ベクトルではなく、「直近ステップで実際に起きた代表的なセル間移動」です。停止中は最後の記録を静止表示します。

施設は水滴入りの丸、菱形の取水、下向き矢印入りの四角の排出口で識別し、町は屋根・窓・扉のある家として別セルに描きます。町の状態は文字を併記します。危険表示には赤系に加えて感嘆符と破線の枠を使います。浸水履歴は水が引いても警告を維持します。危険しきい値の75%以上では表示上の事前注意を出しますが、成功・失敗判定は既存しきい値のままです。

一筆ハイライトには既存`strokeEdits`のCellEdit集合を直接渡します。描画の都合で対象セルを追加・除外しません。削る予定は青系、盛る予定は基準色#C58352で重ね、ラベルでも区別します。残量は編集パネルとCanvas内に表示します。

# 5. PC・スマホの画面構成

PCは左の大きな地図、右のステージ・目標・一筆・実験条件・水量モニターです。地図はスクロール時も追従します。スマホ幅はステージ名と選択を1行に整理し、目標・短い条件、地図、編集・実行操作の順に配置します。ヒントと町の詳細は開閉できます。操作ボタンは最低44px、実行ボタンはスマホ幅で50pxを確保します。固定フッターで地図を覆う構造にはしていません。

Canvasは既存Pointer Events、pointer capture、パン、ピンチとCSSピクセル座標変換を利用します。Canvas内は`touch-action:none`、外側は通常の縦スクロールを維持します。描画解像度の変更は入力座標へ影響しません。

# 6. 比較UIの改善

PCはA/Bを左右、900px以下はBEFORE/AFTER切替を標準にしました。名称・変更有無・論理ステップ・結果を各地図の上に表示します。共通カメラ、地形色の共通尺度、同期ステップを維持します。表示切替で再計算しません。

全体の成功・失敗を最初に示し、取水量と最大浸水深の差をその下に表示します。差分は引き続きB−Aです。給水目標では取水増加、防災目標では最大浸水深減少を改善として示します。今回の目標に含まれない指標は「参考（目標対象外）」とし、改善演出を付けません。複合目標では両指標を評価します。計算条件やGoalResultの判定内容は変更していません。

# 10. 描画性能と既知の制約

Canvasごとに直近の地形色・陰影・境界データをキャッシュします。水量更新だけでは陰影計算を繰り返しません。不変スナップショットでは配列参照が変わるため、キャッシュ判定は高度の値で行います。地形の完全なビットマップキャッシュは行わず、描画時には地形の矩形も再描画します。

DPRは最大2、Canvasの物理辺は最大1,600pxに制限します。演出だけの追加再描画は50ms間隔に抑え、論理ステップ更新・入力の再描画は別途行います。全ステップの流量履歴や複雑な粒子は保存しません。64×64で流量記録は最大8,064隣接ペア/世界/ステップです。現時点では実機FPS・CPU/GPU時間・消費電力を計測していないため、性能保証値は報告しません。

水流の方向偏りは既存のままで、描画変更で解消していません。今回の流量表示は直近ステップの代表移動であり、連続的な流体速度場ではありません。町の小さな文字や64×64での施設は、必要に応じてズームして確認する構成です。
