## 自動テスト

ui-regression.cjsをPlaywrightのChromiumで実行しました。

- 320×568、375×667、390×844、430×932、PC 1280×800：主要UIの画面内配置、本文と選択肢の非重複、2／3個の選択肢の操作を確認。
- Safe AreaはCSS内の値を置換して模擬（小型画面：上20px、大型スマホ：上44px・下34px）。実機の値は未確認。
- 追加ルート解放済みタイトルの表示、長文スクロール、長い選択肢のスクロール・操作を確認。長文はテスト中のみDOMに追加し、シナリオは変更していません。
- セーブなし、破損JSON、null、配列、数値、保存位置なし・未定義・継承プロパティ名でロードを無効化し、新規開始できることを確認。
- セーブ／ロードの往復、既存保存キー・フィールドを確認。
- オート／スキップのメニュー・ログでの停止、閉じた後の再開、選択肢での停止と手動選択後の再開、タイトル・エンディングでの設定解除を確認。
- Enter／Spaceのボタン標準操作、物語の二重進行防止、ログ表示中の進行防止を確認。
- 音量スライダーは本番で無効。テスト中のみ有効化し、矢印キーで調整でき、Enter／Spaceで物語が進まないことを確認。
- touch-action: manipulation、本文のuser-select: none、ログのuser-select: text、ズーム制限なしを確認。
- A／B／C通常ENDのうち2つでは未解放、3つでは解放されることを確認。
- ページのJavaScriptエラーなし。main.js・save.jsの構文検証、git diff --checkも実施。

再実行にはPlaywrightとChromiumが必要です。インストール済みの環境で次を実行してください。

```powershell
node tests/ui-regression.cjs
```

標準の場所にない場合はPLAYWRIGHT_MODULE_PATH（Playwrightモジュールのパス）とCHROMIUM_EXECUTABLE_PATH（ブラウザ実行ファイルのパス）を設定できます。テストは独立したブラウザコンテキストで動作し、利用者の保存データを変更しません。
