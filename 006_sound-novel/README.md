# AI遺産 – Last Memory Protocol

ブラウザで動作するサウンドノベルです。index.htmlを開くか、静的HTTPサーバーで配信してください。

## 操作

- 本文または背景をタップ／クリックすると進みます。文字表示中は全文を表示します。
- Enter／Spaceでも進行できます。ボタン・入力欄にフォーカスがある場合は標準操作を優先します。
- 長い本文と選択肢は、それぞれの領域内でスクロールできます。
- MENUからセーブ、ロード、オート、スキップ、バックログ、タイトルへ戻る操作ができます。
- メニュー・バックログ表示中はオート／スキップによる物語の進行を一時停止し、閉じると設定に従って再開します。選択肢は手動で選んでください。
- タイトル・エンディングではオート／スキップを解除します。バックログの文章は選択・コピーできます。

## 音声について

**BGM・SE処理は未実装です。現時点では音声は再生されません。**
音量スライダーは「音声未実装」と表示し、無効にしています。既存の音量保存フィールドと将来の音声処理用フックは維持しています。

## 保存

保存キーは既存の ai-legacy-mvp-save のままです。currentId、endings、read、truthUnlocked、volumeの形式を維持します。既存仕様として既読・エンディング記録も同じデータに保存されます。
保存が存在しない場合、JSONが壊れている場合、保存位置が不正な場合はロードを無効表示にします。「はじめから」は利用できます。
A／B／Cの通常END到達による追加ルート解放条件は変更していません。
