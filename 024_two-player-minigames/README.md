# ふたり対戦ミニゲーム 共通設計

このゲーム集は、1台のスマートフォンを机に置き、2人が端末を上から見ながら向かい合って遊ぶことを基本とする。

## 収録ゲーム

- 01 トントン相撲DX
- 02 綱引きバトル
- 03 爆弾押し付け
- 04 よろよろボクシング

## 画面と操作

- スマートフォンは縦向きのまま遊べるようにし、横向きへの切り替えを要求しない。
- プレイヤー1の操作領域は画面上端、プレイヤー2の操作領域は画面下端に置く。
- 上側のプレイヤーが読む表示や操作ボタンは、必要に応じて180度回転する。
- 重要な操作は各プレイヤー側の端へ寄せ、相手の手と交差しないようにする。
- 操作領域・得点・残り時間・危険表示は、画面中央を軸に上下対称に配置する。
- 片側だけに情報バーや余白を置かず、両プレイヤーから見える情報量と距離をそろえる。
- 戻る・音量などの共有環境ボタンは対戦盤から独立させ、左右中央の画面端へ対称に置く。
- 共有環境ボタンは端末のセーフエリア内へ完全に収め、44px以上の操作領域と盤面に埋もれない輪郭を確保する。
- 連打操作で画面が拡大しないよう、viewport・touch-action・ダブルタップ／ジェスチャー抑止を共通画面へ適用する。
- ゲーム選択画面は画像を並べず、ゲーム数が増えても一覧性を保てるコンパクトな行形式にする。

## ゲーム内の視点

- 盤面やキャラクターは、机上の端末を真上から見た視点を基本にする。
- キャラクター画像は俯瞰ではなく、原則としてカメラが真上90度にあるトップダウン表現にする。
- 操作キャラクターなどゲームの主役になる要素は、簡易図形で済ませず、ゲームごとに専用の画像素材を作成して使用する。
- 対戦する2体は同じ画風・縮尺・姿勢・中心軸で揃え、色以外の見た目に有利不利が出ないようにする。
- 横視点・正面視点・背景に地平線のある画像を盤面上の操作キャラクターへ使用しない。
- 2人の進行方向、当たり判定、演出は画面中央を軸に対称になるよう設計する。
- 青側は画面上、赤側は画面下とし、キャラクターはそれぞれ自分の色の側から中央へ進む。
- 押し合いでは青キャラクターが上から下へ、赤キャラクターが下から上へ移動する。
- 綱引きでは綱を上下方向へ置き、P1が上、P2が下から中央へ向かって引く。P1入力は下側のP1勝利線へ、P2入力は上側のP2勝利線へ中央リボンを進める。
- 爆弾押し付けではP1が上から下へ、P2が下から上へ爆弾を押し、爆発時に爆弾がある側を敗者とする。
- よろよろボクシングでは同一のトップダウン胴体画像を両者に使い、肩・肘の4関節を個別操作して拳の軌道を作る。専用パンチボタンは設けない。
- 新しいゲーム固有の物理・描画・入力状態は `js/games/` の独立モジュールに置き、共通のカウントダウン・スコア・再戦・サウンド・画面遷移を再利用する。

## よろよろボクシングのテストモード

ゲーム選択画面または対戦画面の `TEST OFF` ボタンを押すと有効になる。時間制限なしでプレイでき、P1/P2それぞれの左右の肩・肘角度を度数で確認できる。もう一度押すと通常モードへ戻る。`index.html?test=1` から直接有効化することもできる。
