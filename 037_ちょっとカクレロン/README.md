# ちょっとカクレロン

Version **0.1.0 — BASE**。iPhone Safariの縦画面を主対象とする、カクレロンの配置操作確認版です。

## 起動

`index.html` をブラウザで開いてください。HTML・CSS・JavaScript・SVGのみで動作し、ビルドや依存ライブラリは不要です。GitHub Pagesなどの静的配信にもそのまま配置できます。

## ファイル

- `index.html`：画面、画像選択、調整ボタン。
- `style.css`：スマートフォン向けレイアウト、Safe Area対応。
- `app.js`：画像読込、Canvas描画、座標管理、Pointer Events。
- `assets/kakureron.svg`：白一色の顔なし人型シルエット。
- `tests/app.test.cjs`：DOM・Canvas代替を使う操作ロジックの内部テスト。

## 操作

1. 「画像を選ぶ」で写真を1枚選択。画像全体を縦横比を保って表示します。
2. カクレロンから1本指／マウスでドラッグして移動します。
3. 1本目をカクレロンに置いたまま2本目を添え、ピンチ・ひねりでサイズと角度を変えます。2本指の中心移動でも移動できます。
4. 下部の「−」「＋」で画像幅に対するサイズを2ポイントずつ変更（5〜60%、初期18%）。回転ボタンは5度ずつ変更します。
5. 「リセット」は写真を保持し、中央・18%・0度に戻します。「画像変更」も新画像の読込成功時に配置を初期化します。

Canvasにキーボードフォーカスがあると、矢印キーで位置を1%ずつ動かせます。キャラクターの中心は写真の範囲内に制限し、輪郭の写真外部分はクリップします。白い写真の上では白いキャラクターが見えにくくなります。

## プライバシー

写真は `URL.createObjectURL` と `Image` を使ってメモリー内で読み込み、Canvasに描画します。読込後はObject URLを解放します。外部送信、fetch、解析ツール、アカウント、永続保存は実装していません。CSPでも `connect-src 'none'` としています。ページを再読み込みすると写真と作業状態は消えます。

## 検証

`node --test tests/app.test.cjs` で内部テストを実行できます。FIT表示、画像読込と変更・エラー、ドラッグ、ピンチ、回転、サイズ制限、リセット、指を離した後の処理、リサイズ時の相対座標を対象にしています。DOM・Canvasの代替による検証で、実ブラウザの描画やOSの写真選択画面を保証するものではありません。

今回の環境ではブラウザ操作ツールが接続できず、PCブラウザの画面・ファイル選択操作は未確認です。

## iPhone Safariでの受入確認

- [ ] 起動し、写真ライブラリから画像を1枚選べる。
- [ ] JPEG・PNG、縦長・横長・正方形、向き情報付き写真を正しい向き・比率で全体表示する。
- [ ] 中央に白いカクレロンを表示する。
- [ ] 1本指で移動し、ページスクロールや長押しメニューが競合しない。
- [ ] 2本指のピンチ・回転が動く。片方／両方の指を離し、再操作しても位置が跳ばない。
- [ ] サイズ・回転ボタンが動き、リセットで写真を残して配置を初期化する。
- [ ] 画像変更、同じ画像の再選択、選択キャンセル、非対応画像からの復帰ができる。
- [ ] 端末回転・Safariツールバーの開閉でも配置の相対位置が維持される。
- [ ] 下部操作がSafari UI・ホームインジケーターと重ならない。
- [ ] ページ全体の拡大・読み上げを妨げない。
- [ ] 開発者ツールで写真の外部送信がない。

## Version 0.2.0 — CAMOUFLAGEへの引き継ぎ

位置は写真幅・高さに対する正規化座標、サイズは写真幅比、角度はラジアンとして `character` に保持しています。`drawCharacter()` に変換と白ベース描画を集約しているため、同じ変換内でSVGをSilhouette Maskに使い、White Base・Paint Layerを重ねられます。ペイントを追加する際は画面座標からキャラクターのローカル座標への逆変換と、配置操作との入力モード分離を追加してください。現版にはペイント・スポイト・保存・共有機能は含めていません。
