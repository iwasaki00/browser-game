# v2.0.0-rc.3 — BEGINNER TUTORIAL

## Plan / Tasks

既存のMISSION GUIDE、発射入力、Canvas、惑星ドラッグ、SCANNER、予測と固定1/120秒の物理を再利用する。練習は同一オリジンの独立iframeで実行し、本編画面を保持したまま一時停止する。終了時はiframeを破棄し、開始前の画面・ゲーム状態へ戻す。

- 本編：既存の設定・進行・記録を維持。練習用のキーだけ追加。
- 練習：設定・進行はメモリ内。IndexedDBを接続せず、移行・航行保存を行わない。
- STEP1：実発射。STEP2：角度と推力を変えた実再発射。
- STEP3：本物の固定ステップで速度方向が5度以上変化し、ユーザーが予測を確認。
- STEP4：惑星の選択・移動と、実エンジンによる予測の差分・ユーザーの確認。
- STEP5：SCANの明示的な対象選択と実際の情報表示。
- STEP6：練習用の方針・目的地選択、実航行・ステーション反応・ログ確認・目標到達。
- 成功後も次へはユーザー操作。スキップと成功は別保存。全STEPにヒント・もう一度・スキップ・終了。

## Build

純粋な進行モデル、練習データ、ゲームへの読取アダプタ、親画面の案内UIを分離する。iframeの通信は同一オリジン・送信元・セッション・STEP世代を確認し、古いイベントを採用しない。再読み込みは保存済みSTEPの開始状態から任意で再開し、飛行途中の復元とはしない。
