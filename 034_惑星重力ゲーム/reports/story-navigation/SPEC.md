# rc.4 STORY NAVIGATION 仕様

## 既存実装との統合

MISSION GUIDEのヘッダーと同じ詳細ダイアログを利用する。HOMEWARD時だけ目的カードを広くし、盤面・下部操作領域の高さは変えない。詳細の「現在の目的」「航海日誌」「進行」を切り替える。CLASSIC/FREEと既存チュートリアルは従来の案内を維持する。

詳細を開くと、既存MISSION GUIDEと同じく航行は一時停止する。閉じると同じ状態から再開。「場所を見る」は詳細を閉じてSCANの滑らかな視点移動を開始するため、飛行中なら通常の航行も再開する。移動・到達・調査を達成扱いにしない。

## データ源と情報公開

| 表示 | 既存情報源・公開条件 |
|---|---|
| 現在の章 | HOMEWARDのcurrentSector |
| 通過した宙域 | 有効なcleared ID。重複・未知IDは数えない |
| 章の一覧 | currentSector、cleared、journal、該当宙域のenter記録がある章だけ |
| 最終章の段階 | finalVoyage.chaptersに記録済みの段階だけ |
| 出航・発見・到着 | journalに保存されている文のみ。静的な到着文を未達成履歴へ生成しない |
| 旧encounter説明 | encountersの達成記録がなければ「宙域の説明・確認待ち」。実遭遇と断定しない |
| 天体・信号 | frontier/deep.targetsのDETECTEDまたはINVESTIGATEDのみ |
| 手掛かり | echoes.cluesに取得状態があるCLUEのみ。関連IDも取得済みだけ |
| 通信 | 保存済みイベントとその解放フラグを照合。未取得CLUEの通信を隠す |
| 結末 | 有効な取得日時が保存されている結末だけ。未取得の名称・総数は出さない |
| CINEMATIC | 保存済み参照IDだけを既存ギャラリーへ渡す。新しい航行を捏造しない |

あらすじは、取得済みの通信・照合・解析を短い最大3文へ整理し、通過数と保存された最近の記録を添える。未解決の謎は既知の手掛かりからだけ作る。将来の出来事を予告するための固定文は追加しない。

## 日時・順序

保存されている数値の日時だけを採用する。欠落・文字列・不正値へ現在時刻を補完しない。日時付きは新しい順、切替で古い順にもできる。日時不明は別枠とし、投影モデル内の記録順を使う。異なるデータ群の厳密な発生順を復元したとは扱わない。時刻のない記録が最後の場合、あらすじにも「保存順で最後」と記載する。

## 目的とヒント

既存missionGuideの判定・操作先・操作可否を再利用する。完了・任務未達・再試行・航行中・判断・解析・準備を区別。調整済みならANGLE/THRUSTの再調整を要求せず発射を案内する。解析・新航路確認は任意とし、現在の帰還目的を上書きしない。

ヒントはボタンでLEVEL1→2→3と進み、最後で停止する。自動展開しない。閉じる操作で戻せる。目的・宙域・状態・発射方式が変わればリセット。LEVEL1は使う画面、LEVEL2は現在の対象・目的、LEVEL3は具体操作。最適な発射入力を含めず、保存や物理へ書き込まない。

## SCAN

日誌に公開でき、かつ現在の宙域でscanObjectsが公開している同じ対象だけにボタンを付ける。別宙域の過去の対象は日誌として読めるが、この画面で位置を表示しない。クリック時にも最新の公開状態を検査する。

「天体情報」は既存SCANの実パネルで該当対象を選ぶ。「場所を見る」は同じ対象への既存ScannerCamera.showを利用する。カメラは約300msで移動し、パン・ピンチで中断できる。既存の「視点を戻す」で開始位置・倍率へ戻る。船・初速・目的地・経過時間・調査フラグを直接変更しない。

## 保存・性能

新しい保存形式・キー・DBは追加しない。HOMEWARD v1と既存のIndexedDBを読み取るだけ。日誌は開く／タブを切り替えた時だけ生成し、閉じた通常画面では毎フレーム再構築しない。通常の案内更新は既存200ms制限と差分更新を維持する。

性能測定で、広域表示が128領域の星空LRUを超えて循環再生成する既存問題を確認した。直前の視点で描いた星の一覧を4096星まで1件だけキャッシュする。領域LRUは128件のまま。視点・ワールド・倍率・品質・シードが変わると無効化する。乱数・星の座標・色・密度の式は変更しない。物理計算に接続しない。

## 操作手順

HOMEWARDを開く→ヘッダーの目的カードを押す→航海日誌で出来事をタップ→必要なら情報・場所・保存記録を確認→閉じて航行。迷った場合は「現在の目的」でヒントを段階的に開く。進行タブで通過済み・現在の章を確認する。
