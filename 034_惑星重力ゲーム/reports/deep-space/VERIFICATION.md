## 5. 航路選択

DIRECT RETURNは帰還中継点、SAFE VOYAGEは検出済みの空白域側の中継候補、DEEP EXPLORATIONは近い未調査反応を選ぶ。方針・目標は可逆で、飛行中にも変更できる。方針は目標候補の選択に留まり、自動操縦・自動回避ではない。詳細は [DESIGN.md](DESIGN.md)。

## 7. 実航路検証

**18区間すべてCLEAR。各区間で1倍と100倍の全終端状態・ステップ数・発見結果が一致し、予測終端と実航行終端が厳密一致。** 全部、既存物理エンジンが選択目標へ接触して成功した。到達判定の強制・ワープは使用していない。

以下は6本の対象往復例。すべてTHRUST 220、初期惑星配置。時間は航行秒。帰還の発射位置は寄港地点の安全な出航位置。

| 代表航路 | 往路ANGLE / 時間 | 帰還ANGLE / 時間 |
|---|---|---|
| 入口→DS01→帰還 | −45° / 11.075秒 | −41.06° / 47.208秒 |
| 入口→DS02→帰還 | −38.22° / 23.258秒 | −45.01° / 34.900秒 |
| 入口→DS03→帰還 | −17.15° / 34.233秒 | −64.65° / 28.242秒 |
| 入口→DS04→帰還 | −32.33° / 45.650秒 | −72.65° / 14.725秒 |
| 入口→DS05→帰還 | −48.08° / 39.242秒 | −24.23° / 19.442秒 |
| 入口→DS06→帰還 | −71.57° / 34.192秒 | −6.59° / 34.258秒 |

個別の往路検証は各目標を検出済みとして幾何的到達性を確認する。それとは別に、実際の解放条件に従う連続プレイ **入口→DS01→DS02→DS03→DS04→DS05→帰還→DS06→帰還** を検証し、途中で再読み込み・正規チェックポイント復元・全6調査・情報報酬を確認した。直接帰還も検証済み。

全18区間の発射位置・角度・推力・時間・終端座標は [ROUTES.md](ROUTES.md)。任意の全地点間の直行を保証するものではない。DS05→DS06の直行は確認できなかったため、中継点経由を攻略例とする。惑星を動かしたら予測で航路を再設計する。
