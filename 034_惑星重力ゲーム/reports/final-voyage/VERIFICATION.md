## 3. 最終ストーリー

観測網は未来の予測器ではなく、時空異常を通る船の航行情報を異なる時間軸へ転送していた。古い記録と72時間先の時刻は、同じ時間基準で読めなかった。本船と一致する識別列には、別の航路を選んだ本船の情報が重なった可能性がある。

イサリの乗員が本船そのものだったとは断定しない。帰還・救難・解明・異常調査・探索継続で異なる答えを残す。既存の「矛盾がある」「発信元の船が確認できない」という文章は調査段階の観測として維持した。

THE LAST SIGNAL → THE OBSERVATION NETWORK → THE CHOICE → THE FINAL APPROACH → HOMEの5章。短い通信、マップ、日誌で提示し、通信の再確認・結末の再閲覧を実装した。[詳細仕様](DESIGN.md)。

## 4. 5種類の結末と成立条件

すべて、選択した目標への**実際の物理到達成功**が必要。失敗・判断ボタンだけ・別地点への接近では付与しない。条件不足は理由を表示し、別の結末に自動変更しない。

| 結末 | 最終判断 / 実到達先 | 追加条件 |
|---|---|---|
| END-01 HOMEWARD | home / 地球 | なし |
| END-02 RESCUE | rescue / 地球 | 最終救難地点への到達、または旧Sector09の救助済み寄港 |
| END-03 THE TRUTH | truth / 地球 | CLUE-01/02/03/06/07/09、DS02/03/06調査済み、final-voyage-chart、中枢到達 |
| END-04 THE OTHER SIDE | other / 異常の通過地点 | 中枢到達 |
| END-05 ENDLESS VOYAGE | continue / 外縁観測点 | なし。探索を継続し、他の結末を封鎖しない |

救難・真相条件が両方成立していても、homeで到達すればEND-01。truthを選んで情報不足のまま地球へ着いてもEND-01へ振り替えず、寄港と不足理由を表示する。

END-04では本船の声を含む転送記録を受信し、選ばなかった航路を観測する。青紫の交差する光輪は描画のみで、ロケットを異世界へ強制移動しない。

## 6. 代表航路と攻略入力

すべてTHRUST 220、初期惑星配置。時間は航行秒。詳細な各区間の入力・終端座標は [ROUTES.md](ROUTES.md) / [routes.json](routes.json)。

| 目的 | 入力・航行 |
|---|---|
| 直接帰還 / END-01 | 入口→地球：144.02°、56.475秒 |
| 救難後帰還 / END-02 | 入口→救難：109.65°、13.050秒 → 地球：151.91°、45.317秒 |
| 真相 / END-03 | 主要手掛かり所持で開始。入口→中枢：117°、26.500秒 → 地球：161.03°、33.917秒 |
| 異常調査 / END-04 | 入口→中枢：117°、26.500秒 → 通過点：−163.81°、14.142秒 |
| 探索継続 / END-05 | 入口→外縁観測点：175.43°、33.850秒 |
| 比較的安全な外縁迂回 | 入口→北側中継：−177.59°、42.833秒 → 外縁待機：77.28°、28.333秒 → 地球：138.37°、10.583秒 |

直接航路は約12533単位・56.475秒、異常の作用範囲を通り最小余裕約506。外縁迂回は約17974単位・81.750秒、最小余裕約1065。短距離側と遠回り側で、時間と危険天体からの距離に差がある。中枢・異常を経由する追加調査も成立する。

## 9. 保存互換性

HOMEWARD v1キーとversionは維持し、任意の `finalVoyage` を追加。旧Sector・voyage・frontier・echoes/CLUE・CLASSICキーを維持。読み込みだけでは書き込みせず、結末を旧進行から推定付与しない。

追加保存は章・通信、現在の判断と履歴、寄港地、調査/救難、取得済み結末と日時、記録参照。重要な初回通信は多数の判断で押し出されないよう保持する。詳細は [DESIGN.md](DESIGN.md)。

専用IndexedDB version1のまま、`ending:END-0x:first` と `final:dock:<id>:first` を追加。既存のimmutable初回保存・最大3回再試行を再利用。通常ギャラリーの整理から独立する。保護する結末航行は最終区間で、前の中枢/救難への区間も初回寄港として別途保護し、日誌から再生できる。

PC Chromeの隔離データで、結末別の専用記録、旧重要記録とお気に入りの非破壊、CLASSIC用キー保持、再読み込み、CINEMATIC再生を確認した。利用者の実保存データの削除・初期化は行っていない。
