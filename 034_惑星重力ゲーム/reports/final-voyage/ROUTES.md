# v1.9.0 攻略入力と到達結果

## 結末ごとの例

- **END-01**：homeを選択。入口から地球へ **144.02° / 220 / 56.475秒**。
- **END-02**：rescueを選択。入口→救難地点 **109.65° / 220 / 13.050秒**。地球を選び直し **151.91° / 220 / 45.317秒**。
- **END-03**：主要CLUEとDEEPの航路情報を持つ状態でtruthを選択。入口→中枢 **117° / 220 / 26.500秒**。地球を選び直し **161.03° / 220 / 33.917秒**。
- **END-04**：otherを選択。入口→中枢 **117° / 220 / 26.500秒**。通過地点を選び直し **−163.81° / 220 / 14.142秒**。
- **END-05**：continueを選択。入口→外縁観測点 **175.43° / 220 / 33.850秒**。その後homeを選び **108.92° / 220 / 33.000秒**で地球へ戻り、END-01も取得できる。

END-01/02/04/05の例は手掛かりなしで最終章に入る開始状態、END-03だけは既存の主要手掛かりと `final-voyage-chart` を所持する開始状態。取得条件は [DESIGN.md](DESIGN.md)、実際の開始データと各航行入力は [ending-results.json](ending-results.json) / [ending-start-summary.json](ending-start-summary.json) に記録。

## 三つの航路方針

- 短距離側：入口→地球。約12533単位、56.475秒。異常の作用範囲を通り、最小余裕約506。
- 外縁迂回：入口→北側安全中継点→外縁待機点→地球。約17974単位、81.750秒。最小余裕約1065。直接航路より長いが、危険本体との間隔はこの検証では2倍以上。
- 調査航路：入口→観測網中枢→異常の通過地点。転送の仕組みを解明して境界を観測する。通過点から地球への帰還も145.31° / 220 / 22.992秒で検証済み。

## 失敗例と再挑戦

中枢から通過点へ **−165.96° / 220** で発射すると、約12.925秒で異常の危険中心へ衝突する。`crashed / encounter-unknown` となり、END-04を付与しない。失敗例でも1倍／100倍と予測結果が一致する。[failure-example.json](failure-example.json)。

結末後も現在の寄港地から別の目的地へ発射できる。同じ寄港地の判断ボタンだけで結末を取り直すことはできない。いったん再出航し、実際に到達する。以下の連続再挑戦も検証済み：探索継続→帰還→救難→帰還→中枢→異常→帰還。[retry-results.json](retry-results.json)。

惑星を移動した場合は参考入力をそのまま保証せず、予測で調整する。任意の全地点間・全配置の攻略を保証するものではない。

すべて初期惑星配置・固定刻み1/120秒の実航行。自動成功・ワープは使用していない。ANGLEは度、時間は航行秒、座標・距離はワールド単位。

19区間で1倍／100倍の終端状態・ステップ数が一致し、予測と実航行の終端も厳密一致した。表の最小余裕は各物理ステップで測った「ロケットと危険本体表面の間隔」であり、端末操作の安全を保証する値ではない。
