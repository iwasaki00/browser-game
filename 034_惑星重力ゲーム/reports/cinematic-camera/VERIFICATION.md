## カメラ演出と判定

| 場面 | 構図 |
|---|---|
| 発射直後／発射準備 | ロケット中心、目標1.15倍へ滑らかに接近 |
| 通常航行 | 速度ベクトルの先へ視点を寄せ、進行方向に余白を作る |
| 高速航行 | 物理速度の上昇に応じて広角化。速度倍率も構図に反映 |
| 惑星接近・スイングバイ | ロケットと主要惑星を含む構図。危険領域の半径も考慮 |
| ゴール接近 | ロケットとゲートを含む構図を優先 |
| ゴール到達 | ロケット付近へゆっくり寄る。目標倍率は1.35倍、ゲートが収まる範囲に制限 |

判定は位置・速度・経過時間・距離・惑星半径と危険領域から行います。固定のステージ座標やステージIDで切り替えていません。優先順位は以下です。

```text
到着・終了 > ゴール接近 > 惑星接近・離脱 > 発射直後 > 高速航行 > 通常航行
```

- 世界サイズ係数：`sqrt(max(width / 375, height / 500))`、1〜sqrt(10)に制限。
- 惑星への接近開始距離：`max(180 × 世界サイズ係数, 惑星・危険領域の最大半径 × 4)`。
- ゲート接近開始距離：`max(240 × 世界サイズ係数, ゲート半径 × 4)`。
- 接近開始後は1.35倍の距離まで同じ対象を維持。複数惑星の候補は距離／接近範囲で比較しますが、接近中に別の惑星へ頻繁に切り替えません。
- 高速の開始は物理速度320超、解除は260以下。速度はワールド単位／シミュレーション秒です。
- スイングバイ専用に物理イベントを作り直さず、同じ惑星を接近から離脱まで映すことで旋回の連続性を保ちます。既存のSWINGBY演出は維持。

## 位置とズームの制御

表示時間に対する指数補間で位置・倍率を更新します。位置の時定数0.30秒、対数ズームの時定数0.48秒。通常のズーム変更は滑らかに行い、拡大は常に補間します。ズーム上下限は0.1〜3.0倍、中心位置のワールド境界制限は既存カメラを使用します。

注目対象を含めた目標倍率を計算し、右上ミニマップと下部操作に余白を確保します。接近対象を取り込む際には構図を滑らかに変更するため、対象が入った瞬間から完全に同時表示されるとは限りません。

100倍等で1描画フレームの移動量が大きい場合は、補間による遅れでロケットを見失わないことを優先します。必要な縮小を先に適用し、最小倍率でも不足する場合は中心位置を表示可能な位置へ最小限補正します。この保護が働く場面は通常の補間より速く構図が変わります。物理位置は変更しません。

## 高速航行と負荷

- カメラ制御は描画フレームに1回。1/120秒の各物理ステップからは呼びません。
- 航行倍率の平方根に応じて目標倍率を下げ、50／100倍で広い空間を映します。
- 既存の物理ステップ繰越・最大240ステップ／4ms目安の実行予算は変更していません。
- 純粋シミュレーション比較では、同じ2130ステップを1倍で1065表示フレーム、100倍で11表示フレームに分けて処理。カメラ更新もそれぞれ1065／11回でした。
- 実時間のPC Chrome測定ではカメラ更新14サンプル、平均約0.13ms、最大約0.20ms。カメラ制御部分だけの値で、物理・星空・全描画を含みません。短時間のPC測定であり、iPhoneの性能保証ではありません。

## 手動操作・復帰

| 操作 | 動作 |
|---|---|
| 空白をタップ／6px未満の移動 | CINEMATICを維持 |
| 空白を1本指で6px以上ドラッグ | FIXEDへ移り、自由にパン |
| 2本指ピンチ／2本指ドラッグ | FIXEDへ移り、自由にズーム・パン |
| ＋／− | CINEMATICを解除しFIXEDへ。FOLLOW時の既存挙動は維持 |
| 全体 | OVERVIEWへ |
| メニュー → カメラ → CINEMATIC | 現在のロケット状態から自動演出を再開 |
| RESET | CINEMATICでは同モードを維持し、発射地点の構図へ。既存モードのRESET挙動は維持 |

惑星の選択・移動・スリングショットは既存の対象判定を優先します。UIボタンでカメラのパンは始まりません。メニュー表示中は従来どおり飛行を停止します。カメラ設定は現在のプレイ画面の状態で、保存形式の変更はありません。

## 既存機能への影響・残存課題

物理エンジン・航行速度スケジューラ・予測・Stage01〜20・HOMEWARDデータ・保存処理・ギャラリー記録処理・音声・星空はソース差分なし。カメラからこれらを書き換える処理はありません。既存セーブやIndexedDBを削除・初期化していません。

今回、Stage01〜20全航路・全ギャラリー機能の回帰は再実行していません。物理非干渉・記録一致の直接確認と、変更対象外モジュールの差分確認を行っています。

残る確認はiPhoneでの補間の感じ方、100倍時の構図補正、ピンチとの切替、持続性能と発熱です。高速時は表示フレームが少なく、短い演出段階が画面に現れない場合があります。次の調整は実機結果を基に判定距離・補間時定数・構図の余白設定に限定して進められます。
