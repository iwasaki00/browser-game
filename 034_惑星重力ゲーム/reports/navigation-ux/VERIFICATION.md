## 2. 航行速度

- 飛行中だけ盤面左下に1／2／5／10／50／100倍の選択を表示。ネイティブselectの高さは44px。右下のカメラ操作とは重なりません。
- 通常・新しい発射・飛行終了・RESETは1倍。ギャラリーの0.5／1／2／4倍とは独立。
- `DEFAULT_PHYSICS.fixedTimeStep` の1/120秒をそのまま渡し、各ステップで既存 `stepLiveFlight` を実行します。重力・移動惑星・衝突・危険領域・ゴール・時間上限の判定を省略しません。
- 記録・接近演出の観測・惑星移動距離も毎ステップ処理。描画はrequestAnimationFrame単位。
- 1フレームは最大240ステップ、処理群の時間予算は4ms。時間予算はステップ間で確認するため、単一ステップやGCによる超過を完全には防げません。
- 未処理のシミュレーション時間は繰り越します。処理予算不足によるステップの飛び越し・近似はありません。倍率を変更すると実行枠を更新し、前の高速設定の実行枠で急加速し続けることを防ぎます。
- 表示する実効倍率は直近約0.5秒の実行物理時間／実時間。倍率変更直後は「計測中」。短時間で終了した飛行では数値表示前に終わる場合があります。
- 設定パネル・ギャラリー・HOMEWARD画面の表示中は従来同様に飛行を停止。バックグラウンドから復帰した時間を大量の新規飛行時間として加算しません。

倍率はシミュレーションの進む速さです。重力操作モードで同じ実時間に指を動かすと、異なるシミュレーション時刻に操作が入ります。比較試験では惑星移動目標も同じシミュレーション条件にそろえています。

## 3. 星空

500×500ワールド座標の領域ごとに、領域座標と固定シードから疑似乱数を生成。各領域に70〜219個の候補を置き、ランダム分布と局所的な密集を混在させています。大きさ、明るさ、淡い4色を変化させ、従来の時間による漂い・格子線を廃止しました。

画面に交差する領域だけを参照し、最大128領域をLRUキャッシュします。縮小時は固定したランダム順位で表示対象を絞り、軽量設定ではさらに半減。ズームで星の数は変化しますが、残る星のワールド位置は変わりません。カメラ往復・キャッシュ破棄後の再生成でも同じ座標と色です。

## 4. マップ操作

| 操作 | 動作 |
|---|---|
| 空白をタップ／6 CSS px未満の移動 | 選択解除。FOLLOWは維持 |
| 空白を6 CSS px以上ドラッグ | 1本指パン。FOLLOW／OVERVIEWからFIXEDへ |
| 惑星をタップ | 選択・リング表示 |
| 編集可能な惑星をドラッグ | 既存の配置制約に従って移動。カメラは移動しない |
| 軌道設計モードの飛行中に惑星をドラッグ | 惑星は動かない。空白のパンは利用可能 |
| スリングショットでロケットを引く | 既存の発射操作を優先 |
| 2本指 | シングル操作をキャンセルし、ピンチ／パンへ。全指を離すまで誤発射を防止 |
| メニュー → カメラ → FOLLOW | 飛行中のロケット追従を再開 |
| 全体 | ワールド全体のOVERVIEWへ |

倍率0.1〜3.0と既存のカメラ中心の境界制限を維持。パンは画面差分を現在のscaleで割ってワールド差分に変換します。UIはCanvas外の要素なので、速度・ズーム・メニュー操作ではパンしません。Pointer Cancel／フォーカス喪失で操作を終了します。

## 8. 既存機能への影響と残存課題

物理・発射ベクトル・予測計算・ステージ定義・セーブ形式・IDB形式は維持。宇宙の境界や惑星の半径・質量はカメラ操作で変化しません。保存済みの画像・再生用記録を書き換える処理は追加していません。ギャラリーの背景表現は今回のプレイ用星空とは独立した既存仕様です。

未確認はiPhoneの実際の指操作・ネイティブ速度選択・安全領域・音声復帰・持続性能と発熱です。高速時は手動での重力操作に使える実時間が短くなります。次の作業は実機結果を基にした処理予算・表示密度の調整を想定し、物理式や既存の進行情報を変更せず進められます。
