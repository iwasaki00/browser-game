# RAGDOLL RUN — Phase 1

Q/W/O/Pで左右の股関節とひざを個別に動かす、横視点の物理ランニング実験です。完走やスコアは設けず、物理人形の操作感の検証に集中しています。

## 起動

リポジトリのルートをHTTPサーバーで配信し、`029_qwop-runner/index.html`を開きます（例: `python -m http.server 8000`）。Matter.jsは`022_pythagora-lab/vendor/matter.min.js`を共有利用します。

## ファイル

- `index.html`: HUD、キャンバス、操作ボタン、デバッグパネル
- `style.css`: 横画面レイアウトとモバイル操作対策
- `physics.js`: Matter.jsの人形、関節、モーター、物理パラメータ
- `game.js`: 入力、描画、追従カメラ、デバッグUI

## 操作

- Q: 右ももを前、左ももを後ろへ
- W: 左ももを前、右ももを後ろへ
- O: 右ひざを曲げ、左ひざを伸ばす
- P: 左ひざを曲げ、右ひざを伸ばす

画面ボタンもPointer Eventsによるマルチタッチ同時押しに対応します。倒れても操作可能です。RETRYはページ再読込なしで人形、速度、関節、カメラ、距離を初期化します。

## 物理構造

頭、胴体、左右の太もも・すね・足を独立Bodyとし、首、股関節、ひざ、足首をConstraintで接続しています。自己衝突を無効にし、人体らしい関節可動域をトルクで制限します。胴体には弱い姿勢維持トルクだけを加えています。

| パラメータ | 初期値 |
|---|---:|
| 重力 | 0.45 |
| 地面摩擦 | 0.92 |
| 足の摩擦 | 1.15 |
| 股関節トルク | 0.00520 |
| ひざトルク | 0.00440 |
| 関節減衰 | 0.42 |
| 姿勢維持トルク | 0.00115 |

DEBUGではBody輪郭、関節位置、重心、速度、胴体・股関節・ひざ角度、FPSを確認でき、全パラメータをリアルタイム調整・リセットできます。

## Phase 2前の調整候補

- 足裏の引っかかりと摩擦を実機で確認
- 股関節と姿勢維持トルクの比率を調整
- 高リフレッシュレート端末で関節制限を比較
- 必要なら接地判定による足裏摩擦切り替えを追加

100mゴール、タイマー、ハイスコア、音、キャラクター選択等はPhase 1には含めていません。
