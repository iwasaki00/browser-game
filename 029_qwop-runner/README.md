# RAGDOLL RUN — Phase 1A

Q/W/O/Pで左右の股関節とひざを個別に動かす、横視点の物理人体・関節制御テストベンチです。Phase 1Aでは歩行性能より、10秒以上の直立安定と入力に対する明確な関節反応を優先しています。

## 起動とテスト

リポジトリのルートをHTTPサーバーで配信し、`029_qwop-runner/index.html`を開きます。Matter.jsは`022_pythagora-lab/vendor/matter.min.js`を共有利用します。

```sh
node 029_qwop-runner/tests/phase1a.test.cjs
```

## 操作

- Q: 右股関節を前、左股関節を後ろへ
- W: 左股関節を前、右股関節を後ろへ
- O: 右ひざを曲げ、左ひざを伸ばす
- P: 左ひざを曲げ、右ひざを伸ばす

キーボード、画面ボタン、DEBUG内のCONTROL TESTは同じ`inputState`を更新します。Pointer Eventsによるマルチタッチ同時押しに対応します。

## 物理構造

頭、胴体、左右の太もも・すね・足を独立Bodyとして、首、股関節、ひざ、足首をConstraintで接続しています。同一キャラクター内の自己衝突は無効、地面との衝突は有効です。初期化時は左右対称の姿勢を生成し、全Bodyの速度・角速度・力・トルクを0へ戻します。

胴体、股関節、ひざ、足首は固定せず、物理更新周期内のPD制御で目標角度へ追従します。股関節・ひざは親Bodyとの相対角度を`atan2(sin(angle), cos(angle))`で正規化して使用します。足首支持点と胴体の水平差にも弱いPD補助力を加えています。

## 推奨初期値

| パラメータ | Kp | Kd | Max Torque |
|---|---:|---:|---:|
| Torso | 0.15 | 0.08 | 0.20 |
| Hip | 4.00 | 0.30 | 4.00 |
| Knee | 6.00 | 0.40 | 6.00 |
| Ankle | 4.00 | 0.30 | 4.00 |

- 重力: 0.72
- 地面摩擦: 1.05
- 足摩擦: 1.35
- Joint Limit Strength: 20.0
- Balance Kp / Kd / Max Force: 0.0020 / 0.020 / 0.10

関節制限は股関節`-60°～+60°`、ひざ`-6°～+92°`、足首`-30°～+30°`です。範囲外ではソフト制限PDが逆方向の補正トルクを加えます。

## DEBUG

DEBUG ONでは入力ON/OFF、胴体角度・角速度、左右の股関節・ひざのCurrent/Target/Torque、座標、速度、FPSを表示します。CONTROL TESTのQ/W/O/Pボタンで1関節系ずつ確認できます。各PD値と摩擦・重力・重心補助は即時変更でき、RESET PARAMETERSで推奨値へ戻ります。

## Phase 1Aの範囲

100mゴール、タイマー、スコア、音、障害物、ゲームオーバー、自動歩行は実装していません。次段階では、現在の強いテストベンチ用安定化を少しずつ弱め、接地脚の切り替えと歩行周期を調整します。
