# すれ違い郵便局 — SORT & SEND

Version **0.1.0 — CORE PLAYABLE**。分岐の循環パターンを組み、荷物を正しい出口へ届ける戦略パズルです。

## 開発環境・起動

Node.js 20.19以降または22.12以降（Vite 7対応版）、npm、TypeScript、Vite、Canvas 2D、HTML/CSS、Vitestを使用します。大型フレームワークは使用しません。

```sh
cd sort-and-send
npm ci
npm run dev
```

ターミナルに表示されるURLをブラウザで開きます。

```sh
npm test           # 関連する単体テスト7件
npm run typecheck  # TypeScript型チェック
npm run build      # 型チェック + Productionビルド
npm run preview    # ビルド結果の確認
```

`sort-and-send/dist/` が静的配信用成果物です。browser-gameの一覧は `sort-and-send/dist/index.html` へリンクします。更新時はビルド成果物も一緒に反映してください。外部サービスへの接続は不要です。開発サーバー単体では親のゲーム一覧を配信しないため、一覧へ戻るリンクの確認はbrowser-game全体を静的配信して行います。

## 操作

1. 分岐Aの2枚の矢印カードをクリック／タップし、L（左）とR（右）を切り替えます。キーボードのTabとEnter／Spaceでも操作できます。
2. 「配送開始」でRED ●、BLUE ▲、RED ●の順に配送します。REDの正解は左、BLUEの正解は右です。
3. 配送中は設定と各操作ボタンをロックします。終了後は正しく届いた個数と各荷物の配送先を表示します。
4. 「再挑戦」で現在の設定を保持したままDESIGNへ戻り、再度「配送開始」を押します。結果画面のカードを直接変更しても設定状態へ戻ります。
5. 「初期設定に戻す」で[L,L]へ戻します。[L,R]がクリアパターンです。

## シミュレーション

`src/stage.ts`が有向グラフと配送順序を定義し、`src/simulation.ts`の`simulate(stage, patterns)`が実行ごとに分岐カウンターを0から開始します。tickは0始まりで、荷物ID順に1tick間隔で出発します。各荷物はtick開始時の位置から最大1エッジだけ移動します。出発tickもSourceから1エッジのみ進みます。同じtickに同じ分岐を通る場合も荷物ID順で処理します。

分岐から送り出す時に現在の矢印を参照してカウンターを循環させます。出口到着後は停止し、誤配送後も残りを継続します。返り値は荷物ごとの経路・配送先・正誤、出発／移動／到着イベント、tick数と集計結果です。入力を変更せず、同一入力から同一結果を返します。Canvasは1論理tickを1秒としてイベントを補間表示し、描画フレームから配送判定を計算しません。
