# 0.5.0-B — HINT：データ検証と文章レビュー

実施日：2026-10-23。対象はStage 01〜20、各3段階、合計60件です。

## 自動検証

`npm run validate:hints`は静的な`src/hints-data.json`と現在のステージを照合します。ヒントに記録した識別子を実行時に自動再生成しないため、ステージ変更による陳腐化を検出できます。

- 全20ステージに1組ずつ、3件の空でない重複しない本文がある。
- ステージIDと既存の`stageFingerprint()`の値が一致する。
- 本文・注目メタ情報が参照する分岐と、明示的な荷物番号・個数が存在する。
- レビューで抽出したL/R接続がグラフと一致する。
- 断定した部分的な枠方向と、例として示す方向の組み合わせが通常成功解の少なくとも1つと両立する。
- 必須通過分岐が全通常成功解の対象荷物の経路に存在する。
- 成功解の証拠は既存のVALIDレポートで識別子・全探索集計を確認し、保持した成功設定も既存エンジンで再実行して検証する。
- HTML記号や連続した完全パターンらしい表記は検出してエラーとする。

結果：**20ステージ・60件 VALID、エラー0件**。通常Solverの全探索をヒント画面で実行せず、成功解を含む検証レポートもゲーム画面には読み込みません。既存のステージ・Solver・検証レポートは変更していません。

自然言語の意味、教育的な段階性、完全解答の推測可能性までは自動判定しません。明示的な検証メタ情報を照合した結果と、次の文章レビューは区別します。

## 発見した問題と承認済み修正

Stage 17 H3の原文：

> Dを通る荷物を変えると、Bの周期も変わります。両方の方向転換コストを確認しましょう。

理由：Bは上流、Dはその下流です。Bの固定3枠の周期はDでの振り分けによって変わりません。Bへの入力列はAの設定で決まります。

ユーザーに提示し、採用を承認された本文：

> 荷物をBから直接届ける場合とD経由で届ける場合を比べ、BとDの方向転換コストを確認しましょう。

提供された60本文との文字列比較では、変更はこの1件だけで、ほか59件は原文と一致しました。ステージやSolverを変更して文章に合わせてはいません。
