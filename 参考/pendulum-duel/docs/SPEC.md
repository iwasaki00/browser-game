# 三重振り子 DUEL

## Goal
ブラウザで三重振り子の予測しにくい動きと、固定・解放の駆け引きを楽しむ。

## Requirements
- CPU戦と同じ画面での2人対戦。
- 3本の等長リンク、固定支点、重力、慣性を位置制約で近似するゲーム用物理。厳密な剛体シミュレーションではない。
- 振り回す長押しで第1関節へ接線方向の力を加える。
- 固定の長押しで関節間距離を保持。最大0.7秒、再使用まで2.8秒。固定中は被ダメージを軽減。
- 先端球と相手コアの接触で速度に応じ7～25ダメージ。同じ攻撃の連続判定を0.48秒抑止。
- HP100、制限60秒。HP0または時間終了で勝敗・引き分けを表示。
- P1 A/S、P2 K/L。タッチは各ボタンを長押し。操作部のダブルタップ拡大を抑止。
- 一時停止、再戦、モード変更、任意の効果音。非表示・フォーカス喪失・画面サイズ変更で一時停止。
- データ送信・アカウント登録・外部API不要。

## Validation
JavaScript構文とアセット参照を確認。PC幅・スマホ幅の物理シミュレーションで数値の有限性、リンク長維持、命中・勝敗を検証。実機ブラウザ操作は未検証。
