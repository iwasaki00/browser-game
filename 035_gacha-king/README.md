# ガチャ王 / GACHA KING

Version 0.1.2 — PLAYABILITY & BALANCE

iPhone Safariを主対象にした、依存ライブラリなしの静的ブラウザゲームです。ガチャで12種類の「へんてこ生物」を集め、即売り・架空フリマ・架空SNSを使って3種類の王を目指します。

Version 0.1.2では抽選率・価格・アイテムIDを維持したまま、周回内の初回種類ボーナスと王冠進捗表示を追加し、人気王の到達条件を調整しました。Version 0.1.0 / 0.1.1のセーブデータをそのまま読み込めます。

## 現行バランス

| 項目 | 仕様 |
| --- | --- |
| 初期資金 | 1,000 G |
| ガチャ料金 | 1回 200 G |
| 資金王 | 有効資金 3,000 G |
| コレクション王 | 現在所持している異なる8種類 |
| 人気王 | 300フォロワー |
| 周回初GET | その周回で初めて入手した種類ごとに150 G |
| 即売り | アイテム価格の100%、待ち時間なし |
| フリマ | アイテム価格の145%、仮想8秒後に成約 |
| 救済 | 200 G未満かつ所持品・出品が空の時に600 G |

排出率は COMMON 45%、RARE 30%、EPIC 15%、LEGEND 8%、MYTHIC 2%です。SNS投稿は同じ所持品につき一度だけで、11～133人のフォロワーを獲得します。SNSからの資金収入はありません。

周回初GETと救済で受け取った支援金は、画面上の所持金として使用できますが資金王の「有効資金」には含まれません。これにより収集の継続を助けつつ、支援金だけで資金王を取ることはできません。

王冠獲得後は、王冠数・発見済み図鑑・演出設定を継承します。所持金・所持品・出品・投稿・フォロワー・周回内ボーナス履歴はリセットされます。

正式画像12枚は `assets/items/henteko-vol01/`、既存IDと素材IDの対応は同フォルダの `manifest.json` にあります。

## 起動

`index.html` を静的Webサーバーで配信してください。ES Modulesを利用するため、`file://` での直接起動ではなく、VS Code Live Serverや次のコマンドが利用できます。

```powershell
py -m http.server 8080
```

その後 `http://localhost:8080/` を開きます。GitHub Pagesではリポジトリ直下を公開元に指定できます。

## テストとシミュレーション

```powershell
npm test
npm run check
npm run simulate
```

`npm run simulate` は資金・コレクション・人気・バランスの4方針を各1,000シードで実行します。フリマ待機は仮想時刻で進めるため実時間を待ちません。この結果はガチャ回数の比較であり、実プレイ所要時間の推定ではありません。調査結果は `docs/BALANCE_0.1.2.md` に記録しています。
