# 0.1.2 — REAL GACHA EXPERIENCE

## 実装

ホームにCSS製のカプセルトイ筐体を配置。透明ドーム、12個のカプセル、正式商品画像3種の見本、コイン投入口、回転ハンドル、排出口、料金・シリーズ表示を実装した。正式画像12種類はそのまま使用し、画像素材・外部依存は追加していない。

Pointer Eventsとpointer captureでハンドルの角度を追跡する。時計回り240度で確定、15度ごとに段階音、見た目は6度単位で追従。未完了の離脱・キャンセル・中心通過で元へ戻す。ドラッグ対象だけ `touch-action: none` を使用し、複数の指による同時操作は一つのpointerIdに制限した。タップとキーボード代替も用意した。

回転確定後に既存抽選を呼び、ドームの揺れ→内部移動→排出口への落下→バウンドを軽量CSSアニメーションで表示する。通常の排出約1.35秒、カプセル待機約0.75秒、開封約0.32秒。じっくりモードは手動開封、サクサクモードは排出・開封を短縮する。高レアでも余分な待機は追加しない。

結果画面で再抽選・保管・即売り・SNS投稿を行える。図鑑進捗、即売り／フリマ価格、投稿フォロワー数を表示する。王冠進捗と周回は専用ダイアログに移した。

効果音はWeb Audioの短い音で合成する。コイン、ハンドル、カプセル移動、落下、開封、レア別獲得音に対応。ユーザー操作でAudioContextを開始し、失敗を捕捉し、ミュート可能とした。

## 保存と互換性

ゲーム状態と演出制御は別モジュール。既存の `draw()` を包む `beginDraw()` は、課金・入手・初発見判定・未表示結果を一回の保存に含める。未表示結果がある間は購入を拒否する。開封済み状態も保存し、ページ再読み込み時に未開封／開封済み結果を復元する。キャンセル可能なのは購入確定前の回転であり、確定後の演出省略は購入を取り消さない。

セーブキー、既存アイテムID、12画像、抽選weight、料金、価格、SNS増加式、王冠条件は以前の0.1.2から変更していない。0.1.0 / 0.1.1 / 以前の0.1.2を読み込む。操作モードとミュートは初期値を補完し、設定として周回継承する。
