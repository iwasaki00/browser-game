# 0.3.3 — MOBILE PLAYTEST & QA 検証

作業日：2026-10-26〜27（日本時間）。既存0.3.2のタッチ・HUD・5タブ・通常攻略QA・profilerを調査し、実機で確認するための道具を追加した。**iPhone Safari実機の受入試験は未実施**。

## 実装

- 「計測」へ手動30秒計測・結果一覧・コピーと、折りたたみのIP-01〜08チェックを追加。
- 既存のライブFPS／6秒BENCHとは別の`js/mobile-playtest.js`を使用。250ms超を無条件に除外せず、500／1000／1500msの前景フレームも含める。
- 実際の前景ゲーム再開後に約1秒を除外し、連続30秒を記録。完了してもゲームを停止しない。LAB・ポーズ・非表示・回転・GAME OVER等は中断し、継ぎ足し不可。
- 2秒超でも直前CPUが間隔の75%以上を占めるものは重い前景フレームとして含め、それ以外の判別不能な長間隔は長さを保持して無効。高負荷かOS停止かを断定しない。判別不能なものを正常30秒の結果として使わない。
- 開始条件・時刻、観測RAF FPS、固定1秒最低値、P50/P95/P99、更新／描画CPU、最大敵／弾／FX、中断理由を記録。直近8件と固定長ヒストグラムのみで保持。
- 日本語テキスト／JSON／手動コピー用textarea。従来攻略JSONにもmobile欄を追加。QA全項目は未確認から利用者が手動で記録し、通常セーブに保存しない。

## ブラウザで確認したこと

ローカルHTTPのChromeで新UIを操作。iPhoneの実指・Safari・実機safe areaの試験ではない。

1. `?debug=1`→TEST LAB→「計測」。5タブと既存BENCH／攻略JSONを維持。
2. 環境欄へ「Chrome / CSSサイズ確認（iPhone実機ではない）」を入力。
3. 現在の戦闘を維持して計測開始。ゲームへ戻り、待機／準備／計測状態へ進むことを確認。
4. LABへ戻ると中断で終了。再開して30秒へ継ぎ足されない。
5. 日本語結果・結果JSONのコピー操作で「コピーしました」を確認。
6. IP-08へ到達し、NG・短い試験メモを入力してチェック結果をコピー。これはフォーム操作試験であり、実機のNG判定ではない。
7. 試験メモを消し、全8項目が「未確認」に戻ったことをDOMで確認。PCテストでOKへ自動変更しない。
8. 最終コードを再読込して、状態が未計測に戻る一時保存仕様を確認。

### 性能の扱い

ブラウザの試行は、操作確認のため**意図的にLABを開いて中断**した1件のみ。正常な30秒の有効結果は**0件**。自動再試行はしていない。

部分記録では10.475秒・71フレーム・中断1、観測RAF平均6.8、固定1秒最低1.0、P50 33.50ms／P95 1000.75ms／P99 1001.25ms、更新CPU平均0.42ms／描画0.60msを表示した。約1秒の長い間隔も消されず記録された。これらは自動操作を含む**中断前の部分値**で、iPhoneの性能、通常の30秒性能、実ゲームの優劣を示す値ではない。

今回の目的は実機計測の道具と操作手順を整えること。正常な前景30秒の性能値は、iPhoneで[手順書](../../docs/MOBILE_PLAYTEST.md)に沿って取得する必要がある。推定値で補完していない。
