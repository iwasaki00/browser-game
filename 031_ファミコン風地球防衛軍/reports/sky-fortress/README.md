## パフォーマンス

今回のブラウザ操作中は、当初の短い表示区間の後に約1000msの長いRAF間隔が繰り返され、従来の有効前景サンプルは0になった。画面には「タブ中断・長いフレーム間隔」「有効サンプル=0」が表示されたため、FPS／CPUの比較値として採用しない。短い初期表示値やNodeテストの実行時間をiPhone性能とみなさない。

50/100/200体の実機30秒比較値は**未取得**。今回のためにProfilerを改変したり、無効区間からFPSを捏造したりしていない。

手動計測：iPhoneで ?debug=1 → ステージでM04を開始 → 計測で実機環境を入力 → 50/100/200を選択 → 30秒計測開始。ゲームを前景表示したまま1秒準備＋30秒を完走し、LABへ戻ってJSONをコピーする。画面切替・回転などで中断した試行は通常性能と混ぜず、新しい試行を開始する。200体はLAB限定。
