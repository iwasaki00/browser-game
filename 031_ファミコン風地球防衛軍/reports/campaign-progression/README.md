## 原因未確定のため実施した変更

根拠のないゲームロジック修正は行わず、既存A1の遷移診断だけを拡張した。

- ボス開始から診断を準備。残HP10以下の有効命中・防御命中と、同条件の前景ループheartbeatを記録する。変化のない防御命中・heartbeatは約1秒間隔に制限。
- HP、Phase、死亡／クリア状態、プレイヤー座標・HP・EN・武器、保持入力・ポインター所有数、隠れタブ、待機タイマー数、解放済みミッション、保存エラー有無を記録。
- 撃破→クリア確定とリザルト表示のタイマーについてscheduled／deferred／fired／done／errorを記録。例外は握りつぶさず元の挙動のまま再throwする。強制進行はしない。
- 既存のwindow error／unhandledrejectionも撃破前から利用。最大24イベントのリングログを専用`sessionStorage`キーへ保存（通常localStorageセーブと別）。制限・保存失敗・任意の診断DOM欠損では診断だけを断念し、ゲーム処理を止めない。
- ポーズ・結果・司令部で表示／コピーできる。自動コピー不可ならreadonlyテキスト欄から手動コピー。再読み込み後も同じタブの記録を参照できるが、次のボス開始で更新、タブ終了やブラウザ側の破棄で消える。永続保存やクラッシュ耐性は保証しない。
- LABは通常診断アーカイブも通常セーブも書き換えない。外部送信はない。
