## 実操作結果

- 全5タブ×5サイズで外枠スクロールなし、中央の横はみ出しなし。ヘッダー／フッターは画面内、中央だけ縦スクロール。主ボタン／selectは44px以上。詳細は[操作仕様と棚卸し](../../docs/TEST_LAB_UI.md)。
- 各サイズで武器20件→「メテオ」検索1件→解除20件→最下部M-20を実選択。SLOT1/2へ独立反映。
- M02 AREA03上ルート指定開始、M01/M02ボス直接開始を実行。候補選択だけでは現在シーンは変わらない。
- WING・R-04装備、4アート、640、FIXED0.35、LEVEL3、揺れOFFとタブ移動後の保持を確認。
- 検証地形候補の保留、E-01の200体生成、全消去、再生成、爆発プレビューを実行。
- プリセット選択のみは不実行、明示適用で候補変更。中央末尾に移動しても共通ヘッダー／フッター位置は同一。
- キーボードの左右／End・Enter／Space、Tab／Shift+Tab循環、LAB中の移動キー遮断を確認。
- ヘッダー閉じる→F2、停止比較→LAB、フッター閉じる→LABで状態とタブを維持。停止時のHP100・X3200が同じことをDOMで確認。
- JSONコピーを実行し成功通知を確認。自分が書き込んだクリップボードを読み戻し、version 0.2.3-D・BENCH4件を確認。
- ブラウザコンソールの警告／エラー0件。

サマリーは最終調整で自由配置・BENCHと実AREA進行を区別し、QAの実効値も併記した。`verification.json` のactions内の古いサマリー文字列は調整前の機能確認ログであり、最新の25枚・layoutsを優先する。
