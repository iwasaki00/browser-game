## 正式4兵科

ミッション選択後の「兵科・装備選択」で全兵科を使用できます。選択は自動保存され、次回出撃・リトライに適用されます。GAME OVER → ミッション選択から別兵科で再挑戦できます。

| 兵科 | HP | 移動px/s | 特殊能力 |
| --- | ---: | ---: | --- |
| RANGER | 100 | 95 | 標準ジャンプ |
| SCOUT | 75 | 180 | ジャンプ1.15倍、C / DASHでダッシュ（無敵なし） |
| GUARDIAN | 200 | 65 | ジャンプ0.95倍、ダメージ25%・ノックバック45%軽減 |
| WING | 65 | 110 | W / ↑ / FLY長押しで上昇、Space / HOLDでホバー、S / ↓で下降 |

- WINGはEN100、上昇20/秒（約5秒）、ホバー8/秒（約12.5秒）、自然下降0/秒、地上回復25/秒。HOLD中は高度を維持し、FLYを同時に押すと上昇を優先します。解除・枯渇後は重力で自然下降します。
- 全兵科で20武器を使用可能（既存8武器の性能は従来どおり）。タッチ操作はSCOUTのみDASH、WINGのみFLY/HOLDを追加・置換します。
- `selectedClass` を既存セーブキーに追加。旧形式v1/v2はRANGERを補完し、進行・武器・設定を保持します。
- TEST LABでも正式兵科を検証可能。旧4プリセットは「実験用」として存続し、LAB内の選択は通常セーブへ反映しません。
- 新素材は `py -3 tools/generate_assets.py --classes-only` で直接生成。詳細は [PLAYER_CLASSES.md](docs/PLAYER_CLASSES.md)。

## 操作

- PC：A/Dまたは左右キーで移動、W/上/Spaceでジャンプ、マウスで照準・射撃、Q/E/Shiftで武器切替、Esc/Pでポーズ
- スマホ：横向き推奨。左側で移動・JUMP、右側で武器切替・FIREを操作します。FIREを押して射撃し、ドラッグで照準方向を変更します。縦向きでも従来のゲーム画面上段・操作面下段の構成でプレイできます。
- 左上の「← TITLE」でゲーム内タイトルへ戻れます。ミッション中は確認を表示し、キャンセルすると継続します。確定すると進行中ミッションを破棄し、取得済み武器とステージ進行記録を保持します。

## モバイル表示

- `portrait` / `landscape` を画面向きから自動判定し、HTMLの `data-layout` に反映します。
- landscape・portrait・PCとも自動ズームです。敵なしは `0.50` 倍、戦況に応じて `0.35〜0.85` 倍（横可視範囲約376〜914ワールドpx）へ滑らかに変化します。背景を含むワールド描画に適用し、HUDは等倍を維持します。
- `100dvh` と `visualViewport.height` を併用し、Safariのアドレスバー伸縮時にもレイアウト高を更新します。
- ヘッダー、操作面、モーダルに `env(safe-area-inset-*)` を適用しています。
- 仮想パッドのFIREは最大132pxの円形操作面とし、狭幅端末向けに104pxまで縮小します。

詳細は `docs/LAYOUT_SPEC.md` を参照してください。

## ダイナミックカメラ

- 600ワールドpx以内のアクティブな敵を、前後それぞれ100px刻みの距離帯へ集計します。画面外も対象ですが、未出現・非アクティブ・死亡した敵は除外します。
- 距離分布、敵数、集団の広がり、進行方向から連続的な目標倍率を計算します。遠方の単独外れ値は影響を弱め、距離帯の境界をまたぐ集団も扱います。
- 評価間隔は0.15秒。0.30秒の安定待ち（敵なしへ戻る際は0.45秒）、0.015の倍率差の無視幅、時間ベースの指数補間で振動を抑えます。
- 進行方向へ少し先を映し、ボス戦ではプレイヤーとボスを同時に収める構図を優先します。ボス中の倍率は初期設定0.35〜0.65で、召喚された通常敵では大きく変動しません。
- 定数は `js/data.js` の `BATTLE_CAMERA`、評価・追従処理は `js/camera.js` にあります。敵密度30〜100体でも同じカメラを使用します。

## ステージ進行とセーブ

- セーブは同じlocalStorageキー `pixel-defense-front-save-v1` を継続使用し、中身を形式バージョン2へ移行します。
- `clearedMissions` にクリア済みID、`unlockedMissions` に解放済みIDを保存します。初期状態はM01のみ解放です。
- M01クリアでM02を解放します。M01/M02は実装済み、M03は `COMING SOON` と表示し選択できません。GAME OVER・リトライ・タイトル復帰で解放を巻き戻しません。
- `CLEAR` は再挑戦可能、`OPEN` は挑戦可能、`LOCKED` は未解放、`COMING SOON` は未実装を示します。
- GAME OVER、リトライ、タイトルへの復帰、リロードで解放状態は巻き戻りません。GAME OVER画面からミッション選択へ戻れます。
- 旧セーブの `cleared` を引き継ぎ、武器解放・装備・スコア・設定も保持します。将来の実装判定は `MISSIONS` で管理し、進行記録と分離しています。

## 撃破演出レベル（0.1.7）

- タイトルまたはポーズ画面の「設定」から、LEVEL 1：標準／LEVEL 2：強烈／LEVEL 3：超強烈を選べます。初期値はLEVEL 1。通常セーブの `settings.destructionLevel` に自動保存します。既存セーブはLEVEL 1で読み込めます。
- LEVEL 2は吹っ飛び1.8倍・回転1.5倍・破片約1.5倍・爆発サイズ1.4倍・揺れ1.3倍・寿命1.2倍。LEVEL 3はそれぞれ3.0／2.5／約2.5／1.8／1.6／1.4倍です。威力・爆風ダメージ範囲・ヒットストップは変えません。
- LEVEL 2以上は短い残像と最大1回の着地バウンドを追加。LEVEL 1の既存動作を保護するため、LEVEL 1には追加しません。死亡演出だけの重力もLEVEL 2=1.8倍、LEVEL 3=3倍にして、短い寿命内に帰ってくる動きを保ちます。
- 「画面揺れON」を外すと、どのレベルでも揺れOFF。LABにも独立したレベル・揺れ設定があり、変更はLAB内だけに即時適用されます。プレイ画面のLEVEL表示で確認できます。
- LABで200体を密集再配置し、各レベルでR-04/G-07の爆発プレビューを比較できます。BENCHも選択レベルを維持します。粒子・死亡状態・爆発上限は従来どおり、追加残像は画面合計32描画までです。
