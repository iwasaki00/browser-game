# CAMPAIGN ENDING / 1.0.0

## 物語の接続

M01市街地、M02地下、M03沿岸での侵略、M04要塞、M05移動基地、M06巨大生物、M07母艦の司令中枢は、全てオーバーマインドの共通信号で結ばれていた。M07の未知信号は中枢の奥の真の指揮生命体を示す。M08 AREA04で4行・8秒の通信として明かす。通信スキップは進行・制御網・報酬を変えない。

## 最終撃破と保存の順序

1. 第3形態HP0を一度だけ受理し、旧攻撃・敵弾を除去。第1/2形態HP0はクリアにしない。
2. 通常出撃なら**そのフレーム内に**M08クリア、最高スコア、最短時間、撃破数、武器箱、戦績、実績判定と完結フラグを保存。
3. 3秒の6段階崩壊。プレイヤーを保護し、上限付きの爆発を表示。
4. 6シーンのエンディングを再生し、既に用意した通常リザルトへ。

演出開始前に保存するため、崩壊・エンディング中にリロード／タイトルへ戻る／スキップしても報酬を失わず、再視聴で増殖しない。スキップ時に別の報酬トランザクションを実行しない。

### 保存項目（既存version2に追加）

| キー | 意味 |
| --- | --- |
| clearedMissions / unlockedMissions | 従来形式。M07クリア履歴からM08自動解放。GAME OVERでも解放を維持 |
| campaignComplete | M08正式クリア済み。旧データはfalse、M08履歴があれば補完 |
| firstEndingReached | 最終撃破後の演出へ到達済み。全シーン視聴の意味ではない。M08完結と整合する場合のみ保持 |
| campaignRewardClaimed | 完結ボーナス付与済み。一度だけ+2000点を与えるガード |

初M08クリアには通常クリア箱に加え初回箱1個。どちらも未所持武器優先、全20所持なら既存代替点数を適用（追加箱は+500点）。完結+2000点は一度だけ。以降の再出撃は通常報酬のみ。通常の装備・selectedClass・設定・武器所持・称号・取得済み実績は消去しない。

保存キーと既存バージョンは変えず、旧v1/v2を読み込める。M08記録がない旧M07クリア済みデータはM08を解放するが、完結フラグや完結報酬を先取りしない。

## エンディング6シーン

各約4秒、全体約24秒。Canvas論理320×180、画面ボタン／HUDとは分離。非表示・非アクティブ中は停止し、長い停止時間を一度に進めない。

| シーン | 内容 |
| --- | --- |
| SIGNAL TERMINATED | 波形が静まり母艦信号停止 |
| INVASION HALTED | 地球背景と停止した侵略兵器 |
| ALL UNITS RETURN | 崩壊中の母艦から離脱、帰還艇と上限付き爆発 |
| THE SEVEN FRONTS | M01〜M07の実背景を7枚の記憶として回顧 |
| EARTH DEFENDED | 地球防衛成功 |
| CAMPAIGN COMPLETE | 完結表示、戦績・報酬確認と再出撃の案内 |

Enter/Spaceまたは画面ボタンで次へ、Esc／スキップで終了。描画関数・再生クラスは保存APIを持たない。通常クリア後は司令部の再視聴ボタンから再生し、終了後は司令部へ戻る。

## クリア後

司令部は実装済み8ミッションを分母にし、全クリアで8/8・CAMPAIGN COMPLETE。4タブ、全M01〜M08再出撃、兵科変更、武器収集、30実績・称号を継続できる。既存「全6作戦」の実績はM01〜M06固定であり、完結表示の分母と混同しない。

LABの崩壊／エンディング／仮想完結はNO SAVEの表示試験。フラグ・通常報酬・実績・統計を書き換えない。終了後はLABへ戻る。正常保存・再読込・複数回クリア・再視聴・全6シーン・スキップを[関連テスト](../reports/final-defense/related-tests.txt)で確認した。
