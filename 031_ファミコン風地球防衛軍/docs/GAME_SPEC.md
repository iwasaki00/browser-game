# ドット防衛戦線 — Game Spec

## 0.8.0 / CHALLENGE OPERATIONS

司令部へ実績タブを追加し4タブにする。30実績は独立マスタ・判定・UIへ分離し、既存CampaignRunの確定イベントに一時ChallengeRunを合成する。武器使用・兵科クリアは正確な0.7統計を再利用。新規連続撃破・被ダメージ・限定装備・B-05順序・B-06露出・敗北後クリアは0.8以降だけで判定する。

任意のachievementsフィールドを既存version2保存へ追加。未記録と0を区別し、A/B区分の旧記録だけ静かに復元。LAB／QAは非加算。解除通知は保存と分離、3秒・1件ずつ・スキップ可能。6カテゴリCSSバッジと5つの保存可能な称号は見た目専用。全20武器／M01〜M06制覇実績は固定対象、UI総数はマスタ参照。

[30条件・確定イベント・保存互換性・変更ファイル](CHALLENGE_OPERATIONS.md) · [関連テスト／実ブラウザ範囲](../reports/challenge-operations/README.md)。戦闘数値・地形・AI・カメラ・報酬を維持。

## 0.7.0 / CAMPAIGN COMMAND

従来ミッション選択を3タブの司令部へ拡張。進行率は実装済みマスタから算出し、M07を除外。M01〜M06の記録／詳細と既存の装備→出撃導線を維持する。武器コレクションもマスタ実件数を参照する閲覧画面。

保存version2に任意のcampaignStats（schemaVersion1）を追加。0.7.0以降の通常出撃だけで兵科・武器の累積値を確定イベントから集計する。旧履歴を推測せず未記録と0を区別。LAB／通常攻略QAを除外し、保存は周期・終了等にまとめる。軽量な6戦場プレビューは別Canvas、音なし、停止／静止代替あり。戦闘数値・報酬・地形・アート・描画解像度は維持。

[各統計の定義・互換性・拡張手順](CAMPAIGN_COMMAND.md) · [確認結果](../reports/campaign-command/README.md)。

## 0.6.0 / M06 巨大生物内部戦

M05クリアで解放、8400px・5エリア。射撃破壊する外殻、占有時に閉鎖を遅延する脈動通路（4/1/2/0.5秒）、足元だけに作用する体液流（+24/−24/間欠+32px/s）、命中で信号伝播し8秒防御停止する再利用ノード。B-06 HP3800は左右ノード6秒受付→コア8秒露出を反復。HP段階65%/30%と防御状態は独立。新敵E-16/17/18のHP85/55/260。M07未実装。

保存キー/version2、未取得優先報酬を継承し、M06もmissionStatsのkillsに対応。新規26PNGは専用フォルダへ生成。M01〜M05・4兵科・20武器・カメラ基本値・通常320・LAB640は維持。[地形・ボス・QA・未確認事項](MISSION_06.md)。

## 0.5.0 / M05 巨大移動基地強襲戦

M04クリアで解放する8000px・5エリアを追加。安定したワールド座標のまま背景・車輪・排気を走行させる。砲塔2基、駆動装置、制御盤でハッチを開き、B-05の左右装置を任意順序で破壊→コアHP3600へ。新敵E-13 HP90／E-14 HP60／E-15 HP240、回復は通常生存敵のみ、必須部位を修復しない。M06は当時未実装（0.6.0で実装）。[設計・検証範囲](MISSION_05.md)。

通常セーブのキー・version2・既存フィールドを維持。M05のmissionStatsに任意のkills（最多撃破数）を追加し、旧データは補完不要で読める。4兵科・20武器、M01〜M04、通常UNIFIED 01／320、LAB限定640・5タブ・保存隔離は維持。

## 0.4.0 / M04 天空要塞迎撃戦

M03クリアで解放する7200px・5エリアの正式ミッションを追加。移動足場、新敵E-10（HP60）／E-11（85）／E-12（220）、B-04コアHP3200と砲台・シールド発生装置を実装。固定装置は通常敵数と別集計。既存320/640の区別、4兵科・20武器・保存互換を維持。[詳細・検証区分](MISSION_04.md)。


- Version: 0.3.2 — GAMEPLAY POLISH（通常アートはUNIFIED 01）
- 戦闘表示: HIT / ARMOR HIT / WEAK POINT / FINISHを既存FXへ追加。ダメージや弱点ルールは維持。HUDは共通画面座標で兵科・HP現在/最大・WING EN・両武器／使用枠・ミッション／エリア・敵数、ボス戦のみ上段ボスHPを表示。B-01の弱点は新設しない。
- 操作・音: 指ごとの同時入力、押下色、回転・lostpointercapture時の解除。ゲーム操作面だけtouch-action:none。ユーザー操作後にWeb Audioを開始／再開、同時8音・秒24音。ミュート・音量を継承する。
- 結果: M01〜M03共通で使用兵科・時間・撃破数・スコア、クリア報酬・新規武器・新規の実装済み解放ミッションを表示。220ms演出は省略可能。保存形式と報酬は変更なし。
- LAB: 第5プリセット「通常攻略QA」は正式兵科・無敵OFF・初期武器・次回STANDARD。明示適用とステージ開始を分離。途中QAは正式クリアにしない。[詳細](GAMEPLAY_POLISH.md)。
- 内部解像度: 320×180 / Canvas 2D / nearest-neighbor
- 通常描画: debug不要でUNIFIED 01。通常用ArtPreviewを起動時に読み込み、未読込中は旧素材、欠損は画像単位で旧セットへ代替する。M01/M02・4兵科・全20武器・敵／両ボス／ネスト・背景／地形／対応FXに適用。兵科／武器プレビューにも使用。HUD文字・バー・アイテム・小粒子プリミティブは従来どおり。
- LAB描画: ORIGINALを初期値としてORIGINAL / STUDY 01 / STUDY 01-B / UNIFIED 01を比較。640×360はLAB限定・画素密度2倍、論理座標320×180を維持。通常用とLAB用のアート状態を分離し、LAB設定は通常セーブにも標準アートにも反映しない。兵科／武器／AI／地形／進行／セーブに変更なし。詳細は[ART_UNIFICATION.md](ART_UNIFICATION.md)。
- ステージ: M01 市街地防衛線（幅4,800px）／M02 地下侵攻作戦（幅5,600px）／M03 沿岸防衛戦（幅6,400px）、各5エリア
- プレイヤー: RANGER / SCOUT / GUARDIAN / WING（全兵科使用可能）。性能は `js/data.js` の `PLAYER_CLASSES`、挙動は `js/player.js`。重力620px/s²、無敵1秒を継続
- 進行: タイトル → ミッション選択 → 兵科・装備選択 → 本編 → リザルト → 武器解放
- 対応入力: PCキーボード＋マウス、タッチ仮想パッド
- モバイル表示: landscape推奨、左右にタッチ操作。portraitはCanvas上段・仮想パッド下段の2段構成を継続
- カメラ倍率: PC・landscape・portrait共通で戦況に応じて0.35〜0.85。敵なしは0.50、横可視範囲約376〜914ワールドpx。HUDは独立した画面座標
- カメラ評価: 600ワールドpx以内のアクティブ敵を前後100px距離帯で0.15秒ごとに集計。距離・敵数・広がり・進行方向・ボス状態を使用し、時間ベースで滑らかに追従
- 敵密度: LIGHT30 / STANDARD50（初期値）/ MASSIVE100。装備画面で選択、次回開始時に固定。settings.enemyDensityを形式v2内へ追加
- 大量出現: SpawnDirector + M01_ENCOUNTERS / M02.encounters。WAVE/SWARMを中心に、上限時は待機。M02はネスト生成も共通上限に含み、ボス召喚は既存の密度別上限
- 保存: localStorage形式v2（clearedMissions、unlockedMissions、解放武器、装備、最高スコア、最短時間、設定）。旧形式v1から移行
- ミッション: M01クリアでM02、M02クリアでM03解放（旧データでも有効）。未実装M04はCOMING SOONとして無効化。形式v2のmissionStatsに各ミッションの最高スコア・最短時間を保持
- タイトル復帰: ゲーム内確認→ミッションと演出予約を破棄、進行記録を保持。単一のゲームループを継続
- 武器: 20種類、6カテゴリ、全4兵科共通。初期A-01/S-02、初回M01でL-03。箱は未所持から抽選して即時保存。全取得後は箱スコア+500のみ
- 装備: 2枠を明示選択、カテゴリ絞り込み、武器一覧を内部スクロール。未解放武器は選択不可。LABのみ未解放を含む20武器を使用可能
- 新武器処理: `js/weapons.js`。寿命・貫通・反射・分裂世代・連鎖キュー・設置数を制限し、既存のダメージ・撃破演出と連携。詳細は [WEAPON_EXPANSION.md](WEAPON_EXPANSION.md)

原典はユーザー提供のVersion 0.1.0詳細設計。実装値は `js/data.js` を正とする。

## M03（0.3.0）

固有データ／挙動は`js/mission03.js`、描画は`js/coastal-art.js`へ分離。AREA境界0/1100/2300/3700/5100、ボス発火x>5480。本体はx6060,y48、HP3000、弱点はworld(x,y+58)。敵HPは70/45/180。WAVE／SWARM／AIR_RAIDの既存Director・攻撃頻度制御・空間グリッドを再利用する。

岸壁上面148px、コンテナ高さ16〜28px。M03だけ落下用床を220pxに設け、y>158で安全地点へ復帰する。海面を安全な透明床として扱わず、水泳は追加しない。味方砲台は独立した2基・耐久160・射程360・0.7秒間隔・12ダメージ、プレイヤーD-19の設置枠を使わない。新ボスの召喚・編隊も既存の密度上限内。

通常クリアはM02と同じ未取得優先の箱1個を付与し、全取得済みはスコア+500。初回／再クリア表示と記録保存の既存経路を使用する。LABではボス結果をQAへ送るだけで通常進行を書き込まない。詳細・制約は[MISSION_03.md](MISSION_03.md)。

## M02（0.2.2）

データ・ギミックは `js/mission02.js`。天井・配管・壁は高さを持つsolid地形で、地上兵科も下面に衝突する。M01は従来の8px足場・片方向着地を維持。ワールド幅はミッション単位で渡し、M01のWORLD定数を上書きしない。

AREA03はy=72の上ルートと床y=148の下ルート。各兵科の通過条件、H-01、B-02弱点、地下武器の制約は [MISSION_02.md](MISSION_02.md) を参照。M02初回報酬と武器箱抽選を単一処理にし、全所持時は+500。M01の初回L-03は変更しない。

## 実装上の補足

- 音源ファイルは使用せず、Web Audio APIで短い矩形波・鋸歯状波の効果音を生成する。
- 画面外の敵も生存・移動・当たり判定を維持する。遠方の飛行軌道更新のみ間引き、通常敵を前方へ再配置しない。描画範囲と検出・衝突判定を分離する。
- M01武器箱はエリア3固定配置と通常敵2%ドロップ。M01初回クリア報酬はL-03を優先する。M02はx=1950/3370の固定箱と既存のドロップ抽選、初回クリアの未所持1武器確定報酬を使用する。
