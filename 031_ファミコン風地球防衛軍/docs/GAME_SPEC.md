# ドット防衛戦線 — Game Spec

- Version: 0.2.3-E — ART RELEASE（通常アートはUNIFIED 01）
- 内部解像度: 320×180 / Canvas 2D / nearest-neighbor
- 通常描画: debug不要でUNIFIED 01。通常用ArtPreviewを起動時に読み込み、未読込中は旧素材、欠損は画像単位で旧セットへ代替する。M01/M02・4兵科・全20武器・敵／両ボス／ネスト・背景／地形／対応FXに適用。兵科／武器プレビューにも使用。HUD文字・バー・アイテム・小粒子プリミティブは従来どおり。
- LAB描画: ORIGINALを初期値としてORIGINAL / STUDY 01 / STUDY 01-B / UNIFIED 01を比較。640×360はLAB限定・画素密度2倍、論理座標320×180を維持。通常用とLAB用のアート状態を分離し、LAB設定は通常セーブにも標準アートにも反映しない。兵科／武器／AI／地形／進行／セーブに変更なし。詳細は[ART_UNIFICATION.md](ART_UNIFICATION.md)。
- ステージ: M01 市街地防衛線（幅4,800px）／M02 地下侵攻作戦（幅5,600px）、各5エリア
- プレイヤー: RANGER / SCOUT / GUARDIAN / WING（全兵科使用可能）。性能は `js/data.js` の `PLAYER_CLASSES`、挙動は `js/player.js`。重力620px/s²、無敵1秒を継続
- 進行: タイトル → ミッション選択 → 兵科・装備選択 → 本編 → リザルト → 武器解放
- 対応入力: PCキーボード＋マウス、タッチ仮想パッド
- モバイル表示: landscape推奨、左右にタッチ操作。portraitはCanvas上段・仮想パッド下段の2段構成を継続
- カメラ倍率: PC・landscape・portrait共通で戦況に応じて0.35〜0.85。敵なしは0.50、横可視範囲約376〜914ワールドpx。HUDは独立した画面座標
- カメラ評価: 600ワールドpx以内のアクティブ敵を前後100px距離帯で0.15秒ごとに集計。距離・敵数・広がり・進行方向・ボス状態を使用し、時間ベースで滑らかに追従
- 敵密度: LIGHT30 / STANDARD50（初期値）/ MASSIVE100。装備画面で選択、次回開始時に固定。settings.enemyDensityを形式v2内へ追加
- 大量出現: SpawnDirector + M01_ENCOUNTERS / M02.encounters。WAVE/SWARMを中心に、上限時は待機。M02はネスト生成も共通上限に含み、ボス召喚は既存の密度別上限
- 保存: localStorage形式v2（clearedMissions、unlockedMissions、解放武器、装備、最高スコア、最短時間、設定）。旧形式v1から移行
- ミッション: M01クリアでM02解放（旧データでも有効）。未実装M03はCOMING SOONとして無効化。形式v2に省略可能なmissionStatsを追加し、各ミッションの最高スコア・最短時間を保持
- タイトル復帰: ゲーム内確認→ミッションと演出予約を破棄、進行記録を保持。単一のゲームループを継続
- 武器: 20種類、6カテゴリ、全4兵科共通。初期A-01/S-02、初回M01でL-03。箱は未所持から抽選して即時保存。全取得後は箱スコア+500のみ
- 装備: 2枠を明示選択、カテゴリ絞り込み、武器一覧を内部スクロール。未解放武器は選択不可。LABのみ未解放を含む20武器を使用可能
- 新武器処理: `js/weapons.js`。寿命・貫通・反射・分裂世代・連鎖キュー・設置数を制限し、既存のダメージ・撃破演出と連携。詳細は [WEAPON_EXPANSION.md](WEAPON_EXPANSION.md)

原典はユーザー提供のVersion 0.1.0詳細設計。実装値は `js/data.js` を正とする。

## M02（0.2.2）

データ・ギミックは `js/mission02.js`。天井・配管・壁は高さを持つsolid地形で、地上兵科も下面に衝突する。M01は従来の8px足場・片方向着地を維持。ワールド幅はミッション単位で渡し、M01のWORLD定数を上書きしない。

AREA03はy=72の上ルートと床y=148の下ルート。各兵科の通過条件、H-01、B-02弱点、地下武器の制約は [MISSION_02.md](MISSION_02.md) を参照。M02初回報酬と武器箱抽選を単一処理にし、全所持時は+500。M01の初回L-03は変更しない。

## 実装上の補足

- 音源ファイルは使用せず、Web Audio APIで短い矩形波・鋸歯状波の効果音を生成する。
- 画面外の敵も生存・移動・当たり判定を維持する。遠方の飛行軌道更新のみ間引き、通常敵を前方へ再配置しない。描画範囲と検出・衝突判定を分離する。
- M01武器箱はエリア3固定配置と通常敵2%ドロップ。M01初回クリア報酬はL-03を優先する。M02はx=1950/3370の固定箱と既存のドロップ抽選、初回クリアの未所持1武器確定報酬を使用する。
