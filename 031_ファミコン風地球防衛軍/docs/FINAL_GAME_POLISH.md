## FXと負荷

生存50体以上／装飾FX48個以上／死亡演出32体以上で混雑表示へ移る。画面内の命中・銃口火花16個、粒子48個まで描く。画面外FXは予算を消費しない。通常爆発の描画透過率72%。生成・寿命更新・当たり判定・得点・死亡演出レベルは維持する。

ボスや固定部位の死亡スプライトは通常死体描画予算超過でも優先。重要なmission collapse／shield等の専用FXは火花間引きの対象外。既存のFX総数・ヒットストップ・揺れ上限・音声8voice／24starts毎秒は維持。

Node Canvas proxy参考計測では描画処理の削減を観測したが、GPUもrAFも実行しない。実機FPS・改善率は認定しない。[生値と制約](../reports/final-polish/README.md)。AI／衝突／探索の全面最適化は根拠不足のため行わない。

## 入力とカメラ

- 個別pointercancelは所有する指だけを解除。他指の移動・射撃を継続。
- touchcancelは残るtouchが0件の場合のみ全解除。pagehideも全解除。既存blur／visibility／画面回転／リザルト解除を維持。
- setPointerCapture失敗時は新しく取得した所有権と押下表示を巻戻す。他の指は解除しない。SWの長押しタイマーは失敗時に作らない。
- A1の「所有状態を先に消す→キャプチャを例外保護付きで解放」の順序は不変。
- PAUSEはプレイ中だけ表示し、連打は状態ガード。FIRE等の長押し操作領域のみcontextmenuを抑止し、一覧のpan-yは維持。
- カメラ先読みの方向を0.12秒継続で確定。ズーム目標式、補間速度、0.35〜0.85、ボスframing、画面／ワールド変換は変更しない。
