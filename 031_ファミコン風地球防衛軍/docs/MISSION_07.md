# M07 侵略母艦突入戦 — 0.9.0 MOTHERSHIP ASSAULT

M07の開始・侵入・混成戦・防衛解除・B-07撃破・リザルト／報酬保存・M08への通信を実装。ローカル変更のみ。公開・Git push・デプロイなし。

## エリアと必須経路

ワールド幅9000px。床面y148、艦内天井y20。通常の移動・重力を使い、無重力操作は追加しない。必須障害物は12/24pxのコンテナで、4兵科の実移動更新を使って通過を検証。地形判定は従来の掃引衝突を使う。

| AREA | X範囲 | 目的・仕組み |
| --- | --- | --- |
| 01 母艦外殻 | 0〜1600 | X1110・地上の制御部HP120を破壊→X1260隔壁開放。初期武器で接近射撃可能 |
| 02 侵略兵器格納庫 | 1600〜3400 | E-11＋E-15、E-14＋E-21、E-19＋E-08、E-07／E-12等の混成戦。支援元を倒すと戦況が変化 |
| 03 生体機械融合区画 | 3400〜5300 | X4540制御装置を射撃→X4700生体防御を6秒停止。0.4秒再操作間隔、何度でも使用可。E-17／18とE-20／21が混成 |
| 04 艦内防衛ネットワーク | 5300〜7100 | X5500=A、5980=B、6520=C、各HP120。順序自由。3系統停止でX6900入口開放 |
| 05 母艦司令中枢 | 7100〜9000 | X7760を越えるとアリーナへ。B-07本体X8500、装置X7980／8320／8680 |

### 進行不能対策

- 融合制御は破壊されず再操作可能、撃破数・スコアを発生させない。停止中でも再射撃で6秒を更新できる。
- 閉鎖時にプレイヤー・生存敵・設置物が重なっていれば隔壁の実体化を延期。タイムアウトで地形内部へ閉じ込めない。
- 3系統の装置はすべて入口手前の地上にあり、別系統の停止を攻撃条件にしない。
- 敵数上限を固定設備と分離。上限到達中も制御部の攻撃・破壊・イベントは進む。
- 大型敵の生成時には全身の地形重なりを検査し、周辺の合法位置へ調整。転移先も出現直前に再検査。
- 万一の下方逸脱は安全足場を探索して復帰。通常の床は連続しており、落下ショートカットは必須でない。

## B-07 マザーコマンドコア

コアHP4200、衝突64×64、描画176×112。核の見た目と照準中心をworld(x,y+32)に統一。3装置は各HP300、28×32、足元y148。任意の順序で破壊できる。

| 装置 | 破壊の効果 |
| --- | --- |
| シールド | 召喚敵へのシールド支援が停止（E-11と重なっても1段階）。コア自体は3装置停止まで保護 |
| 増援 | 新規召喚を停止。召喚は7秒間隔・2体ずつ、最大6体かつ既存共通上限内 |
| 砲台 | Phase1の外部砲撃を停止。Phase2以降はコア自身の攻撃へ移行 |

| Phase | 条件 | 挙動 |
| --- | --- | --- |
| 1 | 装置が1つでも生存 | コア無敵。装置破壊が目標。外部砲撃・召喚は対応装置が稼働中だけ |
| 2 | 3装置すべて破壊 | コア露出、HP減少可能。旧予兆・攻撃を解除し1.6秒猶予、コア攻撃へ |
| 3 | コアHP1260以下 | 不安定化。回復待機1.15秒、3回に1回低い広範囲波。故障した外装表現。全域同時攻撃なし |

### 攻撃・回避

- 全攻撃は同じ`attackPlan.zones`を予兆と実判定へ使用し、予兆の途中でプレイヤーを追尾し直さない。
- 通常砲撃：幅64、高さ128、y20。予兆1.4秒、実判定0.24秒。
- Phase3の波：幅96、高さ24、y124。横移動またはジャンプで回避。
- 次攻撃まで1.6秒、Phase3は1.15秒。ボス自身の攻撃は直列化し、予兆前から画面外全域を即攻撃しない。
- GUARDIANの最悪横退避は(48+7)/65＋反応0.25＝約1.096秒＜1.4秒。4兵科とも実移動更新で0.25秒後の横退避をテスト。一般敵が絡むすべての組合せを無傷保証するものではない。
- 同時突進・射撃は既存共通予算、召喚も最大6体。敵や弾を無制限に増やさない。
- コア撃破で敵・敵弾を止め、1.8秒の段階崩壊後、通常のクリア・報酬・リザルトへ。
