# Version 0.2.3 — MISSION BALANCE & PLAYABILITY

## 範囲

TEST LAB専用のチェックポイント・ボス直行・攻略記録・進行診断を追加した。通常のM01/M02、20武器、正式4兵科、敵AI、素材、報酬/解放、密度30/50/100、カメラ0.35〜0.85、撃破演出3段階、Arcade031リンクは変更しない。LAB限定200体も維持する。

起動は `?debug=1` → TEST LAB → STAGE SELECT。未解放M02もLABだけで検証できる。通常ミッションの解放条件を迂回して保存する機能ではない。

各定義にはmissionId / areaId / x,y / route / safety / progression / enemies / midboss / boss / nests / camera / eventsを持たせる。camera.xは初期倍率0.50・右向き追従とワールド幅から計算し、上下は既存の地面基準変換を使用する。スポーンネストは `x < startX-72` を過去扱いにし、付随する破壊障害物の衝突も解除する。

適用順序：旧試行をメモリ履歴へ退避 → `startMission(id,true)` による共通初期化 → 予定密度のSpawnDirector再構築 → 過去イベントをdoneへ → 残りの静的配置・地形を復元 → 兵科HP/EN・位置・入力・使用中タイマーを初期化 → 必要なボス生成 → AUTOカメラと計測器を初期化。装備2枠・兵科/プリセット・無敵・演出設定は維持する。

前の敵・弾・敵弾・エフェクト・死体・破片・連鎖/雷雲/落雷・マイン/タレット・遅延結果イベント・攻撃枠・空間グリッド・入力は新規状態となる。RAFと入力リスナーは追加しない。RETRY/初期化は同じ地点、別エリア指定は新しい地点から開始する。

## 検証区分と保存保護

| 区分 | 取り扱い |
| --- | --- |
| A | 攻撃なしの地形到達性。自動出現・AI・ネスト増援なし、破壊可能地形あり。ボス入口でTERRAIN_REACHED |
| B | 無敵なしの戦闘QA。実験兵科/未解放武器を使用可能 |
| C | 無敵QA。出現・AI・被弾判定・ボス進行は本物、HP損失/ノックバックなし |
| D | 正式兵科・通常HP・解放済み2武器・無敵OFFを要求する通常プレイ条件。実操作の攻略を自動認定しない |

A〜CをD成功と表示しない。AREA01開始はFROM_MISSION_START、それ以外とボス直行はCHECKPOINT_ONLY。D途中の設定変更はB/Cへ降格しログへ保存。`normalClearCertified:false` / `normalProgressSaved:false` を常に付ける。

記録は `game.lab.run` とメモリ上の直近20試行・12BENCHに隔離。通常の装備・武器解放・最高スコア・最短時間・クリア/解放ミッション・設定を書き換えない。通常の `storeSave()` / `completeMission()` のLABガードを維持する。LABボス撃破の結果コールバックは `finishLabRun()` へ分岐し、武器抽選や通常の結果画面を呼ばない。既存localStorageキー/形式の変更や追加はない。コピーしなければリロードで計測データを失う。

## FPS・CPU計測

既存の `js/profiler.js` に試行全体用の固定長ヒストグラムを追加。通常オーバーレイは240サンプル、試行集計は0.5ms×501ビンでメモリを制限する。非表示/ポーズ/パネルでは時刻基準を破棄し、RAF差分250ms超は除外。p95は0.5ms刻みの上側近似。CPUは `performance.now()` による同期区間でGPU処理時間ではない。

Chrome実ブラウザ・844×390・M01自由配置BENCH・STANDARD実験性能/無敵C・A-01自動射撃・LEVEL1・AUTO。6秒の従来BENCHから中断を除いた短い区間だけの参考値：
