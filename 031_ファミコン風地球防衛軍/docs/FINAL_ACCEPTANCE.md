## 範囲・判定

B1を基準とする最終受入準備。8ミッション／4兵科／20武器／E-01〜24／B-01〜08／30実績・称号・エンディング、通常保存・LAB隔離、公開対象を確認する。新コンテンツ・難易度変更・アート再生成は行わない。公開・commit・push・デプロイは実施しない。

| 状態 | 定義 |
| --- | --- |
| PASS | 指定した範囲を実際に確認。証拠をNode／静的／USER_REPORTED等で区別 |
| FAIL | 実行して対象の問題を確認 |
| NOT RUN | 未実施。未評価を合格にしない |
| BLOCKED | 必要な環境等がなく実行不能 |

READYは必須の自動・実機・通常人手受入がすべて完了した場合だけ。自動合格でも手動未確認があればCONDITIONAL。重大な未解決問題や必須自動試験失敗があればNOT READY。[実行結果と判定](../reports/final-acceptance/README.md)／[機械可読集計](../reports/final-acceptance/results.json)。

## 実行コマンド

```text
npm run qa
npm run audit:release
node tools/acceptance-http-smoke.mjs
node tools/final-acceptance-report.mjs
```

順序はQA→静的監査→ローカルHTTP→集計。集計は版不一致や自動FAILを検出し、READYを自動生成しない。静的監査はファイル読取と隔離VMのみ。HTTPスモークは一時的なNodeループバックサーバーで日本語サブディレクトリ・版クエリ・254ファイルのバイト／MIMEと404を検証し終了する。実配信設定・JS実行・描画・入力・CDNの試験ではなく、公開・Git更新も行わない。既存の`benchmark`系はNode CPU参考値であり、実FPSの代用ではない。

## 通常難易度の人手試験

通常URL（debugなし）を使用する。LABの途中開始・全武器・無敵結果と混ぜない。元セーブを削除しない。新規条件が必要なら専用のブラウザプロファイル／別オリジンで試験し、その試験用保存だけを使用する。

各ミッションを[記録テンプレート](../reports/final-acceptance/manual-playthrough.csv)の**複製**へ記録する。配布テンプレートは未実施のまま保持し、集計ツールは入力された自己申告を自動認定しない。以下は必須。確認できない値は「不明／未取得」とし、0で埋めない。

| 記録項目 | 方法 |
| --- | --- |
| ミッション・兵科・武器2枠・敵密度 | 出撃前の装備画面とHUDを記録。基本は初期A-01/S-02・STANDARD |
| クリア／敗北／中断、到達AREA・時間 | 通常リザルト／GAME OVER／中断時画面。途中開始の場合は明記 |
| 被ダメージ・死亡原因 | 確認できた値・攻撃・直前状況。回復や軽減があるためHP差から総被害を捏造しない。不明なら不明 |
| ボス戦の問題 | Phase／必須部位／盾／予兆／攻撃不能／復帰等、具体的な再現手順 |
| 操作上の問題 | 指の組合せ、画面方向、入力保持／cancel、中断・復帰 |
| 難易度評価 | 1〜5と理由。人手の評価であり自動QAから採点しない |

既存LAB「計測→実機診断→人手通常攻略の手動記録」も利用可能。通常URLで試験後、自己申告の文脈だけを別途入力する。既存項目にない被害・死亡原因・ボス問題はメモへラベル付きで記入し、CSVにも残す。LAB測定のFPSや無敵結果を通常攻略欄へ流用しない。入力しただけで認定完了とはしない。

## 公開前監査の境界

`tools/release-audit.mjs`はゲームのHTML/CSS/JS参照、実際の画像ローダー定義、PNG署名・寸法・大文字小文字、秘密候補、ローカルパス、外部通信API、依存、Arcade031を検査する。秘密候補の実値・周辺文は出力せず場所とルールだけを出す。全Git履歴・全バイナリ・侵入試験・法的権利を網羅する監査ではない。

親READMEの公開手順はmain／リポジトリroot、.nojekyllあり。別途親のSites用hosting.jsonはstaticディレクトリ`dist`を指すが、現在の作業ツリーにその出力はない。実際のGitHub Pages／Sites設定や現在公開中のURLは未参照で、どちらが有効か断定しない。root公開なら開発用docs/reports/tests/toolsも公開され得る。監査JSONの`runtimeFiles`をゲーム実行用許可リストとして使い、将来公開する担当者が配信方式・対象・成果物を確認する。今回はファイル削除・公開構成変更・dist作成・自動アップロードをしない。他ゲーム全体の監査は範囲外。

画像は既存の固定シードPython/Pillow生成器とマニフェストに由来し、外部画像の取得コードは検出していない。効果音はCombatAudioの合成、同梱音声・フォントファイルや実行時npm依存はなし。CSSは端末システムフォント。開発環境のPillow 10.2.0メタデータはHPNDだが、そのライブラリをブラウザへ配布してはいない。素材・ソースの最終権利確認と公開条件の選択は所有者の確認事項で、独自ライセンスを勝手に付けない。
