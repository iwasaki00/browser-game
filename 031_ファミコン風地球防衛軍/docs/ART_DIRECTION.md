## 2. 新しい方向：FIELD STEEL / LIVING CARAPACE

16bit寄りの、読みやすい軍事SFピクセルアート。味方は角張った鋼板と布・装備、侵略生物は重なる曲面甲殻と節足。共通の暗い輪郭、左上光源、少数の段階的な色面で同じ世界にまとめる。過度な写実、写真テクスチャ、ぼかし・自動アンチエイリアス、全面的な微細ノイズは使わない。

- 優先順位：輪郭 → 大きい明暗 → 向き/部位 → 材質 → 微細情報。
- 1pxの点を撒くより2〜6px程度のピクセル群で面を作る。斜線は一定の段差リズム、輪郭は必要な場所だけ1〜2px。
- 明るい顔/照準・武器先端、暗い胴、読み分けられる腕/脚。全周を白で縁取らない。
- ダメージ範囲・武器性能・既存の当たり判定を見た目の変更に合わせて拡大しない。

## 3. 配色

共有パレットをサンプル生成モジュールに集約する。光源は左上、金属のハイライトは冷たい灰緑、反射は控えめな青緑、敵の装甲は紫褐色から銅/珊瑚色。白に近い色は顔・刃先・エネルギー核だけへ限定する。

| 用途 | 色の役割 |
| --- | --- |
| 共通輪郭 | 青黒。真っ黒一色の太い縁で面を潰さない |
| 味方 | スレート/オリーブの4〜5段階＋青緑バイザー＋小さな象牙色 |
| 敵 | 紫褐色の影＋銅/珊瑚色の甲殻＋酸黄の眼/器官。味方の青緑を主要面に使わない |
| 武器 | 共通の鋼材。アサルト=青緑、ロケット=琥珀、誘導=酸黄、雷撃=青紫、設置=青緑＋警告色。色だけで分類しない |
| M01 | 冷たい青灰の空気遠近、崩れた都市と少数の暖色窓。活動物より低彩度 |
| M02 | 濃い青緑の閉鎖空間、太い配管/金属、局所的な鈍い酸黄。M01より天井と奥行きの暗さを強める |

キャラクター/敵/ボスの単一コマは概ね8〜20色を目安とする。陰影のための色であり、細かな色差だけの大量パレットは作らない。背景は別の抑えたランプを使用する。

### 改善点と限界

- RANGERは装甲・布・前腕・銃を同じ水平の向きへ整理。WINGは大きく開く背面フィンと浮いた膝で、単色でもRANGERと区別できる。
- 敵の主面を暖色へ統一。地上の低い六脚と飛行の翼膜を明確に分け、味方の青緑バイザーと競合しない。
- B-01は縦色帯主体から、重なる甲殻/節/大顎の造形へ。描画枠は同じなので、巨大化による印象差ではない。
- 武器は銃身/単筒/連装ポッド/電極/三脚で外形を分け、弾と命中見本にも対応する色/形を持たせた。
- 市街地は空気遠近、損傷建物と高架。地下は閉鎖的なアーチ・配管・放置車両。窓・柱・タイルの単純な等間隔反復を減らした。近景は左右へ寄せ、中央は活動物より抑えた明度にした。
- 初回の縮小確認で味方の金属/布が背景へ沈みやすかったため、中間色・縁の明度とバイザー面積を調整した。派手な全面発光で解決する案にはしていない。
- **320×180・0.35倍では細部が消える**。原画を整数拡大した一覧だけで評価せず、比較ビューも確認する必要がある。左右比較は1枚あたりのCSS幅が実ゲームと異なり、iPhone実機の見やすさを保証しない。
- 背景はルック見本。継ぎ目・パララックス・高所/大量戦闘の遮蔽は全採用前のゲーム内検証が必要。今回、全素材差し替え・描画面変更・完成アニメーション制作は行っていない。
