# iPhone実機テスト — Version 0.3.3

この機能は「iPhoneで確認する人のための道具」です。自動テストやPCブラウザでの表示確認だけで、iPhone実機を合格にはしません。ゲームの武器・兵科・敵・ステージ・通常セーブは変更していません。

## 1. iPhoneで開く

1. 今回のローカル変更を利用中の公開先へ反映してから、SafariでBrowser Game Arcadeの031番「ドット防衛戦線」を開きます。この作業では公開処理は行っていません。Arcadeのリンク自体は変更していません。
2. URLの末尾に`?debug=1`を付けます。すでに`?`があるURLでは`&debug=1`を付け、`#`より前に置きます。すでに`debug`がある場合は重複追加せず、値を`1`に変更します。
3. 画面を横向きにします。縦向きでも操作できますが、横向きを推奨します。
4. タイトルの **TEST LAB** を押します。「NO SAVE」は通常ゲームの記録へ保存しない意味です。

PC用の`http://127.0.0.1:ポート/`は、iPhoneから同じPCへつながるアドレスではありません。実機では利用中の公開URLを使ってください。この作業で新規公開やネットワーク・ファイアウォールの設定変更は行っていません。

通常URLには追加の計測UIを出しません。UNIFIED 01・320×180の通常表示を維持します。LAB内では従来のアート4種と640×360も比較できます。

## 2. 遊ぶ条件を決める

LABの5タブは従来のままです。

| タブ | 設定するもの |
| --- | --- |
| ステージ | M01〜M03、エリア、M02ルート、ボス直接開始・B-03 Phase |
| 兵科・武器 | 正式4兵科／実験性能、無敵、全20武器・2枠 |
| 敵・ボス | 生成数1〜200、密集／分散、敵種、再配置 |
| 見た目 | アート、320／640、カメラ、撃破LEVEL、画面揺れ |
| 計測 | 新しい30秒計測、結果コピー、実機チェック、従来BENCH・攻略JSON |

実戦に近い確認は、クイック設定を開いて **通常攻略QA（初期武器・無敵なし）** → **表示された設定を適用** → 「ステージ」で **選択地点から開始**。正式兵科・通常HP、A-01/S-02、STANDARD、敵攻撃・被ダメージありです。途中エリアやボス直接開始は、全編通しクリアとは区別してください。

性能だけを調べるときは無敵を使っても構いません。ただし結果に無敵ONと記録され、通常難易度の攻略結果とは扱いません。

## 3. 操作を確認する

- 左側：左右移動、JUMP。SCOUTはDASH、WINGはFLY/HOLDが兵科に応じて表示されます。
- 右側：SWで武器切替、FIRE長押しで射撃、FIRE内をドラッグして照準。
- SCOUT：DASH＋移動＋FIREを同時に試します。ダッシュ無敵はありません。
- WING：FLY＋FIREで上昇射撃、HOLD＋FIREでホバー射撃。ENは上昇20/秒、ホバー8/秒、自然下降0、着地回復25/秒を維持します。FLY/HOLD同時入力は上昇優先です。
- M-18：FIREで設置。SWを短押しで切替、設置物があるとき450ms以上長押しで起爆します。最大3個・寿命など既存ルールはそのままです。
- 移動＋JUMP＋射撃、指を別々に離す、複数指を離す、押したまま回転、タッチのキャンセルを確認します。終わった指の操作だけが解除され、移動・射撃が残らないことを見ます。
- LABを開くと戦闘は停止し、入力は解除されます。LABをスクロールしてもゲームへ射撃・移動を伝えません。閉じてプレイで再開します。
- PCの通常ポーズはEsc/P。iPhoneのLAB中の一時停止は **LABを開く** 操作で確認できます。通常ゲームのタイトル戻り確認も、キャンセルで元の状態へ復帰します。

実機でノッチ・ホームバー・Safariのアドレスバー開閉・画面回転後に、HUDや操作面が隠れないか確認してください。CSSサイズの再現だけでは、これらの実機確認の代わりにはなりません。

## 4. 30秒計測する

1. 「計測」を開き、**実機の環境** に端末名・iOS・Safariなどを入力します。未入力なら未入力としてコピーされます。自動で「iPhoneで確認済み」とはしません。
2. **計測条件** を選びます。
   - **現在の戦闘を維持**：位置・HP・敵・時間・武器・進行を変えません。通常攻略QAや指定エリア・ボス戦を測る場合はこちら。
   - **通常敵50／100／200体で開始**：既存の再配置機能でテスト配置を作ります。位置・HP・敵・弾・FX・時間・スコアを初期化します。兵科・武器・見た目は維持。M01はE-01、M02はE-05、M03はE-07を使い、現在の密集／分散設定を使います。自動補充はしません。敵密度欄は実際のLABの密度・上限・開始時数を別々に記録します。
3. **30秒計測開始 → プレイ** を押します。条件選択だけでは再配置・再開始しません。
4. ゲームへ戻り、普段どおり操作します。最初の実際の前景フレームから約1秒は準備として除外します。LABが表示されたままの停止時間は含みません。
5. 小さな「あと○秒」を見ながら、そのまま30秒間プレイします。最後のRAF到着で完了するため、実測時間は30秒を少し超える場合があります。実際の時間を結果に表示します。
6. 完了表示が出てもゲームは止まりません。**LAB → 計測** を開いて結果を見ます。

途中でLAB・ポーズ・タイトル確認を開く、タブが非表示になる、フォーカスを失う、画面を回転する、GAME OVERやQA終了になると、その試行は中断として終了します。戻っても時間を継ぎ足しません。再び測る場合は **再計測（新しい30秒）** を押してください。

## 5. 結果の読み方

「結果一覧」に直近8件を保持します。ページの再読込・終了で消える一時記録です。必ずコピーしてから閉じてください。

| 項目 | 意味 |
| --- | --- |
| 観測RAF FPS | requestAnimationFrameの間隔から計算した、ブラウザで観測できた頻度。画面への表示完了やGPU時間ではありません |
| 最低1秒平均FPS | 準備後の開始点から固定1秒ごとに到着したフレーム数の最低値。完全な1秒窓だけを使い、空の窓も0として含めます。末尾の1秒未満は含めません |
| P50／P95／P99 | フレーム間隔の中央・95%・99%点。値が大きいほど間隔が長いことを示します。0.25ms刻みの上側近似です |
| 更新／描画CPU平均 | ゲーム更新処理とCanvas呼出しの所要時間。RAF間隔・GPU時間と混同しません |
| 最大敵／弾／FX | 記録区間中の最大値。FXには破片も含みます |
| 中断・無効理由 | 正常な30秒として使えるかを必ず数値と一緒に確認します |

開始日時（ISO 8601、ZはUTC）、ミッション・エリア・兵科・両武器・敵密度／上限／開始時数・アート・描画解像度・カメラ・無敵／QA区分・撃破LEVELも記録します。

中断前の値は**部分記録**です。30秒完了した結果と同列に性能比較しないでください。「未計測」は推定で埋めません。30／60／120／144Hzなどを60Hzへ丸めたり、上限60FPSへ切り捨てたりしません。

### 重いフレームと中断

この30秒計測では、従来BENCHの「250ms超を除外」という規則は使いません。可視・前景・ゲーム更新中であれば、500／1000／1500msの重い間隔も記録します。

2秒超でも、直前フレームの更新＋描画CPUが間隔の75%以上を説明できる場合は、高負荷と整合するフレームとして間隔・FPS・分位値に含めます（`cpuAccountedLongFrames`）。現在フレームのCPUではなく、次のRAFを遅らせる直前フレームを参照します。

それ以外の信号のない2秒超は、OSの一時停止と高負荷を区別できません。長さを`unclassifiedGapMs`へ残し、試行を**無効**で終了します。間隔だけを黙って捨て、良い30秒の成績として報告しません。CPU比率は保守的な整合判定で、OS停止やGPU負荷の原因確定ではありません。準備中の2秒超も有効試行にしません。

ゲーム処理、描画、計測が止まったり非表示になった場合も有効な連続30秒としては採用しません。従来の6秒BENCH・ライブFPS・攻略JSONの既存集計は変更せず、別の計測として残しています。

## 6. コピーして共有する

1. 結果一覧で対象を選び、**体感メモ** に見切れ・同時操作・重かった場面などを書きます（最大500字）。メモはコピー時に付ける共通欄です。
2. **結果を日本語テキストでコピー** を押し、メッセージやメモへ貼り付けます。
3. 詳細データは **結果JSONをコピー**。従来の **計測JSONをコピー** にも`mobile`欄として実機計測とチェック結果を含めます。
4. Safariで自動コピーできない場合、**選択・手動コピー用テキスト** が開きます。内容を長押しし、全選択・コピーしてください。ボタンを連打したり、ファイルをダウンロードしたりする必要はありません。

計測結果は通常セーブへ書き込みません。コピーした内容を外部へ送信するのは、貼付先で利用者が行う操作です。この機能から自動送信はしません。

## 7. 実機受入チェック

「計測」→ **iPhone実機受入チェック IP-01〜08** を開きます。

| ID | 確認するもの |
| --- | --- |
| IP-01 | 起動・横画面表示、HUD、safe area、回転 |
| IP-02 | 移動＋ジャンプ＋射撃、指を離した後の解除 |
| IP-03 | 4兵科、SCOUTダッシュ、WING上昇・ホバー・EN |
| IP-04 | 全20武器、武器切替、マイン起爆 |
| IP-05 | M01〜M03の戦闘・各エリア・ボス表示 |
| IP-06 | 50体・100体の正常な30秒計測と体感 |
| IP-07 | LAB200体、エフェクトと操作継続 |
| IP-08 | 音声、通常保存、非表示・復帰、コピー |

最初は全部 **未確認**。実機で確認した人だけが **OK／NG** を選びます。NGはメモ欄が有効になります（最大200字）。PCテストの成功で自動的にOKにはしません。**チェック結果をコピー** で日本語一覧を共有できます。チェック状態・メモはLAB専用の一時状態で、通常セーブとは分離しています。

報告には端末・iOS・ブラウザ、横／縦、ミッション／エリア、兵科・武器、敵数、NG手順、計測結果を添えてください。無敵QA・エリア途中開始と、通常の全編クリアは分けて記録します。

## 8. 計測できないとき

- 「ゲーム更新待ち」なら、Safariを前景にし、ゲームが操作できる状態か確認してください。
- 「中断あり」なら、表示された理由を読んで新しい計測を開始します。前回の秒数は引き継ぎません。
- 「判別不能な長間隔」なら、環境・場面・間隔をメモし、OS停止と処理負荷を断定せず報告してください。
- 自動ブラウザ操作で正常30秒を取得できない場合、無意味な再計測を繰り返しません。有効結果0件として、iPhone実機で手動確認してください。
- 端末が熱い、低電力モード、通知・通話などがあった場合は体感メモへ記録します。都合の悪いフレームだけを除いて成績を良く見せません。
